# 三卦递进解读法

## 一、三卦体系概述

梅花易数占断的核心方法之一，是通过**本卦、互卦、变卦**三卦递进解读，构成完整的事件时间线分析。三卦各司其职，层层递进，形成"当前→过程→结果"的完整逻辑链条。

- **本卦**（主卦）：反映**当前状态**，是事情的开端和现状
- **互卦**（中爻卦）：反映**发展过程**，是事情的中途变化
- **变卦**（之卦）：反映**最终结果**，是事情的结局和归宿

---

## 二、本卦的解读——当前状态

### 2.1 本卦的定义

本卦即起卦时直接得到的重卦，是占断的起点和基础。一切分析从本卦出发。

### 2.2 本卦的解读方法

**（1）卦象层面**
- 观察上下两卦的卦象组合，理解整体意象
- 如：地天泰（坤上乾下），大地在天空之上，象征天地交泰，万物通顺
- 如：水山蹇（坎上艮下），水在山上，流而不通，象征艰难险阻

**（2）卦德层面**
- 从上下卦的卦德理解当前状态的性质
- 上卦为外、为环境、为他人；下卦为内、为自身、为主体
- 如：上乾下坤（天地否），外刚健而内柔顺，外强中干之象

**（3）体用层面**
- 确定体卦和用卦（由动爻决定）
- 判断体用生克关系，确定当前吉凶大势
- 如：体卦为离火，用卦为坤土，体生用，主当前有消耗

**（4）爻辞层面**
- 参看动爻所在位置的爻辞，获取具体信息
- 动爻的爻辞往往直接点出问题的关键所在

**解读示例**：本卦为"火雷噬嗑"，四爻动。
- 卦象：离火在上，震雷在下，火雷交加，咬合之象
- 当前状态：面临阻碍（咬合），需要突破（火雷之力）
- 体用：震木为体，离火为用，体生用，当前处于消耗状态
- 爻辞提示：九四爻"噬干胏，得金矢，利艰贞"，暗示困难中有利可图

---

## 三、互卦的解读——发展过程

### 3.1 互卦的取法

互卦（又称"中爻卦"）从本卦的中爻取出，反映事情发展的中间过程。

**取爻规则**：
- 取本卦的**第二、三、四爻**组成下互卦（下卦）
- 取本卦的**第三、四、五爻**组成上互卦（上卦）
- 将上互、下互组成新的重卦，即为互卦

**示意**：
```
本卦六爻         互卦
▅▅▅ 上九（六）    ——
▅▅▅ 九五（五）    → 上互卦（三四五爻）
▅▅▅ 九四（四）    → 上互卦（三四五爻） / 下互卦（二三四爻）
▅▅▅ 九三（三）    → 下互卦（二三四爻）
▅▅▅ 九二（二）    → 下互卦（二三四爻）
▅▅▅ 初九（一）    ——
```

**互卦取法示例**：
- 本卦：雷火丰（震上离下）
  - 爻位：上六、六五、九四、九三、六二、初九
  - 下互卦：取二三四爻（六二、九三、九四）→ 巽卦 ☴
  - 上互卦：取三四五爻（九三、九四、六五）→ 兑卦 ☱
  - 互卦：泽风大过（兑上巽下）

### 3.2 互卦的解读方法

互卦反映事情发展的**中间过程**和**隐性变化**，揭示事情发展过程中可能出现的关键转折和内在因素。

**解读要点**：

1. **互卦卦象**：看互卦的整体卦象，判断发展过程中的主要趋势
2. **互卦卦德**：从互卦的卦德理解发展过程的性质特征
3. **互卦与体卦的关系**：互卦的上下卦与体卦的五行生克，判断过程中对自身的利弊影响
4. **互卦的特殊意义**：互卦藏于本卦之中，表示"隐而未显"的因素

**解读示例**：承上例，本卦"火雷噬嗑"。

取互卦：
- 本卦爻位：上九、六五、九四、六三、六二、初九
- 下互卦：二三四爻（六二、六三、九四）→ 艮卦 ☶
- 上互卦：三四五爻（六三、九四、六五）→ 坎卦 ☵
- 互卦：水山蹇（坎上艮下）

互卦解读：
- 水山蹇为"艰难险阻"，表示发展过程中会遇到困境
- 坎水在艮山之上，水流受阻，暗示中途会有阻滞
- 但蹇卦六爻皆提示"见险而能止，知矣哉"，提示遇到困难应当暂停，不可冒进

## 四、变卦的解读——最终结果

### 4.1 变卦的取法

变卦（又称"之卦"）由本卦的动爻阴阳变化而得，反映事情的最终结果。

**取爻规则**：
- 本卦中动爻的位置，阳爻变阴爻，阴爻变阳爻
- 其余不动爻保持原样
- 变化后的六爻组成新卦，即为变卦

**变卦取法示例**：
- 本卦：火雷噬嗑（离上震下），四爻动
  - 四爻九四为阳爻，动则变为阴爻
  - 变化后：上卦离变为艮（离卦九四变六四→艮卦），下卦震不变
  - 变卦：山雷颐（艮上震下）

### 4.2 变卦的解读重点

**（1）变卦卦象**
- 看变卦的整体卦象，判断最终结果的大势
- 如变卦为"山雷颐"，颐为养，主最终结果是得到休养和调整

**（2）变卦的体用关系**
- 以变卦为"用"，本卦为"体"，看变卦（最终结果）对本卦（自身）的生克
- 变卦生本卦：最终结果对自身有利，事成
- 变卦克本卦：最终结果对自身不利，事败
- 本卦克变卦：自身能克制最终结果，虽成但费心
- 本卦生变卦：自身被最终结果消耗，劳而无功
- 本卦与变卦比和：最终结果与自身和谐，平稳过渡

**（3）动爻爻辞**
- 查看动爻对应的爻辞，往往点出结果的关键信息

**解读示例**：承上例，变卦"山雷颐"。
- 颐卦为"颐养"，主最终结果是休养生息、恢复调整
- 本卦（火雷噬嗑）体卦震木，变卦（山雷颐）上艮土、下震木，变卦上卦艮土被体卦震木克
- 结论：自身力量能克制最终局面，虽过程艰难（互卦蹇），但最终能掌控局势

## 五、三卦串联——完整时间线解读

### 5.1 三卦递进逻辑

```
本卦（现在）→ 互卦（过程）→ 变卦（结果）
   ↓              ↓              ↓
当前状态      发展变化       最终结局
```

### 5.2 完整解读实例

**起卦**：占问是否应该跳槽换工作，得"火雷噬嗑"，四爻动。

**第一步：本卦分析（当前状态）**
- 本卦：火雷噬嗑（离上震下）
- 体用：震木为体，离火为用，体生用（消耗）
- 当前状态：自己在现有工作中消耗精力，如咬硬物，颇为费力

**第二步：互卦分析（发展过程）**
- 互卦：水山蹇（坎上艮下）
- 发展过程：若换工作，过程中会遇到困难险阻，"蹇"为跛足难行之象
- 提示：求职过程不会一帆风顺，需有心理准备

**第三步：变卦分析（最终结果）**
- 变卦：山雷颐（艮上震下）
- 最终结果：颐卦为养，主最终得到休养生息
- 体卦震木克变卦上艮土，自己能掌控局面
- 结论：跳槽最终能成，过程虽有困难，但结果是好的

**综合判断**：当前工作消耗大，转职过程有波折，但最终能找到更合适的工作，建议坚持推进。

---

## 六、三卦解读的注意事项

1. **本卦为本，互变为辅**：本卦是基础，互变是补充，不要喧宾夺主
2. **体用始终以本卦为准**：体卦和用卦由本卦的动爻决定，互卦和变卦用来辅助判断过程与结果
3. **三卦要统一解读**：三卦之间要有逻辑联系，形成完整的故事线
4. **动爻是贯通三卦的线索**：动爻所在的位置是本卦、互卦、变卦变化的根源，要重点关注
5. **卦象与卦德结合**：不仅要看卦象的象征意义，还要结合卦德判断性质
6. **互卦的特殊价值**：互卦揭示的是"隐藏信息"，往往是占问者自己尚未意识到的关键因素
