# 声音外应起卦法

## 一、概述

梅花易数讲究"三要"（耳、目、心）和"十应"（天时、地理、人事等十种外应），声音和外应起卦法正是"三要"和"十应"理论的具体运用。这些方法与时间、数字、文字起卦法不同，更强调起卦者当下的感知能力和与环境的感应。

---

## 二、声音起卦法

### 2.1 以声音次数起卦

**规则**：根据听到的声音次数起卦。

- **一声**：上卦为乾，下卦为乾（或加时辰数取动爻）
- **两声**：上卦为兑，下卦为兑
- **三声**：上卦为离，下卦为离
- **四声**：上卦为震，下卦为震
- **五声**：上卦为巽，下卦为巽
- **六声**：上卦为坎，下卦为坎
- **七声**：上卦为艮，下卦为艮
- **八声**：上卦为坤，下卦为坤
- **超过八声**：以8取余数，余数对应卦象

**若两声以上**：可将第一声（或前几声）取上卦，第二声（或后几声）取下卦，总声数取动爻。

**实例**：听到敲门声5下，紧接着又听到3下。
- 前5声：5 ÷ 8 = 0余5 → 上卦为巽 ☴
- 后3声：3 ÷ 8 = 0余3 → 下卦为离 ☲
- 总声数8：8 ÷ 6 = 1余2 → 二爻动
- 本卦：风火家人（巽上离下），二爻动
- 变卦：风天小畜（巽上乾下）

### 2.2 以声音方位起卦

**规则**：根据声音传来的方位起卦，结合八卦方位。

- 东方传来声音 → 震卦
- 西方传来声音 → 兑卦
- 南方传来声音 → 离卦
- 北方传来声音 → 坎卦
- 东南方传来声音 → 巽卦
- 西南方传来声音 → 坤卦
- 西北方传来声音 → 乾卦
- 东北方传来声音 → 艮卦

**组合用法**：以声音传来的方位取上卦，以声音的次数取下卦，以总次数或时辰取动爻。

**实例**：南方传来鸟鸣3声。
- 南方 → 离卦 ☲，取上卦
- 3声 → 离卦 ☲，取下卦
- 3 ÷ 6 = 0余3 → 三爻动
- 本卦：离为火，三爻动
- 变卦：火雷噬嗑（离上震下）

### 2.3 以声音属性起卦

**规则**：根据声音的属性（音色、音调、音质）对应八卦。

| 声音属性 | 对应卦象 | 举例 |
|----------|----------|------|
| 洪亮、高亢、金属声 | 乾卦 | 钟声、锣声、金属碰撞声 |
| 悦耳、清脆、笑声 | 兑卦 | 笑声、歌声、乐器声 |
| 明亮、热烈、爆裂声 | 离卦 | 爆竹声、火焰声、掌声 |
| 震动、轰鸣、低沉 | 震卦 | 雷声、鼓声、爆炸声 |
| 柔和、细微、风声 | 巽卦 | 风声、呼吸声、轻语 |
| 低闷、水声、暗哑 | 坎卦 | 水声、雨声、哭泣声 |
| 沉闷、厚重、停顿 | 艮卦 | 撞击声、重物落地声 |
| 低沉、绵长、大地声 | 坤卦 | 地动声、回音、低沉轰鸣 |

**实例**：突然听到一声清脆的钟响。
- 钟声属金属声 → 乾卦 ☰，取上卦
- 1声 → 乾卦 ☰，取下卦
- 本卦：乾为天

## 三、外应起卦法

### 3.1 外应的概念

"外应"是指在起卦的当下，周围环境中出现的各种信号和征兆。梅花易数认为，天地万物相互感应，起卦时的外应直接反映了所求之事的信息。

**外应的核心原则**：当下所见所闻，皆是天机所示。

### 3.2 以所见事物起卦

**规则**：根据起卦时看到的事物，对应八卦取象。

**常见事物取象速查**：
- 看到天、太阳、圆形物体、官长 → 乾卦
- 看到水、月亮、湖泊、少女 → 兑卦
- 看到火、灯光、红色东西、文书 → 离卦
- 看到树木、绿色、雷声、车辆 → 震卦
- 看到风、飞鸟、扇形物体、草木 → 巽卦
- 看到江河、黑色、猪、鱼 → 坎卦
- 看到山、石头、狗、门 → 艮卦
- 看到土地、牛、黄色、方形物体 → 坤卦

**实例**：起卦时恰好看到一只狗跑过。
- 狗 → 艮卦 ☶
- 狗跑过为动 → 震卦的动意
- 可取上卦艮、下卦震，得山雷颐卦
- 或直接以艮卦为体进行判断

### 3.3 以天气变化起卦

**规则**：根据起卦时的天气状况取卦。

| 天气 | 对应卦象 | 含义 |
|------|----------|------|
| 晴天、烈日 | 离卦 | 事情明朗、顺利 |
| 阴天、乌云 | 坎卦 | 事情有阻碍、不明确 |
| 刮风 | 巽卦 | 事情有变动、不确定 |
| 打雷 | 震卦 | 事情有突变、惊动 |
| 下雨 | 坎卦 | 事情有波折、需要等待 |
| 下雪 | 乾卦/坎卦 | 事情有阻隔、需耐心 |
| 雾气 | 坤卦/艮卦 | 事情不明朗、隐藏 |

### 3.4 以突发动静起卦

**规则**：起卦时突发的意外动静，往往是最直接的外应信号。

**处理方式**：
- 突然的响声 → 取震卦（动）
- 物品突然掉落 → 取艮卦（止）或坤卦（地）
- 灯突然熄灭 → 取坎卦（暗/险）
- 突然有人来访 → 取乾卦（来）或该人所属卦象
- 动物突然出现 → 取该动物对应的卦象

**实例**：起卦时桌上的杯子突然倒了。
- 杯子为兑卦（容器、开口之物）
- 倒为转变之象
- 可取兑卦为体，判断所求之事可能有口舌或变化

## 四、其他起卦法

### 4.1 颜色起卦法

**规则**：根据看到的颜色起卦。

| 颜色 | 对应卦象 |
|------|----------|
| 红色、紫色、赤色 | 离卦 ☲ |
| 青色、绿色、碧色 | 震卦 ☳ / 巽卦 ☴ |
| 白色、银色 | 兑卦 ☱ / 乾卦 ☰ |
| 黑色、深蓝色 | 坎卦 ☵ |
| 黄色、棕色 | 坤卦 ☷ / 艮卦 ☶ |
| 金色 | 乾卦 ☰ |

**用法**：以颜色取上卦，以看到的数量或时辰取下卦和动爻。

### 4.2 方位起卦法

**规则**：根据求测者所在方位或所问方向的方位起卦。

**以问卦者所来方向**：取为上卦
**以问卦者所问之事的方向**：取为下卦
**以时辰取动爻**

**实例**：求测者从东方来，问南方之事，午时。
- 东方 → 震卦 ☳，取上卦
- 南方 → 离卦 ☲，取下卦
- 午时数7：7 ÷ 6 = 1余1 → 初爻动
- 本卦：雷火丰（震上离下），初爻动
- 变卦：雷山小过（震上艮下）

## 五、外应在解卦中的辅助作用

### 5.1 外应佐证卦象

外应可以作为卦象判断的佐证，增强判断的准确性。

**规则**：
- 若卦象显示吉，外应也吉 → 吉象加倍，可大胆断言
- 若卦象显示吉，外应显示凶 → 吉中有阻，需谨慎判断
- 若卦象显示凶，外应也凶 → 凶象确认，直言不讳
- 若卦象显示凶，外应显示吉 → 凶中有救，不必过于悲观

### 5.2 外应修正卦象判断

当卦象与外应严重冲突时，应重新审视：

1. **起卦是否准确**：重新核实起卦数据
2. **外应是否误读**：外应的取象是否正确
3. **是否应重新起卦**：心不诚则卦不灵，可等心静后重新起卦

### 5.3 外应使用的注意事项

1. **第一反应最重要**：起卦时最先注意到的外应最有效
2. **不可刻意寻找**：外应要自然感知，不可刻意寻求
3. **外应为辅，卦象为主**：外应作为辅助参考，不能喧宾夺主
4. **结合"三要"**：耳听、目视、心感三者结合，综合判断
5. **"十应"综合运用**：天时、地理、人事、声音、颜色、方位等十种外应相互印证
