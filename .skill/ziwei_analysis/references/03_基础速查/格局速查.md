# 三合派理论与经典格局库



## 一、三合派核心方法论

三合派是紫微斗数最古老、最基础的流派，也是所有流派的共同基础。



### 四大核心原则

1. **以命宫为太极**：所有分析从命宫出发，围绕命宫展开

2. **三方四正论命**：重点观察命宫三方四正的星曜组合

3. **庙旺利陷为基**：星曜得地则力强，失陷则力弱

4. **格局成败定高低**：成格者层次高，破格者层次降



### 三合派解读步骤

1. 看命宫主星是什么，定基本性格与人生基调

2. 看三方四正有哪些星，判断整体格局

3. 看吉星煞星分布，判断助力与阻力

4. 看生年四化分布，判断人生重点领域

5. 识别是否成格局，定人生层次高低

6. 逐宫分析各领域具体表现



### 三合派优缺点

- **优点**：体系完整，入门容易，格局判断直观，大方向准确

- **缺点**：对动态变化分析较弱，应期不够精准，细节不足



## 二、经典格局大全



### 第一类：帝王贵格（上等格局）

#### 1. 紫府同宫格

- **成格条件**：紫微、天府同宫于寅宫或申宫

- **格局意象**：君臣合璧，大富大贵，格局宏大

- **成格要点**：需左右昌曲魁钺相辅，方为真格

- **破格因素**：逢煞星多、空劫冲破，则为孤君库空，格局大减

- **人生特点**：领导力强，稳重可靠，事业基础扎实，一生发展稳健



#### 2. 紫府朝垣格

- **成格条件**：紫微、天府分守命宫三方，一在命一在财帛或官禄

- **格局意象**：君臣相得，互相呼应，事业有成

- **特点**：虽不如紫府同宫力量集中，但更灵活均衡



#### 3. 君臣庆会格

- **成格条件**：紫微守命，左辅右弼、文昌文曲、天魁天钺齐聚三方

- **格局意象**：明君贤臣，相得益彰，大贵之格

- **特点**：贵人极多，一生顺风顺水，易得人相助



#### 4. 府相朝垣格

- **成格条件**：天府、天相对拱命宫，或一在命一在对宫

- **格局意象**：印库相生，稳重富足，事业顺遂

- **特点**：一生衣食无忧，生活品质高，事业稳中有升



### 第二类：富贵格局

#### 1. 禄马交驰格

- **成格条件**：禄存与天马同宫或对照

- **格局意象**：动中得财，异地致富，奔波获利

- **特点**：适合外出发展、经商贸易，动则生财



#### 2. 财禄夹马格

- **成格条件**：化禄、禄存夹制天马

- **格局意象**：财源滚滚，奔波获利，财随动来

- **特点**：越动越有钱，出差、外派、搬迁都带财运



#### 3. 日月并明格

- **成格条件**：太阳在卯宫、太阴在酉宫，命宫居中

- **格局意象**：日月同辉，光明磊落，事业亨通

- **特点**：为人正直，事业光明，男女贵人皆有



#### 4. 日月反背格

- **成格条件**：太阳落酉、太阴落卯，失位对照

- **格局意象**：劳碌奔波，逆势而行，晚运方佳

- **特点**：早年辛苦，中年后逐渐好转，大器晚成



### 第三类：文贵格局

#### 1. 阳梁昌禄格

- **成格条件**：太阳、天梁同宫，加文昌、化禄

- **格局意象**：学业出众，文名远扬，科甲顺遂

- **特点**：考试运佳，适合学术、教育、文职发展



#### 2. 机月同梁格

- **成格条件**：天机、太阴、天同、天梁会于三方

- **格局意象**：文职发展，稳定上升，吏人之命

- **特点**：适合公职、行政、文员、服务行业，稳扎稳打



#### 3. 文星拱命格

- **成格条件**：文昌、文曲、左辅右弼、天魁天钺拱照命宫

- **格局意象**：才华横溢，科名顺遂，聪明好学

- **特点**：智力出众，学习能力强，靠才华吃饭



#### 4. 科名会禄格

- **成格条件**：化科、化禄同入命宫三方

- **格局意象**：名利双收，既有名声又有实利

- **特点**：事业名声与财富同步增长



### 第四类：武贵格局

#### 1. 七杀朝斗格

- **成格条件**：七杀守命于寅宫或申宫，得紫微对照

- **格局意象**：将星得地，武职显贵，开拓力强

- **特点**：适合军警、武职、管理、创业，执行力极强



#### 2. 英星入庙格

- **成格条件**：破军守命于子宫或午宫

- **格局意象**：英气逼人，开创力强，大起大落

- **特点**：敢闯敢拼，能成大事，但起伏大，中年后稳定



#### 3. 马头带箭格

- **成格条件**：擎羊与天马同宫

- **格局意象**：武职发展，边疆建功，动中带煞

- **特点**：适合远方发展、军警武职，动中求财但带风险



#### 4. 杀破狼格

- **成格条件**：七杀、破军、贪狼三星会齐于三方

- **格局意象**：一生起伏大，开创力强，变动频繁

- **特点**：成大事者多出于此格，但也多波折动荡，不稳定



### 第五类：特殊格局

#### 1. 火贪格 / 铃贪格

- **成格条件**：火星（或铃星）与贪狼同宫

- **格局意象**：横发格局，意外之财，爆发机遇

- **特点**：财运爆发性强，易有意外收获，但也主横破

- **注意**：成格也主起伏，发得快败得也快，需守财



#### 2. 石中隐玉格

- **成格条件**：巨门守命于子宫或午宫

- **格局意象**：外表普通内藏锦绣，中年后爆发

- **特点**：早年平平，中年后逐渐显露才华，大器晚成



#### 3. 双禄交流格

- **成格条件**：化禄与禄存互照命宫与财帛

- **格局意象**：财运亨通，富足安稳，财库充盈

- **特点**：一生财运稳定，不愁钱财，生活富足



#### 4. 空劫同命格

- **成格条件**：天空、地劫同入命宫

- **格局意象**：思想独特，易走偏门，财运起伏

- **特点**：思维异于常人，适合创意、玄学、艺术，但财运不稳



## 三、格局成败判断法则



### 成格三要素

1. **主星得地**：主星庙旺，不落陷

2. **吉星扶助**：左右昌曲魁钺等吉星辅助

3. **煞星不冲**：煞星少，不破格局



### 破格四因素

1. **主星落陷**：星曜失位，力量不足

2. **煞星冲破**：羊陀火铃空劫过多

3. **化忌冲宫**：化忌冲入命宫或三方

4. **空劫耗损**：天空地劫耗散福气



### 救格三因素

1. **吉星化解**：化科、天梁、魁钺可解煞

2. **禄星转化**：化禄、禄存可增福减凶

3. **主星强旺**：主星庙旺可抵御煞星



### 格局判断总原则

- 格局只是参考，不可执一而论

- 上等格局也有不顺之年，下等格局也有好运之时

- 格局定人生上限，运限定具体起伏

- 现代人社会环境变化大，格局的实际表现与古代已有差异
