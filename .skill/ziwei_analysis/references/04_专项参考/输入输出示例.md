# 输入输出示例

> 本文件展示紫微斗数分析在问答模式与报告模式下的典型输入输出格式，涵盖综合运势、流日择吉、性格、财运、感情婚姻、大限运势等核心场景，以及报告模板选取与特殊场景处理，供模型参考对齐。

---

## 一、问答模式示例

> 问答模式适用于用户提出具体、单一或少量命理问题的场景。输出遵循「结论先行 + 简要依据 + 行动建议」结构，按问题类型与时间维度优先级分配篇幅。

---

### 示例1：综合运势询问（问答模式）

**输入**：

```
命宫：紫微天相在午
身宫：夫妻宫
四化：廉贞化禄、破军化权、武曲化科、太阳化忌
大限：福德宫（2020-2030，35-44岁）
流年：丙午（2026），流年命宫在寅
问：2026年求职运势怎么样？
```

**输出**：

#### 2026求职运势：流年命宫逢天机，变动中藏机遇，8月是关键窗口

**核心结论**：**2026年有求职机遇，但过程波折需耐心，最佳入职窗口在8月中旬至9月上旬。**

**命盘背景**：命宫紫微天相带吉，格局不低但天相保守，主动求变时易犹豫。当前大限在福德宫，内心对事业方向有深层思考。2026流年命宫天机坐守，主变动、选择、奔波，求职为应象。

**关键月份**：
- ⚠️ **4-7月**：流月星曜不稳，面试邀约时有时无，反馈延迟，适合蓄力准备、完善简历
- ✅ **8月中旬-9月上旬**：流月命宫吉星汇聚，天魁贵人入命，面试发挥好，容易收到正式录用通知
- ⚠️ **10月后**：流月化忌冲官禄，新岗位机会减少，不宜做重大跳槽决定

**行动建议**：
1. 7-8月全力投递简历、完善作品集，8月中旬集中面试
2. 面试优先选择流日命宫有吉星或天魁天钺入命的日期
3. 面试穿蓝/黄色系增强气场，佩戴紫水晶或黄水晶
4. 首选管理、文化创意、教育行业，呼应命宫紫微天相的调性

> 命理为趋势参考，积极准备才能把运势优势转化为实际结果。

### 示例2：流日择吉（问答模式）

**输入**：

```
命宫：武曲贪狼在辰
问：下周三（癸卯日）能不能签合同，什么时辰最好？
```

**输出**：

#### 癸卯日签约：可行，推荐15:00-17:00

**当日吉凶**：中等偏吉，适合文书类事务。流日天机星入命，思维清晰、沟通顺畅；三方四正无煞星来冲，合作环境稳定。（⚠️ 注意：流日命宫天机主变，合同条款需仔细审核，避免细节疏漏）

**时辰排名**：
1. ✅ **申时（15:00-17:00）最佳**：流时命宫吉星汇聚，天魁入命，贵人运强，利于谈判达成共识
2. ✅ **酉时（17:00-19:00）次选**：流时命宫天相坐守，气场稳定，利于合同合规与条款确认
3. ❌ **避开巳时（9:00-11:00）、午时（11:00-13:00）**：流时煞星入命，易有压力与条款纠纷

**建议**：穿蓝色或白色系增强气场，核心条款提前沟通确认，当日不签过于复杂的合同。

### 示例4：财运分析（问答模式）

**输入**：

```
命宫：武曲天府在子（武曲旺、天府庙）
身宫：财帛宫
生年四化：巨门化禄、太阳化权、文曲化科、文昌化忌
财帛宫：贪狼在申（旺）
福德宫：天梁在寅（庙）
田宅宫：天同在卯（平）
大限：官禄宫（2020-2029，36-45岁），大限化禄入财帛
流年：丙午（2026），流年命宫在午
问：我的财运怎么样？求财方向和注意事项有哪些？
```

**输出**：

#### 财运总评：正财格局扎实，中年后财库丰盈，需防文星化忌招是非破财

**核心结论**：**命宫武曲天府坐镇，财星遇库星，属稳财厚局型命格。一生正财兴旺，善理财能守财，45岁后为财运高峰期。2026年大限化禄入财帛，当年财运偏吉，但流年化忌冲仆役需防合伙借贷破财。**

**财帛宫分析**（赚钱方式）：贪狼在申坐财帛，旺地。贪狼主多欲多求，财来多元渠道——正职之外有副业、投资、人情往来之财。但贪狼财起伏大，需配合武曲天府命宫的稳健特质，以正职为本、副业为辅。禄存同宫则流动财旺，适合动中求财。

**福德宫分析**（财源根基）：天梁在寅坐福德，庙旺。天梁为荫星，主清高贵气，财源根基在于名声口碑、专业积累。理财观念偏稳健保守，不喜高风险投机，重精神满足甚于物质攀比。天梁化权（大限引动）则求财有主见、有魄力，中年后靠威望地位获利。

**田宅宫分析**（财库容量）：天同在卯坐田宅，平地。天同主福，田宅平则财库容量中等——赚得到但积累速度一般，需刻意储蓄方能聚财。天同不喜煞星冲，若流年化忌入田宅，当年易有家居修缮、搬迁等额外开支消耗财库。

**发财路径判断**：
- ✅ **主业致富为主**：武曲化权（大限引动）坐命，正职收入是根基，适合金融、财务管理、五金贸易、技术执行类行业
- ✅ **副业投资为辅**：贪狼坐财帛有偏财运，可在主业稳定基础上适度发展副业、长线投资
- ✅ **名声变现**：天梁福德+文曲化科，靠专业口碑、知识变现、顾问咨询类收入有潜力
- ⚠️ **不宜暴利投机**：命宫天府库性保守，火贪格不成立，横发横破之财不适合此命局

**破财风险信号**：
- ⚠️ **文昌化忌**：文书合同类破财，签约、担保、借贷易出纠纷，2026年流年引动时尤为明显
- ⚠️ **流年化忌冲仆役**：朋友合伙、人情借贷是本年最大破财隐患
- ⚠️ **田宅天同偏弱**：财库不厚，大额意外支出（医疗、家宅）易动摇财务根基

**2026年财运关键月份**：
- ✅ **农历正月、五月**：流月化禄引动财帛宫，正财偏财均有利，适合推进重要项目
- ⚠️ **农历七月、十一月**：流月化忌冲仆役或田宅，避免借贷担保，控制不必要开支

**行动建议**：
1. 以正职收入为根基，2026年大限化禄入财帛，适合争取加薪晋升或承接核心项目
2. 副业投资控制在总收入20%以内，选择稳健型长线项目，忌短线高杠杆
3. 所有涉及金钱的合同、借贷、担保，务必逐条审核，遇有歧义条款宁可不签
4. 田宅偏弱，建议将盈余转化为不动产或定期存款，减少手头现金流动
5. 有利方位：正西方、北方求财；幸运颜色：白色、金色系；旺运饰品：黄水晶、金发晶

> 财运分析为趋势参考，具体投资决策请结合市场环境与专业财务建议。

### 示例5：感情婚姻分析（问答模式）

**输入**：

```
命宫：破军在午（旺）
身宫：夫妻宫
生年四化：廉贞化禄、破军化权、武曲化科、太阳化忌
夫妻宫：天相在子（庙）
福德宫：天同太阴在寅（天同旺、太阴平）
桃花星：红鸾在卯、天喜在酉
大限：夫妻宫（2020-2029，28-37岁）
流年：丙午（2026），流年命宫在午
问：我的感情婚姻运势怎么样？什么时候能遇到正缘？
```

**输出**：

#### 感情总评：破军坐命情路波折，天相夫妻可稳，2026红鸾引动有正缘机遇

**核心结论**：**命宫破军化权，性格刚烈好动，感情中主导性强但易生变动。夫妻宫天相庙旺，配偶温和有辅，婚姻底子不差但需经磨合。当前行夫妻宫大限（28-37岁），是婚恋关键期，2026年红鸾入命、天喜入夫妻，正缘出现概率高，建议把握上半年社交窗口。**

**夫妻宫分析**（配偶特质与婚姻质量）：
- **天相在子庙旺**：配偶性格温和周到，善于协调，有服务意识，外貌端正。天相为印星，配偶可能从事行政、人事、秘书、设计类工作
- **对宫官禄宫互涉**：破军命宫冲天相夫妻，自身事业心强、变动多，容易因工作忽略感情，需刻意平衡
- **三方四正**：夫妻宫三方汇天府、紫微，配偶有一定社会地位或能力不弱，但也意味着双方都好强，需学会示弱

**桃花星分析**：
- **红鸾在卯（子女宫）**：正桃花星，主婚恋喜庆。2026流年引动，恋爱机遇增多，尤其通过社交活动、朋友介绍认识对象
- **天喜在酉（田宅宫）**：喜庆星，2026流年天喜入夫妻宫位，婚姻宫位被引动，有缔结良缘之象
- **廉贞化禄在官禄宫**：次桃花星化禄，个人魅力在工作场合展现，易因工作关系发展感情

**婚姻质量评估**：
- ✅ **优势**：天相夫妻庙旺，配偶得力且包容，婚姻有稳定基础；身宫在夫妻宫，自身重视感情，愿意投入经营
- ⚠️ **隐患**：破军化权坐命，性格急躁强势，感情中易冲动决策；破军主"耗"，恋爱关系中聚少离多反而更稳
- ⚠️ **太阳化忌冲子女宫**：婚后子女缘稍有波折，或因子女问题产生矛盾，需提前沟通教育理念

**2026年感情运势**：
- ✅ **农历正月-四月**：红鸾引动，社交运旺，通过朋友介绍、工作场合、兴趣社群认识合适对象的概率最高
- ✅ **农历五月**：天喜入夫妻宫，感情升温快，适合确定关系或表白
- ⚠️ **农历七月、十月**：流月煞星入夫妻宫，易因小事争吵闹矛盾，需控制情绪、多沟通
- ✅ **农历八月、十二月**：贵人星入命，感情有长辈或朋友助力，适合见家长或推进婚事

**行动建议**：
1. 2026年上半年积极拓展社交圈，参加兴趣活动、行业交流，提高遇见正缘的概率
2. 择偶优先选择性格温和、包容性强的对象（天相特质），互补破军的刚烈
3. 恋爱中学会示弱和倾听，避免破军化权的"掌控欲"给对方压力
4. 相处保持适当距离感，各自有事业空间，不宜过度黏人——破军命宜"聚少离多反而情长"
5. 2026年适合认识交往，但不宜闪婚，建议相处一年以上再考虑婚嫁
6. 旺感情方法：佩戴粉水晶、草莓晶旺正缘；卧室布置暖色调；多参加春季社交活动

> 感情分析为趋势参考，幸福婚姻取决于双方用心经营与相互包容。

### 示例6：大限运势分析（问答模式）

**输入**：

```
命宫：天机太阴在寅（天机旺、太阴平）
身宫：官禄宫
生年四化：天机化禄、天梁化权、紫微化科、太阴化忌

流年：丙午（2026），流年命宫在午
问：我当前大限运势怎么样？未来十年有什么重点？
```

**输出**：

#### 大限总评：官禄宫大限逢太阴化禄，事业财运上升期，健康情绪为隐忧

**核心结论**：**当前行官禄宫大限（33-42岁，2020-2029），大限命宫主星得禄权科三吉加持，是事业发展的黄金十年。太阴化禄入交友宫主人际财源广，天机化科入命宫主名声提升。唯巨门化忌入疾厄宫，健康与口舌是非为本大限最大课题。2026流年命宫在午逢贪狼，人缘旺但需防过度社交消耗精力。**

**大限命宫分析**：
- **官禄宫坐大限命**：此十年人生重心在事业，工作成为自我认同的核心。官禄宫本命主星若为天梁（化权），则此十年有晋升掌权、承担重任的机遇
- **大限命宫三方四正**：汇天机太阴（本命命宫）、天同巨门（疾厄宫），事业格局与个人能力匹配，但健康宫位煞忌较重需注意

**大限四化分析**（十年运势驱动力）：
- ✅ **太阴化禄入交友宫**：人际交往带来财运，朋友、客户、合作伙伴是财源。此十年适合拓展人脉、经营客户关系，女性贵人运尤佳

- ✅ **天机化科入命宫**：名声提升，智慧才能被认可，适合考取证书、发表论文、建立专业品牌

**叠宫效应**（大限宫位与本命宫位叠加）：
- **大限命宫叠本命官禄宫**：事业主题强化，此十年事业成就直接决定人生高度
- **大限化禄入交友宫叠本命交友宫**：人际关系运双层叠加，社交圈扩大且带来实质利益

```
     - 第五部分：行事宜忌总览 → 终身宜忌 + 年度建议
  5. 按缺省模板填充规则执行（表格全填、占位符全替换等）

输出：
  按缺省模板五部分结构输出的完整报告
```

### 3.4 三档模板版本处理（精简版 / 高级版 / 至尊版）

当用户或系统指定报告版本时，按以下标准调整报告深度与篇幅：

| 版本 | 触发方式 | 篇幅 | 内容深度 | 适用场景 |
|------|----------|------|----------|----------|
| **精简版** | 用户说"简单看看""精简版""快速过一遍" | 3000-5000字 | 核心结论+关键宫位+当前运势 | 快速了解命盘概况 |
| **高级版** | 用户说"详细报告""高级版"（或未指定版本时的默认） | 8000-12000字 | 五部分全覆盖+逐宫分析+大限流年 | 标准深度解读 |
| **至尊版** | 用户说"至尊版""最详细""深度解盘" | 12000-15000+字 | 全覆盖+多流派交叉验证+飞星追踪+神煞详解+逐年细批 | 深度全面解读 |

**精简版示例**：

```
输入：
  排盘JSON + 用户问题"帮我简单看看这个命盘，精简版就行"

处理：
  1. 模式判定：报告模式（用户要求看命盘）→ 版本判定：精简版
  2. 选取精简版模板结构：
     - 命盘概览：命宫主星、身宫、格局定调（1段）
     - 核心判断：格局层次、四化吉凶、命局总评（1表+1段）
     - 当前运势：当前大限一句话 + 流年关键提示（1段）
     - 行事建议：3-5条核心建议（列表）
  3. 控制篇幅在3000-5000字

输出：
  ───────────────────────────────────
  紫微斗数命盘简析（精简版）
  ───────────────────────────────────

  一、命盘概览
  命宫紫微在午，帝坐得地，成极向离明格...
  （约500字）

  二、核心判断

  | 格局 | 极向离明格，上等偏中 |
  | 层次 | 72分，中等 |
  | 四化 | 禄权科三吉+化忌一凶 |
  | 总评 | 先贵后磨型，中年有考验 |
  （约800字）

  三、当前运势
  当前行子女宫大限（35-44），大限化忌入疾厄...
  2026流年命宫在午，天同化禄入疾厄...
  （约800字）

  1. 事业宜守不宜攻，流年化忌冲官禄
  2. 健康定期检查脾胃口腔
  3. 财运以正财为本，避免高风险投机
  4. 善用天魁天钺贵人借力
  （约500字）
  ───────────────────────────────────
```

**高级版示例**（默认版本）：

```
输入：
  排盘JSON + 用户问题"帮我生成一份详细的紫微斗数报告"

处理：
  1. 模式判定：报告模式 → 版本判定：高级版（未指定版本时默认）
  2. 选取高级版模板结构（即缺省报告模板五部分完整结构）：
     - 第一部分：命盘基础信息（十二宫表格+星曜统计）
     - 第二部分：命局核心判断（格局表+四化表+层次评分表）
     - 第三部分：人生领域详解（性格/六亲/事业/财运/健康/感情，各2-4条结论）
     - 第四部分：运势时序分析（大限总览表+当前大限详解+近五年流年表+流年重点）
     - 第五部分：行事宜忌总览（宜忌表+年度建议+化煞方案）
  3. 控制篇幅在8000-12000字

输出：按五部分完整结构输出（参见"二、报告模式示例"中的结构概览）
```

**至尊版示例**：

```
输入：
  排盘JSON + 用户问题"帮我做一份至尊版的深度解盘，越详细越好"

处理：
  1. 模式判定：报告模式 → 版本判定：至尊版
  2. 在高级版五部分基础上，增加深度内容：
     - 第一部分追加：星曜庙旺利陷逐颗详解、神煞分类详表（甲级/乙级/丙级）
     - 第二部分追加：多流派交叉验证（三合定象+飞星寻踪+四化应期）、
       来因宫分析、三方四正组合详解（命/财/官/夫四关键宫）
     - 第三部分追加：每个领域增加飞星因果追踪、宫干飞化连锁效应分析
     - 第四部分追加：大限逐限详评（12步全覆盖，每步含四领域评分）、
       流年逐年细批（近十年逐年分析，含关键月份逐月判断）
     - 第五部分追加：终身运势曲线描述、人生阶段规划建议、
       化煞改运全方案（含择吉择时、风水方位、饰品饮食全方位建议）
  3. 控制篇幅在12000-15000+字

输出：在高级版基础上全面扩展深度的完整报告
```

**版本选取规则总结**：

```
用户未指定版本 → 默认高级版
用户说"精简""简单""快速" → 精简版
用户说"至尊""最详细""深度" → 至尊版
用户说"详细""完整" → 高级版
用户提供的模板已含结构 → 按用户模板执行（版本由模板自身结构决定）
```

### 4.1 信息缺失场景

**场景**：用户提供的排盘数据不完整，缺少关键信息。

**示例1：缺少大限信息**

```
输入：
  命宫：紫微天相在午
  身宫：夫妻宫
  四化：廉贞化禄、破军化权、武曲化科、太阳化忌
  问：我今年事业运势怎么样？

处理：
  → 信息校验：命宫主星 ✓、身宫 ✓、四化 ✓、大限 ✗、流年 ✗
  → 大限和流年信息缺失，无法精确判断当年运势

输出：
  您好，根据您提供的命盘信息，命宫紫微天相在午，格局不低，带
  廉贞化禄、武曲化科，事业方面有贵人有名声。

  但要精确分析今年的事业运势，还需要您补充以下信息：
  - 当前所行大限（年龄区间+大限宫位）
  - 欲分析的流年年份

  补充后我可以为您做更精准的流年事业分析。
```

**示例2：缺少生年四化**

```
输入：
  命宫：天机太阴在寅
  问：我财运怎么样？

处理：
  → 信息校验：命宫主星 ✓、四化 ✗、财帛宫 ✗
  → 四化是命盘核心，缺失则无法判断财运吉凶层次

输出：
  您好，命宫天机太阴在寅，天机主智慧变动，太阴主财，本身对
  财运有正面暗示。但要深入分析财运，还需要您补充：
  - 生年四化（化禄/化权/化科/化忌分别落哪颗星）
  - 财帛宫主星
  - 当前大限

  这些信息决定财运的吉凶层次与求财方向，补充后为您详细分析。
```

**处理原则**：
1. **一句话礼貌询问**，不臆断、不编造缺失信息
2. 优先基于已有信息给出初步判断，再列出需要补充的内容
3. 不因信息缺失而拒绝回答，而是给出"有限信息下的最大分析"
4. 若用户提供的是排盘JSON，优先检查 `analysis` 预计算字段是否完整

### 4.3 多维度联动场景

**场景**：用户同时询问多个时间维度的运势，或选中的焦点包含多个维度。

**示例1：用户同时问大限+流年+流月**

```
输入：
  命宫：天机太阴在寅
  大限：官禄宫（2020-2029，33-42岁）
  流年：丙午（2026），流年命宫在午
  流月：农历五月，流月命宫在申
  问：我当前大限怎么样？今年整体运势如何？五月适合做重要决策吗？
```

**处理**（按时间维度优先级规则分配篇幅）：

```
用户涉及3个维度：大限 + 流年 + 流月
→ 由小到大排列：流月（最小）> 流年 > 大限
→ 信息量分配：流月 ≥60% > 流年 ≈25% > 大限 ≈15%

输出结构：
  1. 流月分析（核心重点，≥60%篇幅）
     - 农历五月流月命宫在申，主星与四化作用
     - 当月吉凶判断、具体日期窗口
     - 适合/不适合做重要决策的日期
     - 当月行动建议
  
  2. 流年分析（简要背景，≈25%篇幅）
     - 2026丙午流年整体定调
     - 关键月份提示（含五月）
     - 流年行动方向
  
  3. 大限分析（一句话背景，≈15%篇幅）
     - 当前官禄宫大限整体趋势一句话概括
     - 大限对本年流月的支撑/制约作用
```

**输出**：

**核心结论**：**农历五月流月命宫在申，逢贪狼坐守引动偏财机缘，整体偏吉，适合做重要决策。但5月15日前后流日化忌冲命，需避开此窗口。大限官禄宫逢太阴化禄，事业大方向有利；2026流年天同化禄入疾厄，身体有福但易懒，决策时保持清醒。**

**流月分析（农历五月）**：
- 流月命宫在申，贪狼坐守，主社交活跃、机遇增多
- 流月四化引动财帛宫，当月有财务决策的窗口
- ✅ 适合决策日：农历五月初三、初八、十二（流日吉星入命）
- ⚠️ 避开日：农历五月十五、十六（流日化忌冲命，易判断失误）
- 建议在5月上旬完成调研，中旬吉日做最终决策

**流年背景**：2026丙午年整体运势中等偏平，流年命宫在午逢贪狼，人缘旺但需防过度社交消耗精力。五月是全年中较好的决策窗口之一。

**大限背景**：当前官禄宫大限太阴化禄入交友，事业人际大环境有利，重要决策可放心推进。

**行动建议**：
