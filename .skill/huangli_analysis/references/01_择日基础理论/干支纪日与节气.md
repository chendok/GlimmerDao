# 干支纪日与节气

## 一、六十甲子纪日体系

### 1.1 干支纪日的基本原理

干支纪日是中国传统历法中最为古老的纪日方法，其历史可追溯至殷商甲骨文时代，至今已延续三千余年。干支纪日以十天干（甲、乙、丙、丁、戊、己、庚、辛、壬、癸）与十二地支（子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥）依次相配，组成六十个基本单位，称为"六十甲子"或"六十花甲子"，每六十日为一个循环，周而复始，独立于年、月之外连续运行。

干支纪日不受闰年、闰月的影响，是择日学中最稳定的时间坐标系统。所有吉神凶煞的推算、建除十二神的排列、黄道黑道的循环，乃至彭祖百忌的对应，都以日辰干支为基础。

### 1.2 干支组合规律

干支组合遵循"阳干配阳支、阴干配阴支"的规则：

- **阳干**：甲、丙、戊、庚、壬（5个）
- **阴干**：乙、丁、己、辛、癸（5个）
- **阳支**：子、寅、辰、午、申、戌（6个）
- **阴支**：丑、卯、巳、未、酉、亥（6个）

阳干只能与阳支相配，阴干只能与阴支相配。因此，天干与地支的组合并非随意的 120 种（10×12），而是 60 种（5×6 + 5×6），这正是六十甲子的由来。例如：甲子、乙丑、丙寅……永远不会出现"甲丑"或"乙子"这样的组合。

### 1.4 干支纪日在择日中的核心作用

干支纪日是所有择日判断的出发点，具体体现在以下几个方面：

1. **建除十二神推算**：以月令地支为基准，确定当月建日，然后按地支顺序排列建除十二神。例如正月建寅，寅日为建日，卯日为除日，依此类推——这完全依赖于日辰地支。
2. **黄道黑道推算**：以日辰地支为基准，按青龙、明堂、金匮、天德、玉堂、司命、天刑、朱雀、白虎、天牢、玄武、勾陈的顺序循环，确定当日黄道或黑道。
3. **吉神凶煞推算**：绝大多数吉神凶煞的判定都以日辰干支为基础。如天德贵人根据月令和日干确定，三合根据日支与月令的关系确定，劫煞灾煞根据日支与月令的三合关系确定。
4. **彭祖百忌对应**：彭祖百忌中"甲不开仓""乙不栽植"等条目直接对应日干，是日辰干支的直接应用。
5. **五行生克判断**：日辰干支的五行属性（天干五行与地支五行）与事项五行的生克关系，是日辰与事项匹配的核心依据。

### 1.5 日辰干支的空亡

空亡是干支纪日体系中一个重要的概念。六十甲子按六甲（甲子、甲戌、甲申、甲午、甲辰、甲寅）分为六旬，每旬十日，各有二支为空亡：

- 甲子旬：戌亥空亡
- 甲戌旬：申酉空亡
- 甲申旬：午未空亡
- 甲午旬：辰巳空亡
- 甲辰旬：寅卯空亡
- 甲寅旬：子丑空亡

空亡日的选择需谨慎。传统上认为，空亡日不宜进行签约、交易、立券等需要长久效力的事项，因"空亡"意味着事成之后可能落空。

## 二、二十四节气与择日关系

### 2.1 二十四节气概述

二十四节气是中国古代根据太阳在黄道上的位置制定的历法补充体系，以立春、雨水、惊蛰、春分、清明、谷雨、立夏、小满、芒种、夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪、冬至、小寒、大寒为二十四节气。其中，立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒为"节"，其余为"气"。

在择日学中，节气是划分月令的根本依据，而非农历初一。月令的起始以"节"为界，而非"气"。

### 2.3 关键节气在择日中的特殊意义

**四立日（立春、立夏、立秋、立冬）**：四立日是季节交替的节点，气场变化剧烈。立春、立夏、立秋、立冬当日不宜婚嫁、安葬等重大事项，但立春后一日为"迎春"吉日，适宜出行、祈福。

**二分二至日（春分、秋分、夏至、冬至）**：分至日是阴阳转换的关键节点。春分、秋分阴阳平衡，宜祭祀、祈福；夏至阳气至极，宜静不宜动；冬至一阳来复，宜祭祀祖先、祈福纳祥。

**四离日**：四离日是冬至、夏至、春分、秋分的前一日，属大凶之日。四离日忌嫁娶、开业、出行、签约等一切吉事，因其为阴阳分离之时。

**四绝日**：四绝日是立春、立夏、立秋、立冬的前一日，同样是大凶之日。四绝日忌一切重大事项，因其为四季断绝之时。

**土王用事日**：立春、立夏、立秋、立冬前十八日为"土王用事"期间，此期间土气旺盛，忌动土、修造、安葬等涉及土地的事务。尤其立春前十八日（冬末）和立秋前十八日（夏末）的土王用事日，避忌最为严格。

### 2.4 节气前后择日注意事项

1. **节气交替当日**：节气交节当日，气场处于转换之中，不稳定。重大事项如婚嫁、开业、安葬等宜避开节气交节当日，至少提前或推后一日。
2. **节气前三日**：重大节气（如立春、立夏、立秋、立冬、冬至）前三日，气场渐趋变化，亦不宜安排重大事项。
3. **节气后三日**：节气后气场渐趋稳定，是启动新事项的好时机。特别是立春后、立秋后，可作为择吉的参考窗口。
4. **清明前后**：清明为祭祀节日，清明前后三日不宜婚嫁、开业等喜庆事项，但祭祀、扫墓则在清明当日或前三日后三日均可。
5. **冬至特殊规则**：冬至日是"一阳来复"之日，传统上认为冬至日诸事不宜，但冬至后阳气渐长，适宜开始新的事务。

## 三、七十二候与择日

### 3.1 七十二候的基本概念

七十二候是中国古代将二十四节气进一步细分的体系，每节气分为三候，每候五日，全年共七十二候。七十二候描述了自然界中动植物和气候现象的周期性变化，是中国古代物候学的重要成果。

### 3.2 七十二候在择日中的参考价值

在传统择日学中，七十二候主要用于辅助判断时令的细微变化，对择日的影响主要体现在以下方面：

1. **农事择日**：七十二候直接指导农事活动的时机选择。如"惊蛰三候，鹰化为鸠"期间，万物复苏，适宜播种；"谷雨一候，萍始生"期间，宜种植水稻。
2. **出行择日**：七十二候中关于气候变化的描述，可作为出行择日的参考。如"小暑一候，温风至"期间，出行宜避暑热；"大寒一候，鸡始乳"期间，虽寒冷但阳气渐生，可安排远行。
3. **祭祀择日**：七十二候中与祖先崇拜相关的候应（如"清明一候，桐始华"），可作为祭祀择日的参考节点。
4. **修造择日**："霜降"之后土气渐固，为动土修造的较佳时节；"雨水"之后土气渐松，动土需谨慎。

### 3.3 七十二候择日核心规则

- **启蛰候**（惊蛰一候至三候）：万物复苏，宜开启新事，如开业、出行、修造开工。
- **华实候**（各类植物开花、结果的候应）：宜婚嫁、祭祀、祈福。
- **蛰藏候**（各类动物蛰伏的候应）：宜收敛、不宜大动，出行需谨慎。
- **肃杀候**（秋风萧瑟的候应）：宜收敛、安葬、祭祀，不宜婚嫁、开业。

## 四、干支五行纳音

### 4.1 五行纳音的基本概念

五行纳音，又称"六十甲子纳音"，是将六十甲子按五行特性分为三十组，每组两个干支对应一个纳音五行。纳音五行不同于天干地支的基础五行，而是揭示了一种更为精微的五行属性，在择日学中常用于判断日辰的内在气质。

### 4.3 纳音五行在择日中的应用

1. **判断日辰的精微气质**：纳音五行比基础五行更能反映日辰的内在气质。例如，甲子日天干甲木、地支子水，基础五行以木为主；但纳音为"海中金"，说明此日有金的内在气质，在择日时需要综合考虑。
2. **事项五行匹配**：某些事项对日辰的纳音五行有特殊要求。如婚嫁择吉中，纳音五行相生的日辰更为理想；安葬择吉中，亡者纳音五行与日辰纳音五行不宜相克。
3. **纳音三合运用**：纳音五行之间也存在三合关系。如海中金（甲子乙丑）、沙中金（甲午乙未）、白蜡金（庚辰辛巳）三者纳音均为金，可以视作纳音三合，在同一天干纪年对应的日辰中，可以形成纳音层面的合力。

## 五、日辰五行与事项五行匹配规则

### 5.1 日辰五行属性判定

日辰的五行属性需从三个层面判定：

1. **天干五行**：甲乙木、丙丁火、戊己土、庚辛金、壬癸水。
2. **地支五行**：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。
3. **纳音五行**：如上表所示，六十甲子各有纳音五行。

在择日实践中，通常以天干五行为主，地支五行为辅，纳音五行作精细调校。当日辰天干五行与地支五行不一致时，需要综合考量。

### 5.2 事项五行分类

不同事项具有不同的五行属性，择日时应选择日辰五行与事项五行相生或比和之日：

| 事项类别 | 五行属性 | 说明 |
|----------|----------|------|
| 婚嫁 | 火（喜） | 婚嫁为喜庆之事，属火，宜选火旺日或木生火日 |
| 开业 | 金（财） | 开业求财，属金，宜选金旺日或土生金日 |
| 祭祀 | 土（敬） | 祭祀为庄重之事，属土，宜选土旺日或火生土日 |
| 修造 | 木（建） | 修造兴建，属木，宜选木旺日或水生木日 |
| 出行 | 水（行） | 出行流动，属水，宜选水旺日或金生水日 |
| 安葬 | 土（归） | 入土为安，属土，宜选土旺日或火生土日 |
| 签约 | 金（契） | 契约文书，属金，宜选金旺日或土生金日 |
| 求医 | 木（生） | 求医问药，属木，宜选木旺日或水生木日 |
| 诉讼 | 金（断） | 诉讼裁断，属金，宜选金旺日或土生金日 |

### 5.3 五行生克匹配规则

**日辰五行与事项五行的理想关系**：

1. **日辰生事项**（吉）：日辰的五行能量生助事项，如日辰属木，事项属火（木生火），为最佳匹配，主顺遂有成。
2. **日辰与事项比和**（吉）：日辰五行与事项五行相同，如日辰属火，事项亦属火，主平稳顺利，但不如相生。
3. **事项生日辰**（中平）：事项五行生助日辰五行，如日辰属土，事项属火（火生土），主消耗自身能量以成就日辰，非最佳但可用。
4. **日辰克事项**（不宜）：日辰五行克制事项五行，如日辰属金，事项属木（金克木），主阻碍、不顺，不宜选用。
5. **事项克日辰**（不宜）：事项五行克制日辰五行，如日辰属水，事项属火（水克火），主事与愿违，不宜选用。

### 5.4 五行旺衰与择日时机

五行之气在一年中有旺衰变化，择日时应结合时令五行旺衰：

- **春（木旺）**：木旺火相，宜选木、火相关事项；水休土死，水、土相关事项非最佳。
- **夏（火旺）**：火旺土相，宜选火、土相关事项；金休木死，金、木相关事项非最佳。
- **秋（金旺）**：金旺水相，宜选金、水相关事项；木休火死，木、火相关事项非最佳。
- **冬（水旺）**：水旺木相，宜选水、木相关事项；火休金死，火、金相关事项非最佳。
- **四季末（土旺）**：辰戌丑未月，土旺金相，宜选土、金相关事项。

### 5.5 综合案例

**案例一：婚嫁择日**

婚嫁属火，春季木旺，选木日（如甲寅、乙卯日）为最佳，木生火，婚嫁火热喜庆。若选金日（如庚申、辛酉日），金克木，而木为火之母，间接不利婚嫁。

**案例二：开业择日**

开业属金，秋季金旺，选金日（如庚申、辛酉日）为最佳，比和助力。若选火日（如丙午、丁巳日），火克金，对财运不利，应避开。

**案例三：修造择日**

修造属木，冬季水旺，选水日（如壬子、癸亥日）为最佳，水生木，修造顺利。若选金日（如庚申、辛酉日），金克木，修造过程中易有阻碍。

> 日辰五行与事项五行匹配是择日学中较为精微的层面，在实际操作中应将其作为综合判断的一部分，与建除十二神、黄道黑道、吉神凶煞等维度共同考量，不可偏废。
