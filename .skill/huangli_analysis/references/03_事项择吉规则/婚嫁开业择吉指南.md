# 婚嫁开业择吉指南

## 一、婚嫁择吉详细规则

### 1.1 择日宜选

#### 一级吉日（首选）

以下日辰条件为婚嫁首选，吉力最强：

- **黄道日**：青龙、明堂、金匮、天德、玉堂、司命值日。
- **建除吉神**：成日、开日、定日为婚嫁首选建除十二神。
- **吉神配合**：天德、月德、天德合、月德合、天喜、六合、三合、益后、续世等吉神值日。
- **二十八宿**：角、氐、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿值日。

#### 二级吉日（次选）

- **建除神**：平日、执日（需配合其他吉神）。
- **吉神**：天恩、母仓、福生、圣心等。
- **二十八宿**：参、井等。

#### 最佳神煞组合

婚嫁择日最理想的神煞组合依次为：

1. **天月二德 + 天喜 + 六合 + 成日/开日 + 黄道日**：至吉组合，婚姻美满，白头偕老。
2. **天德/月德 + 天喜 + 三合 + 定日 + 黄道日**：大吉，婚姻稳固，家庭和睦。
3. **天德合/月德合 + 天喜 + 益后/续世 + 成日/开日 + 黄道日**：吉，子孙兴旺，家业传承。

### 1.2 择日忌避

#### 绝对禁忌（不可用）

- **月破日**：主婚姻破裂，夫妻不和。
- **岁破日**：冲犯太岁，大凶。
- **四离日**：主夫妻分离，婚姻难久。
- **四绝日**：主断绝，婚姻绝灭。
- **四废日**：主婚姻衰败。
- **黑道日**：玄武、白虎、天牢、勾陈值日。

#### 强烈禁忌（尽量避开）

- **建除凶神**：破日、闭日。
- **凶煞**：往亡、灾煞、死气、劫煞。
- **二十八宿凶宿**：亢、心、牛、女、虚、危、昴、觜、鬼、柳、星、翼。
- **重丧日、三丧日**：虽主丧事，但婚嫁亦应避开。

#### 一般禁忌

- **建除神**：除日（除旧之意与婚嫁喜事相悖）、满日（满则溢）。
- **新娘本命冲日**：日支与新娘生肖地支相冲之日。
- **杨公忌日**：正月十三、二月十一、三月初九、四月初七、五月初五、六月初三、七月初一、七月廿九、八月廿七、九月廿五、十月廿三、十一月廿一、十二月十九。共十三日，忌婚嫁等一切大事。

### 1.3 时辰选择

婚嫁时辰选择原则：

1. **黄道时辰优先**：子时（司命）、寅时（青龙）、卯时（明堂）、午时（金匮）、未时（天德）、酉时（玉堂）为黄道吉时。
2. **避开黑道时辰**：丑时（勾陈）、辰时（天刑）、巳时（朱雀）、申时（白虎）、戌时（天牢）、亥时（玄武）。
3. **根据婚嫁仪式选择**：迎亲宜选上午吉时（寅、卯、辰、巳时中的黄道时分）；拜堂宜选午时（金匮值日，最为吉利）；入洞房宜选酉时（玉堂值日）。
4. **新娘生肖配合**：避开与新娘生肖相冲的时辰。如新娘属鼠，避开午时；属牛，避开未时，以此类推。

### 1.4 注意事项

1. **男女双方命理配合**：理想情况下，婚嫁日辰应与双方八字相合，避开冲克。若无法请专人合婚，至少应避开与新娘生肖相冲之日。
2. **季节选择**：春季婚嫁最佳（万物生长，生机勃勃），秋季次之。夏季炎热，冬季寒冷，非最佳季节。
3. **月令配合**：婚嫁宜选农历二月（花朝月）、八月（中秋月）、十月（阳春月）等吉利月份。
4. **避开特殊日期**：避开七月（鬼月）、清明、中元、寒衣节等祭祀节日；避开父母生辰、忌日。

## 二、开业择吉详细规则

### 2.1 择日宜选

#### 一级吉日（首选）

- **黄道日**：青龙、明堂、金匮、天德、玉堂、司命值日。
- **建除吉神**：成日、开日为开业首选（寓意"开张成功"）。
- **吉神配合**：天德、月德、天德合、月德合、三合、五合、福生等吉神值日。
- **二十八宿**：角、氐、房、尾、箕、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿值日。

#### 二级吉日（次选）

- **建除神**：满日（满则丰盈，适合开业纳财）、定日（安定稳固）。
- **吉神**：天恩、母仓、阳德、普护等。
- **二十八宿**：参、井等。

#### 最佳神煞组合

1. **天月二德 + 三合 + 成日/开日 + 金匮/明堂**：至吉，财源广进，生意兴隆。
2. **天德/月德 + 福生 + 开日 + 青龙/司命**：大吉，开业顺利，福气盈门。
3. **天德合/月德合 + 三合 + 成日 + 黄道日**：吉，事业稳固，合作顺利。

### 2.2 择日忌避

#### 绝对禁忌

- **月破日、岁破日**：冲犯月令或太岁，开业大凶。
- **四离日、四绝日**：主分离、断绝，开业不久即闭。
- **四废日**：主衰败，开业后生意萧条。
- **黑道日**：玄武、白虎、天牢、勾陈、天刑、朱雀值日。

#### 强烈禁忌

- **建除凶神**：破日、闭日（闭日尤其忌开业）。
- **凶煞**：大耗、小耗、劫煞、灾煞、死气。
- **四穷日**：穷困之意，开业大忌。

### 2.3 行业五行与日辰匹配

不同行业五行属性不同，开业日辰应与之配合：

| 行业类别 | 五行属性 | 宜选日辰 | 忌选日辰 |
|----------|----------|----------|----------|
| 餐饮、美容、文化、教育 | 火 | 巳日、午日、寅日、卯日 | 亥日、子日 |
| 金融、珠宝、五金、机械 | 金 | 申日、酉日、辰日、戌日、丑日、未日 | 巳日、午日 |
| 物流、贸易、旅游、酒水 | 水 | 亥日、子日、申日、酉日 | 辰日、戌日、丑日、未日 |
| 农业、建筑、地产、家具 | 土 | 辰日、戌日、丑日、未日、巳日、午日 | 寅日、卯日 |
| 林业、医药、服装、出版 | 木 | 寅日、卯日、亥日、子日 | 申日、酉日 |

### 2.4 时辰选择

1. **开业仪式时辰**：首选辰时（7-9点，龙抬头之意）、巳时（9-11点，阳气上升）、午时（11-13点，金匮值日）。现代企业开业多选上午吉时，寓意"如日方升"。
2. **黄道时辰**：寅时（青龙）、卯时（明堂）、午时（金匮）、未时（天德）、酉时（玉堂）。
3. **针对不同行业**：金融业宜选辰时、酉时（金旺）；餐饮业宜选巳时、午时（火旺）；物流业宜选亥时、子时（水旺）。

### 2.5 开业方位建议

开业当日的方位选择与择日同样重要：

1. **财神方位**：当日财神所在方位为最佳开业朝向。财神方位根据日干确定：甲日东北、乙日正东、丙日东南、丁日正南、戊日东南、己日正南、庚日西南、辛日正西、壬日西北、癸日正北。
2. **喜神方位**：迎宾、接待的方位应朝向当日喜神方位。喜神方位根据日干确定：甲戊庚日东北、乙己日西北、丙日西南、丁日正南、辛日西南、壬日正南、癸日东南。
3. **开门方位**：店铺、公司大门朝向应避开当日噩神方位（噩神方位与岁破方位相同）。

## 三、婚嫁择吉的完整三级吉日体系

### 3.1 大吉日（一级）

婚嫁大吉日需同时满足以下至少四个条件：

1. **建除为成日或开日**：成日取"婚姻圆满"之意，开日取"开启新生活"之意。
2. **黄道日**：青龙、明堂、金匮、天德、玉堂、司命值日。
3. **至吉神或上吉神值日**：天德、月德、天德合、月德合、天喜等至少一位值日。
4. **二十八宿吉宿**：角、氐、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿值日。
5. **无彭祖百忌"亥不嫁娶"**：日辰不是亥日。
6. **时辰选择**：可选黄道吉时（寅时、卯时、午时、酉时等）。

**大吉日的神煞组合特征**：天月二德至少一位值日，天喜值日，三合或六合值日，无任何大凶煞。

### 3.2 吉日（二级）

婚嫁吉日至少满足以下条件之三：

1. **建除为定日、除日或建日**：定日安稳，除日迎新，建日开始。
2. **黄道日**：至少为黄道日。
3. **中吉神值日**：天喜、三合、六合、益后、续世等至少一位值日。
4. **二十八宿吉宿**：至少为吉宿值日。
5. **无彭祖百忌相关忌讳**：或虽有"亥不嫁娶"但有大吉神化解。

**吉日的神煞组合特征**：有天喜值日，或有天德但不完全满足大吉条件，有小凶煞但不影响大局。

### 3.3 中平日（三级）

婚嫁中平日满足以下条件：

1. **建除为平日、执日或满日**：平平稳稳，虽无大吉但也无大凶。
2. **黄道或黑道中偏吉者**：至少不是明显凶日。
3. **无大凶煞**：无月破、岁破、四废、四离、四绝等。
4. **无彭祖百忌"亥不嫁娶"**：若为亥日，则降为"不宜"。

**中平日的神煞组合特征**：无大吉神也无大凶煞，建除平平，黄道黑道平平。适合对吉日要求不高的简单婚礼。

### 3.4 不宜日

以下日辰为婚嫁不宜日：

1. 建除为破日、闭日、危日。
2. 黑道日且无吉神化解。
3. 有彭祖百忌"亥不嫁娶"且无天德月德化解。
4. 日辰冲新娘生肖或日柱。

## 四、婚嫁择吉的神煞组合详解

### 4.1 天德月德系列组合

**天德 + 月德（天月二德）**：至吉组合。天德为天之福德，月德为月之福德，二德同现，百福并集。《协纪辨方书》称："天月二德，百事大吉，无所禁忌。"婚嫁得此组合，婚姻得天时地利，夫妻恩爱，白头偕老。天月二德同时值日的情况极为罕见，每年仅寥寥数日，一旦出现，即为婚嫁首选。

**天德 + 天德合**：上吉组合。天德与天德合同现，天地和谐，婚姻稳固。虽不及天月二德，但亦是极佳的组合。

**月德 + 月德合**：上吉组合。月德与月德合同现，月之福泽加倍，婚姻得月之庇佑，夫妻和睦，家庭美满。

### 4.2 天喜系列组合

**天喜 + 六合**：上吉组合。天喜主婚嫁喜庆，六合主夫妻和谐，两神同现，婚姻喜庆且和谐，是婚嫁择吉中最理想的组合之一。

**天喜 + 三合**：上吉组合。天喜与三合同现，婚姻喜气洋洋，夫妻与家族和睦，社会关系融洽。

**天喜 + 天德/月德**：至吉组合。天喜与天德或月德同现，婚嫁得天地之喜，福泽深厚，子孙兴旺。

### 4.3 三合六合系列组合

**三合 + 六合同现**：上吉组合。三合主外合，六合主内合，内外和谐，婚姻稳固。三合六合同现，意味着夫妻关系既在内部和谐，也在外部（双方家族、社会关系）和谐。

**三合 + 益后 + 续世**：中吉组合。三合主和谐，益后主子孙有益，续世主家族延续。此组合特别适合注重传宗接代的婚嫁择吉。

### 4.4 组合效果等级

| 组合等级 | 组合内容 | 效果 | 婚嫁适用度 |
|----------|----------|------|-----------|
| 至吉 | 天月二德 + 天喜 + 六合/三合 | 婚姻美满，白头偕老，子孙兴旺 | ⭐⭐⭐⭐⭐ |
| 上吉 | 天德/月德 + 天喜 + 六合 | 婚姻幸福，夫妻和谐，家庭和睦 | ⭐⭐⭐⭐⭐ |
| 上吉 | 天德合/月德合 + 天喜 + 三合 | 婚姻稳固，家族兴旺，社会关系好 | ⭐⭐⭐⭐ |
| 中吉 | 天喜 + 六合 + 三合 | 婚姻喜庆，内外和谐 | ⭐⭐⭐⭐ |
| 中吉 | 天德 + 天喜 | 婚姻得福，喜庆圆满 | ⭐⭐⭐⭐ |
| 吉 | 天喜 + 六合 或 天喜 + 三合 | 婚姻和谐喜庆 | ⭐⭐⭐ |

## 五、婚嫁择吉的时辰选择方法

### 5.1 纳彩时辰选择

纳彩（提亲）为婚嫁六礼之首，时辰宜选：

- **辰时（7:00-9:00）**：龙抬头，提亲顺利，对方欣然接受。
- **巳时（9:00-11:00）**：阳气旺盛，沟通顺畅，双方满意。
- **午时（11:00-13:00）**：金匮值日，诚意满满，财礼丰厚。

纳彩宜避开酉时（"酉不会客"）、申时（白虎值日，易有冲突）。

### 5.2 迎亲时辰选择

迎亲（接新娘）为婚嫁中最热闹的环节，时辰宜选：

- **寅时（3:00-5:00）**：青龙值日，清晨出发，一路顺风。传统上迎亲多在寅时出发，取"寅不通光"之意，暗合"新娘不见日光"的旧俗。
- **卯时（5:00-7:00）**：明堂值日，日出东方，迎亲大吉。现代婚礼多选卯时出发，到新娘家时天已亮，既合古礼又合现代习惯。
- **辰时（7:00-9:00）**：龙抬头，气势磅礴，迎亲队伍浩浩荡荡。

迎亲宜避开申时（白虎值日，易有冲突）、酉时（日落西山，不吉）。

### 5.3 拜堂时辰选择

拜堂（结婚典礼）为婚嫁的核心环节，时辰宜选：

- **午时（11:00-13:00）**：金匮值日，至吉时辰。金匮为财富之神，此时拜堂，财运亨通，家业兴旺。传统上拜堂多选午时，取"午时三刻"阳气最盛之意。
- **巳时（9:00-11:00）**：阳气旺盛，宾客满堂，典礼隆重。
- **未时（13:00-15:00）**：天德值日，庄重典雅，礼仪周全。

### 5.4 入洞房时辰选择

入洞房（合卺）为婚嫁的收官环节，时辰宜选：

- **酉时（17:00-19:00）**：玉堂值日，良辰吉时，新人入洞房，夫妻恩爱。传统上入洞房多选酉时，取"酉"为"有"之谐音，寓意"有子有福"。
- **戌时（19:00-21:00）**：虽是黑道基础时辰，但具体日辰可能不同，需结合当日时辰黄道黑道判断。

### 5.5 时辰选择注意事项

1. **时辰不冲新娘生肖**：如新娘属鼠（子），避开午时（子午冲）。
2. **时辰不冲新郎生肖**：如新郎属马（午），避开子时（午子冲）。
3. **时辰宜合双方生肖**：如双方生肖为寅和亥（寅亥合），则选寅时或亥时更佳。
4. **以黄道时辰为优先**：无论何种仪式，优先选择黄道时辰。

## 六、婚嫁择吉与新人八字的配合原则

### 6.1 新娘命理优先原则

传统婚嫁择吉以新娘命理为优先，因"女命以夫家为归宿"。具体规则：

1. **日辰不冲新娘日柱**：择选婚嫁日辰的地支，严禁冲克新娘出生日的日柱地支。
2. **日辰不冲新娘生肖**：日辰地支严禁冲克新娘生肖地支。
3. **日辰宜合新娘日柱或生肖**：日辰地支与新娘日柱地支或生肖地支形成三合或六合为佳。
4. **大利月与小利月**：传统上，婚嫁择吉与新娘出生月份有关。每个新娘有自己的"大利月"（最佳婚嫁月份）和"小利月"（次佳婚嫁月份），"妨月"（不宜婚嫁月份）应避开。

### 6.2 新郎命理配合原则

新郎命理为次要考虑，主要规则：

1. **日辰不宜冲新郎日柱**：虽非绝对禁忌，但若能避开更佳。
2. **日辰宜合新郎生肖**：日辰地支与新郎生肖地支形成三合或六合为佳。

### 6.3 双方命理利益平衡

当双方命理出现冲突时（如日辰合新娘但冲新郎），处理原则：

1. 优先满足新娘命理（女命优先）。
2. 若日辰冲新郎，则尽量另选日期，避免一方受损。
3. 若无法找到同时满足双方的日辰，则满足新娘，但需通过时辰选择等方式弥补新郎方的不利。

### 7.2 行业五行与日辰五行生克详解

**金行业（金融、珠宝等）**：

- 最佳日辰：庚申日、辛酉日（金日比和，金气最旺）
- 次佳日辰：戊辰日、己丑日（土日生金，财源培育）
- 不宜日辰：丙午日、丁巳日（火日克金，财气受损）
- 推荐时辰：辰时（7-9点，土旺生金）、酉时（17-19点，金旺）

**木行业（文化、教育等）**：

- 最佳日辰：甲寅日、乙卯日（木日比和，木气旺盛）
- 次佳日辰：壬子日、癸亥日（水日生木，智慧生发）
- 不宜日辰：庚申日、辛酉日（金日克木，文运受阻）
- 推荐时辰：寅时（3-5点，木旺）、卯时（5-7点，木旺）

**水行业（物流、贸易等）**：

- 最佳日辰：壬子日、癸亥日（水日比和，水气流通）
- 次佳日辰：庚申日、辛酉日（金日生水，财源滚滚）
- 不宜日辰：戊辰日、己未日（土日克水，流通受阻）
- 推荐时辰：亥时（21-23点，水旺）、子时（23-1点，水旺）

**火行业（餐饮、传媒等）**：

- 最佳日辰：丙午日、丁巳日（火日比和，火气旺盛）
- 次佳日辰：甲寅日、乙卯日（木日生火，生意兴隆）
- 不宜日辰：壬子日、癸亥日（水日克火，客源减少）
- 推荐时辰：巳时（9-11点，火旺）、午时（11-13点，火旺）

**土行业（建筑、地产等）**：

- 最佳日辰：戊辰日、己丑日（土日比和，土气稳固）
- 次佳日辰：丙午日、丁巳日（火日生土，根基牢固）
- 不宜日辰：甲寅日、乙卯日（木日克土，根基动摇）
- 推荐时辰：辰时（7-9点，土旺）、未时（13-15点，土旺）

4. 开业当日的第一笔生意，宜从财神方位进入。

喜神方位主喜庆、人气，开业当日喜神方位为迎宾、接待的最佳方位：

1. 迎宾人员宜站在喜神方位迎客。
2. 开业剪彩时，剪彩嘉宾宜面向喜神方位。
3. 招待宾客的座位，宜安排在喜神方位。

### 8.3 开门方位与噩神方位避忌

开业当日，开门方位不仅要朝向吉方，还应避开噩神方位。噩神方位与岁破方位相同，每年不同。开业当日还应避开以下方位：

1. 当年三煞方位（申子辰年三煞在南方，亥卯未年三煞在西方，寅午戌年三煞在北方，巳酉丑年三煞在东方）。
2. 当年五黄煞方位（每年不同，需查当年流年飞星）。
3. 当年太岁方位（与当年地支对应）。

## 九、开业择吉的仪式时辰推荐

### 9.1 各行业推荐开业时辰

| 行业 | 推荐时辰 | 理由 |
|------|----------|------|
| 金融、银行 | 辰时（7-9点） | 辰为龙，龙抬头，气势磅礴；辰为土，土生金，财源培育 |
| 餐饮、饭店 | 巳时（9-11点） | 巳为火，餐饮属火，比和旺相；巳时阳气旺，宾客盈门 |
| 零售、百货 | 午时（11-13点） | 午时金匮值日，财神临门；午时人气最旺，开业大吉 |
| 文化、教育 | 卯时（5-7点） | 卯为木，教育属木，比和旺相；卯时日出，象征希望 |
| 物流、贸易 | 亥时（21-23点） | 亥为水，物流属水，比和旺相（但实际开业多选上午，此为参考） |
| 建筑、地产 | 辰时（7-9点） | 辰为土，建筑属土，比和旺相；辰时龙抬头，工程顺利 |
| 美容、美发 | 巳时（9-11点） | 巳为火，美容属火，比和旺相；巳时阳气旺，客源不断 |
| 珠宝、钟表 | 酉时（17-19点） | 酉为金，珠宝属金，比和旺相；酉时玉堂值日，高贵典雅 |

### 9.2 开业仪式时辰选择通用原则

1. **上午优先**：开业仪式宜选上午，寓意"如日方升"，事业蒸蒸日上。
2. **黄道时辰优先**：优先选择寅时（青龙）、卯时（明堂）、午时（金匮）、未时（天德）、酉时（玉堂）等黄道时辰。
3. **避开黑道时辰**：避开丑时（勾陈）、辰时（天刑）、巳时（朱雀）、申时（白虎）、戌时（天牢）、亥时（玄武）。
4. **行业五行匹配**：根据行业五行属性选择对应的时辰。
5. **现代实用考虑**：现代开业仪式多选辰时（7-9点）或巳时（9-11点），既符合传统择吉，又方便宾客参加。

## 十、择日通用原则

1. **先避凶，后择吉**：首先排除所有大凶之日，再在剩余日子中寻找最佳吉日。
2. **综合判断**：单一吉凶因素不足以决定，需综合黄道黑道、建除十二神、吉神凶煞、二十八宿等判断。
3. **事项优先**：根据具体事项关注对应的吉神凶煞。婚嫁首重天喜、天德、六合；开业首重天德、三合、福生。
4. **个人命理**：理想情况下，应结合个人八字命理进行择日，避开与个人生肖、日柱相冲的日辰。
5. **行业匹配**：开业择吉需结合行业五行属性，选择与行业五行相生或比和的日辰，以达到最佳效果。
6. **方位配合**：择日与方位配合，方能达到"天时地利"的效果。开业择吉不仅要选好日子，还要选好方位和时辰。
