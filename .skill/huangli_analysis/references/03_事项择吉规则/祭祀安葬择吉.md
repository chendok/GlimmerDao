# 祭祀安葬择吉

## 一、祭祀择吉详细规则

### 1.1 祭祀择吉概述

祭祀是择日学中极为重要的事项类别，其择吉规则严谨而细致。祭祀择吉的核心原则是"神享其祀，人受其福"，即所选日辰应便于神灵祖先享用祭品，从而使祭祀者获得福报。在传统择日体系中，祭祀被视为人与天地鬼神沟通的桥梁，择吉不当可能导致"神不享祭"，祭祀效果大打折扣。

### 1.2 祭祖择吉

#### 宜选日辰

祭祖择吉以慎终追远、敬祖睦宗为核心诉求，宜选以下日辰：

1. **建除吉神**：成日（圆满成就，祖灵安享）、定日（安定长久，祖荫绵延）、开日（开畅通达，孝思可达）。
2. **黄道吉日**：青龙、明堂、金匮、天德、玉堂、司命值日。其中天德日（黄道六神之天德）最为契合祭祀的庄重氛围。
3. **吉神配合**：天德、月德、天恩、母仓、福生、圣心等吉神。天德主天之恩德，月德主月之福泽，祭祖得此二神加持，孝心可达先灵，福泽可荫后人。
4. **二十八宿**：角、氐、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿。其中角宿（木蛟，青龙之角）尤利祭祀，能通天地之气。
5. **特殊吉日**：清明日（正日）、冬至日、中元日（农历七月十五）、寒衣节（农历十月初一）为传统祭祀节日，当日祭祖最为应时。但需注意，中元日（鬼节）祭祀虽应时，但当日不宜进行其他喜庆事项。

#### 忌选日辰

1. **绝对禁忌**：
   - 月破日、岁破日：冲犯太岁月令，祭祀无效且可能招来不利。
   - 四废日：四时衰废，祭祖不敬先灵。
   - 寅日（"寅不祭祀，神鬼不尝"）：阳气过盛，鬼神不享。
   - 辰日（"辰不哭泣，必主重丧"）：祭祖多含哀思，辰日哭泣有"重丧"之忌。

2. **强烈禁忌**：
   - 建除凶神：破日（破败之意，于祭祖不敬）、闭日（闭塞不通，孝思不达）。
   - 黑道日：玄武（阴私）、白虎（血光）、天牢（困厄）尤忌。
   - 凶煞：灾煞、劫煞、死气、往亡。

3. **一般禁忌**：杨公忌日、与亡者忌日太近的日子、与家主生肖相冲之日。

#### 时辰选择

祭祖时辰以午时（11:00-13:00）为最佳，此时阳气最盛，可达幽冥。其次为辰时（7:00-9:00）、巳时（9:00-11:00）。传统上祭祖忌在傍晚以后进行，因阴气渐盛，于祭祀者不利。具体时辰选择：

- **午时（金匮值日）**：最佳时辰，阳气充沛，金匮为财富之神，祭祖可得祖先庇佑财运。
- **辰时（青龙值日，但需注意辰时为黑道基础时辰）**：次选，辰为龙，有升腾之意，孝思可上达。
- **避开**：子时（深夜阴气重）、酉时（日落西山，象征衰败）。

#### 方位讲究

1. **祭祖朝向**：面向祖先墓地方位或灵位方位。若墓地在东方，则面向东方焚香祷告。
2. **喜神方位**：祭祖时，祭祀者立于当日喜神方位，可增加福气。
3. **财神方位**：摆放祭品时，供桌朝向当日财神方位，寓意祖先赐福赐财。
4. **避开噩神方位**：不可面向当日噩神方位进行祭祀。

### 1.3 祈福择吉

祈福择吉用于祈求神灵赐福，包括求子、求寿、求财、求平安等。与祭祖不同，祈福的对象是天神地祇，择吉规则更为严格。

#### 宜选日辰

1. **建除吉神**：成日（所求圆满）、开日（开启福运）、定日（福运稳固）。
2. **黄道吉日**：青龙、明堂、金匮、天德、玉堂、司命值日。其中玉堂日（高贵庄严）最宜祈福。
3. **吉神配合**：天德、月德、天德合、月德合、天赦（天赦日祈福，百求百应）、福生、天恩、普护。天赦日是祈福的至吉之日，天赦日每年仅有四至五日，极为珍贵。
4. **二十八宿**：角、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿。
5. **特殊吉日**：正月初一（元日）、正月十五（上元节）、六月初一（半年节）、八月初一（天医节）、冬至等。

#### 忌选日辰

1. **绝对禁忌**：
   - 月破日、岁破日：冲犯神灵，祈福不灵。
   - 四离日、四绝日：阴阳分离断绝，祈福无效。
   - 寅日（"寅不祭祀"）：神灵不享。
   - 黑道日：尤忌玄武、白虎、天牢。

2. **强烈禁忌**：
   - 建除凶神：破日、闭日。
   - 凶煞：灾煞、劫煞、死气、伏断。

#### 时辰选择

祈福宜选上午吉时：
- **辰时（7:00-9:00）**：龙抬头，阳气上升时。
- **巳时（9:00-11:00）**：阳气正旺时。
- **午时（11:00-13:00）**：金匮值日，最佳祈福时辰。

#### 方位讲究

祈福时应面向神灵所在方位。如求观音，面向南方（观音道场在南海普陀）；求财神，面向当日财神方位；求福神，面向当日喜神方位。

### 1.4 酬神还愿择吉

酬神还愿是答谢神灵庇佑的仪式，其择吉比祈福更为特殊。

#### 宜选日辰

1. **建除吉神**：成日（还愿圆满）、定日（谢意坚定）。
2. **黄道吉日**：明堂、玉堂、金匮值日。
3. **吉神配合**：天德、月德、天恩、福生、圣心。
4. **特殊要求**：还愿日辰宜与当初许愿日辰的天干相同（如当初许愿在甲日，还愿也宜选甲日），寓意"有始有终"。

#### 忌选日辰

- 月破日、岁破日、四废日、四离日、四绝日。
- 寅日（"寅不祭祀"）。
- 黑道日。

#### 时辰选择

还愿时辰宜选午时（金匮值日），与许愿时辰一致为佳。

### 1.5 其他祭祀类型择吉

| 祭祀类型 | 宜选日辰 | 特殊注意 |
|----------|----------|----------|
| 祭灶 | 丙日、丁日（火旺，灶神喜火） | 忌壬日、癸日（水克火） |
| 祭土地 | 戊日、己日（土旺，土地神喜土） | 宜选辰时、未时（土旺时辰） |
| 祭财神 | 庚日、辛日（金旺，财神喜金） | 忌丙日、丁日（火克金） |
| 祭文昌 | 甲日、乙日（木旺，文昌属木） | 宜选寅时、卯时（木旺时辰） |
| 祭太岁 | 避开岁破日，选天德月德日 | 忌与太岁相冲之日 |

## 二、安葬择吉详细规则

### 2.1 安葬择吉概述

安葬择吉是择日学中最为严谨的事项之一，素有"生死大事，择吉为首"之说。安葬择吉不仅要考虑日辰的吉凶，还要结合亡者的生辰八字、去世时辰、墓地坐向等多重因素，是择日学中最为综合的应用场景。《协纪辨方书》将安葬列为"慎终"之首，其择吉规则体系完整、层次分明。

### 2.2 宜选日辰

#### 一级吉日（首选）

1. **建除吉神**：成日（安葬圆满，亡者安息，后人得福）、定日（安定稳固，亡者归位，家宅安宁）。成日、定日为安葬首选建除神，其中成日尤佳，取"死者安葬，事成圆满"之意。

2. **鸣吠日**：鸣吠日是安葬择吉中的特殊吉日，专为安葬而设，其吉力远高于普通吉日。鸣吠日的判定口诀为："庚午、壬申、癸酉、壬午、甲申、乙酉、庚寅、丙申、丁酉、壬寅、丙午、己酉、庚申、辛酉。"共十四日。鸣吠日安葬，亡者入土安宁，后人得福。其中"鸣吠对日"（丙子、丁丑、丙寅、丁卯、丙申、丁酉、丙午、丁未）专用于破土开穴。

3. **黄道吉日**：青龙、明堂、金匮、天德、玉堂、司命值日。其中天德日（黄道六神之天德）最为适合安葬，取其"天德覆护"之意。

4. **吉神配合**：天德、月德、天德合、月德合、天恩、母仓（入土为安，母仓为土地之母）、普护等吉神值日。天德月德加持安葬，亡者得天之德，后人得月之福。

5. **二十八宿**：角、氐、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿。其中室宿（火猪，主安葬）和壁宿（水貐，主归宿）尤为适合。

#### 二级吉日（次选）

1. **建除神**：开日（开启冥途，亡者往生）、除日（除去旧业，亡者解脱）。
2. **吉神**：天赦、圣心、敬安、阳德等。
3. **二十八宿**：参、井等。

#### 最佳神煞组合

1. **天月二德 + 成日 + 鸣吠日 + 黄道日 + 母仓**：至吉组合，安葬后亡者安宁，家宅兴旺，子孙昌盛。
2. **天德/月德 + 定日 + 鸣吠日 + 明堂/玉堂**：大吉，安葬稳妥，亡者得其所，后人得福荫。
3. **天德合/月德合 + 成日 + 鸣吠日 + 青龙/司命**：吉，安葬顺利，亡者安息。

### 2.3 忌选日辰

#### 绝对禁忌（不可用）

1. **重丧日**：重丧日是安葬择吉中的大忌，意为"丧事重复发生"。重丧日判定口诀："正七连甲庚，二八乙辛当，三九六十二，戊己是重丧，四十丙壬方，五十一丁癸。"通俗解释：正月、七月，甲日、庚日；二月、八月，乙日、辛日；三月、六月、九月、十二月，戊日、己日；四月、十月，丙日、壬日；五月、十一月，丁日、癸日。重丧日安葬，恐有家人再次去世之应，为安葬择吉中最为忌讳之日。

2. **三丧日**：三丧日同样可能导致"接二连三"的丧事，其判定为：春辰日、夏未日、秋戌日、冬丑日。三丧日安葬，大凶。

3. **天火日**：天火日安葬，恐招火灾，对墓地和家宅均不利。天火日判定：正月巳日，二月子日，三月未日，四月寅日，五月酉日，六月辰日，七月亥日，八月午日，九月丑日，十月申日，十一月卯日，十二月戌日。

4. **月破日、岁破日**：冲犯太岁月令，安葬大凶，主家宅不安，亡者不宁。

5. **四废日、四离日、四绝日**：衰败分离断绝，安葬后家运衰败，后人离散。

6. **黑道日**：玄武、白虎、天牢、勾陈值日，尤忌安葬。白虎主血光，天牢主困厄，于安葬极不吉利。

7. **辰日**（"辰不哭泣，必主重丧"）：辰日安葬多含哭泣，有"重丧"之忌。

#### 强烈禁忌（尽量避开）

1. **建除凶神**：破日（破败，亡者不安）、闭日（闭塞，亡者冥途阻塞）、危日（危亡，于安葬不吉）。
2. **凶煞**：灾煞、劫煞、死气、往亡（往亡日安葬，亡者魂魄迷茫，不知归处）。
3. **二十八宿凶宿**：亢、心、牛、女、虚、危、昴、觜、鬼、柳、星、翼，安葬均应避开。

#### 一般禁忌

1. **杨公忌日**：十三日，忌安葬。
2. **土王用事期间**：立春、立夏、立秋、立冬前十八日，忌动土安葬。
3. **与亡者生肖相冲之日**：日支与亡者生肖地支相冲之日。
4. **与家主生肖相冲之日**：日支与家主生肖地支相冲之日。

### 2.4 亡者命理与日辰配合

安葬择吉不仅看日辰，还需结合亡者的生辰八字，主要配合原则如下：

1. **日辰不宜冲亡者日柱**：亡者出生日的日柱地支与安葬日辰地支不宜相冲。如亡者生于甲子日，安葬日辰不宜选午日（子午相冲）。
2. **日辰五行宜生亡者日柱五行**：亡者日柱天干五行宜被安葬日辰五行所生。如亡者日柱天干为甲木，安葬日辰天干为壬癸水（水生木）为佳。
3. **日辰纳音宜与亡者纳音相生**：亡者生年纳音与安葬日辰纳音不宜相克。如亡者甲子年生（海中金），安葬日辰不宜选丙寅日（炉中火，火克金）。
4. **亡者去世时辰不宜与安葬时辰相冲**：亡者去世的时辰地支与安葬时辰地支不宜相冲。

### 2.5 墓穴方位与日辰五行

墓穴的坐向与安葬日辰的五行配合是安葬择吉中另一重要维度：

1. **坐向与日辰五行相生**：墓穴坐向五行宜被日辰五行所生。如墓穴坐北朝南（坐子向午，子属水），安葬日辰宜选金日（金生水）或水日（比和）。
2. **坐向不冲日辰地支**：墓穴坐向地支不宜与日辰地支相冲。如墓穴坐子（北方），安葬日辰不宜选午日。
3. **坐向合理搭配**：墓穴坐向宜与择日时的吉神方位配合。如安葬当日天德在东方，则墓穴坐东朝西为最佳。
4. **避开三煞方位**：墓穴坐向应避开当年三煞方位。如当年三煞在南方，则墓穴不宜坐南朝北。

### 2.6 时辰选择

安葬时辰选择极为严格：

1. **黄道时辰**：子时（司命）、寅时（青龙）、卯时（明堂）、午时（金匮）、未时（天德）、酉时（玉堂）为黄道吉时。其中卯时（日出之时，象征新生的开始）和未时（天德值日，天德覆护）为安葬最佳时辰。
2. **避开黑道时辰**：丑时（勾陈）、辰时（天刑）、巳时（朱雀）、申时（白虎）、戌时（天牢）、亥时（玄武）。
3. **安葬时辰与亡者生肖配合**：避开与亡者生肖相冲的时辰。
4. **传统安葬时辰**：传统上安葬多选在上午，以卯时（5:00-7:00）和辰时（7:00-9:00）最为常见。取"日出东方，亡者往生"之意。

### 2.7 安葬择吉综合流程

1. 确定亡者生辰八字，提取日柱、年柱关键信息。
2. 排除所有大凶日辰（重丧日、三丧日、天火日、月破日、岁破日、四废日、四离日、四绝日）。
3. 在剩余日辰中，优先寻找鸣吠日。
4. 在鸣吠日中，筛选建除为成日或定日的日辰。
5. 进一步筛选黄道日、吉神值日。
6. 结合墓穴坐向，选择五行相生的日辰。
7. 最后选择最佳时辰，完成安葬择吉。

> 安葬择吉涉及生死大事，传统上极为重视。以上规则为通用择吉指南，具体安葬择吉建议结合亡者及家属的详细命理信息，由专业择日师进行综合判断。
