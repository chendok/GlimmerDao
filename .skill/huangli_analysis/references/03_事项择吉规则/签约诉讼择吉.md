# 签约诉讼择吉

## 一、签约/交易择吉详细规则

### 1.1 签约择吉概述

签约、交易、立券等契约类事项，在择日学中属于"文书契约"类事项。此类事项的择吉核心在于"契约稳固、合作长久"，因此特别看重日辰的稳定性和诚信度。《协纪辨方书》将签约交易列为"民用要事"之一，其择吉规则体系完善。

### 1.2 宜选日辰

#### 一级吉日（首选）

1. **建除吉神**：成日（签约成功，交易圆满）、定日（契约稳定，合作长久）、执日（执掌契约，掌握主动）。此三种建除神为签约交易首选，其中成日最为理想，取"事成"之意；定日次之，取"稳定"之意；执日再次，取"掌控"之意。

2. **黄道吉日**：青龙、明堂、金匮、天德、玉堂、司命值日。其中明堂日（光明正大，交易透明）和金匮日（金匮为财富之神，利于交易求财）最为契合签约交易。

3. **吉神配合**：天德、月德、天德合、月德合、三合、六合、五合、天恩、福生等吉神。三合、六合主合作和谐，是签约交易的特有吉神，其重要性甚至超过天德月德（因为签约的核心是合作，而三合六合正主合作）。

4. **二十八宿**：房、尾、箕、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿。其中房宿（日兔，主文书契约）和壁宿（水貐，主文书归宿）尤利签约。

#### 二级吉日（次选）

1. **建除神**：开日（开启新合作）、满日（合约丰满，内容充实）。
2. **吉神**：天赦、母仓、阳德、圣心等。
3. **二十八宿**：参、井等。

#### 最佳神煞组合

1. **天月二德 + 三合/六合 + 成日 + 金匮/明堂**：至吉，签约顺利，合作长久，财源广进。
2. **天德/月德 + 六合 + 定日 + 青龙/司命**：大吉，合作稳固，诚信可靠。
3. **天德合/月德合 + 三合 + 执日 + 黄道日**：吉，签约顺利，双方满意。

### 1.3 忌选日辰

#### 绝对禁忌

1. **月破日、岁破日**：签约大凶，契约破裂，合作失败。
2. **四离日、四绝日**：分离断绝，合作无法长久。
3. **四废日**：衰败之日，签约后合作衰败。
4. **空亡日**：签约交易最忌空亡日，因"空亡"意味着契约落空，合作无果。空亡日判定见本知识库"干支纪日与节气"篇。
5. **黑道日**：朱雀（口舌纠纷）、玄武（欺诈暗昧）、勾陈（纠缠不清）、天刑（官司诉讼）尤忌签约。签约最忌朱雀日，因朱雀主口舌是非，签约后易发生合同纠纷。

#### 强烈禁忌

1. **建除凶神**：破日（破败，签约不成）、闭日（闭塞，合作不通）。
2. **凶煞**：劫煞（遭劫受损）、大耗（耗费资财）、小耗（小额损失）、灾煞。
3. **二十八宿凶宿**：亢、心、牛、女、虚、危、昴、觜、鬼、柳、星、翼。

### 1.4 文书星与契约星的运用

在择日学中，签约交易有专门的"文书星"和"契约星"概念：

1. **文书星**：文书星主文书契约的顺利签署。文书星所在日辰，签约顺利，条款清晰，双方满意。文书星可根据日干推算，口诀为："甲日文书在巳，乙日文书在午，丙日文书在申，丁日文书在酉，戊日文书在亥，己日文书在子，庚日文书在寅，辛日文书在卯，壬日文书在巳，癸日文书在午。"

2. **契约星**：契约星主契约的效力和长久性。契约星所在日辰，契约效力强，合作长久。契约星可根据月令推算，口诀为："正七在寅，二八在申，三九在巳，四十在亥，五十一在卯，六十二在酉。"

3. **文书星与契约星同时值日**：文书星与契约星同时出现在同一日辰，为签约交易的至吉之日，契约效力强大，合作长久稳固。

### 1.5 推荐时辰

签约交易宜选上午吉时，因"一日之计在于晨"，早晨签约寓意合作方兴未艾：

- **辰时（7:00-9:00）**：龙抬头，气势正旺，适合大型签约。
- **巳时（9:00-11:00）**：阳气旺盛，思路清晰，适合条款复杂的签约。
- **午时（11:00-13:00）**：金匮值日，财运亨通，适合交易类签约。
- **未时（13:00-15:00）**：天德值日，贵人相助，适合合作类签约。

签约宜避开申时（白虎值日，易有冲突）、戌时（天牢值日，易有圈套）、亥时（玄武值日，易有欺诈）。

### 1.6 签约择吉综合流程

1. 排除所有大凶日辰（月破、岁破、四废、四离、四绝、空亡、黑道日）。
2. 在剩余日辰中，优先选择建除为成日、定日、执日之日。
3. 进一步筛选黄道日，优先明堂、金匮值日。
4. 检查三合、六合等吉神是否值日。
5. 检查文书星、契约星是否值日。
6. 选择最佳时辰，完成签约择吉。

## 二、诉讼择吉详细规则

### 2.1 诉讼择吉概述

诉讼择吉在传统择日学中属于"词讼"类事项，其择吉核心在于"理直气壮、胜诉有望"。诉讼择吉与签约择吉不同，签约看重稳定和谐，诉讼则看重清明果断。

### 2.2 宜选日辰

#### 一级吉日

1. **建除吉神**：执日（执掌主动，占据优势）、平日（公平公正，裁决公允）。执日和平日为诉讼首选建除神。执日取"执掌案件"之意，平日取"公平裁决"之意。

2. **黄道吉日**：青龙、明堂、玉堂、司命值日。其中玉堂日（高贵庄严）最宜诉讼，因诉讼需在庄严的法庭中进行。

3. **吉神配合**：天德、月德、天德合、月德合、阳德、天恩。天德月德加持诉讼，可得天理昭彰，公道自现。

4. **二十八宿**：角、氐、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿。

#### 最佳神煞组合

1. **天月二德 + 执日 + 玉堂/明堂**：至吉，诉讼有理有据，裁决公正。
2. **天德/月德 + 平日 + 青龙/司命**：大吉，公平公正，胜诉有望。
3. **阳德 + 执日 + 黄道日**：吉，占据主动，诉讼顺利。

### 2.3 忌选日辰

#### 绝对禁忌

1. **月破日、岁破日**：诉讼大凶，理屈词穷，败诉。
2. **四废日、四离日、四绝日**：衰败分离，诉讼无功。
3. **癸日**（"癸不词讼，理弱敌强"）：癸日诉讼，道理不明，处于弱势。此为诉讼择吉中最为关键的彭祖百忌。
4. **黑道日**：天刑（天刑值日，易遭刑罚）、天牢（天牢值日，易有牢狱之灾）、朱雀（口舌纠纷，诉讼过程曲折）、玄武（暗昧不明，证据不足）尤忌诉讼。

#### 强烈禁忌

1. **建除凶神**：破日、闭日（闭日诉讼，有理难伸）。
2. **凶煞**：劫煞、灾煞、死气。
3. **二十八宿凶宿**：亢、心、牛、女、虚、危、昴、觜、鬼、柳、星、翼。

### 2.4 官星与口舌星的运用

1. **官星**：官星主官方、官府、法官。官星所在日辰，诉讼得官方重视，公正裁决。官星根据日干推算，口诀为："甲日官星在酉，乙日官星在申，丙日官星在子，丁日官星在亥，戊日官星在卯，己日官星在寅，庚日官星在午，辛日官星在巳，壬日官星在未，癸日官星在辰戌丑未。"

2. **口舌星**：口舌星主口舌是非、争辩。口舌星所在日辰，诉讼过程中易有口舌之争，辩论激烈。口舌星需避开，但若己方口才出众，亦可利用口舌星之力。

3. **官星与口舌星的关系**：官星值日而口舌星不现，为最佳诉讼日辰；官星与口舌星同现，诉讼过程可能激烈但结果尚可；口舌星值日而官星不现，诉讼过程纷乱，结果难料。

### 2.5 时辰选择

诉讼时辰宜选上午吉时，因"朝阳初升，理直气壮"：

- **辰时（7:00-9:00）**：青龙值日（部分日辰），适合出庭。
- **巳时（9:00-11:00）**：阳气旺盛，适合辩论。
- **午时（11:00-13:00）**：金匮值日，财运相关诉讼尤利。

诉讼宜避开申时（白虎值日，对方势强）、戌时（天牢值日，恐有不利裁决）。

## 三、求医择吉详细规则

### 3.1 求医择吉概述

求医择吉在传统择日学中属于"医药"类事项，其择吉核心在于"药到病除、早日康复"。《玉匣记》中记载了详细的求医择吉规则，强调"择吉求医，事半功倍"。

### 3.2 宜选日辰

#### 一级吉日

1. **建除吉神**：除日（除病去疾，最为契合求医）、成日（治疗成功，康复圆满）、开日（开窍通络，病情好转）。除日为求医首选建除神，因"除"有"去除病痛"之意，与求医的核心诉求完美契合。

2. **天医日**：天医日是求医择吉中的特殊吉日，专为医药而设。天医日判定口诀："正月天医在卯，二月在亥，三月在丑，四月在未，五月在巳，六月在卯，七月在亥，八月在丑，九月在未，十月在巳，十一月在卯，十二月在亥。"天医日求医，得天之医药星护佑，治疗效果显著。

3. **黄道吉日**：青龙、明堂、金匮、天德、玉堂、司命值日。其中天德日（黄道六神之天德）最为适合求医，取其"天德护佑，病痛消除"之意。

4. **吉神配合**：天德、月德、天德合、月德合、天恩、福生、普护。天月二德加持求医，可得天地福泽，早日康复。

5. **二十八宿**：角、氐、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸等吉宿。

#### 最佳神煞组合

1. **天月二德 + 除日 + 天医日 + 黄道日**：至吉，求医顺利，药到病除。
2. **天德/月德 + 成日 + 天医日 + 明堂/玉堂**：大吉，治疗效果显著，康复迅速。
3. **天德合/月德合 + 除日 + 青龙/司命**：吉，求医顺利，病情好转。

### 3.3 忌选日辰

#### 绝对禁忌

1. **月破日、岁破日**：求医大凶，病情加重。
2. **四废日、四离日、四绝日**：衰败分离，求医无效。
3. **死神日**：死神日是求医择吉中的大忌。死神日判定："正月在巳，二月在子，三月在未，四月在寅，五月在酉，六月在辰，七月在亥，八月在午，九月在丑，十月在申，十一月在卯，十二月在戌。"死神日求医，病情可能加重，甚至危及生命。
4. **未日**（"未不服药，毒气入肠"）：未日服药，药效不达，甚至产生副作用。此为求医择吉中最为关键的彭祖百忌。
5. **黑道日**：白虎（血光之灾）、天牢（困厄病榻）尤忌求医。

#### 强烈禁忌

1. **建除凶神**：破日、闭日、危日（危日求医，病情危重）。
2. **凶煞**：灾煞、劫煞、死气。
3. **二十八宿凶宿**：亢、心、牛、女、虚、危、昴、觜、鬼、柳、星、翼。

### 3.4 时辰选择

求医宜选上午吉时：

- **辰时（7:00-9:00）**：阳气上升，适合问诊。
- **巳时（9:00-11:00）**：阳气旺盛，适合检査治疗。
- **午时（11:00-13:00）**：金匮值日，适合手术类治疗。

求医宜避开申时（白虎值日，手术风险高）、亥时（玄武值日，病情不明）。

> 求医择吉仅为传统文化参考，不可替代专业医疗行为。紧急病情应立即就医，不应因择吉而延误治疗。

## 四、其他常见事项择吉简要规则

| 宜 | 忌 |
|----|----|
| 成日、开日、定日、执日 | 破日、闭日、土王用事日 |
| 青龙、明堂、金匮、天德、玉堂、司命 | 白虎、天牢、玄武 |
| 天德、月德、母仓、普护 | 天火日、岁破日 |
| 角、氐、房、尾、斗、室、壁、奎、娄、胃、毕、张、轸 | 亢、心、牛、女、虚、危、昴、觜、鬼、柳、星、翼 |

装修时辰宜选辰时（龙抬头，开工大吉），动土时辰宜选午时。装修方位应避开当年三煞方位。

### 4.2 安床择吉

| 宜 | 忌 |
|----|----|
| 成日、定日、开日 | 破日、闭日、申日（"申不安床，鬼祟入房"） |
| 青龙、明堂、金匮、天德、玉堂、司命 | 白虎、玄武、天牢 |
| 天德、月德、天恩、福生、益后、续世 | 死气、劫煞、灾煞 |

安床时辰宜选辰时（龙抬头，床上吉祥）、酉时（玉堂值日，床第安宁）。安床方位宜配合家主命理喜用方位。

### 4.3 入学择吉

| 宜 | 忌 |
|----|----|

| 青龙、明堂、玉堂、司命 | 玄武、天牢 |
| 文昌星值日、天德、月德 | 四废日、四离日 |

入学时辰宜选辰时（龙抬头，学业有成）、巳时（阳气旺盛，思维清晰）。开学方位宜朝向当日文昌方位。
