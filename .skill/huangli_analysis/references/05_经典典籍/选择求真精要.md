# 选择求真精要

## 一、《选择求真》概述

### 1.1 成书背景

《选择求真》为清代姚承舆所撰，是清代择日学的重要著作。清代是择日学发展的重要时期，一方面《协纪辨方书》的编纂确立了官方理论体系，另一方面民间择日实践也需要更加贴近实操的专业指南。姚承舆有感于当时择日之书"或失之太繁，或失之太简"，遂以《协纪辨方书》为理论基础，结合自身实践经验，撰成此书，旨在为择日从业者提供一部既不失理论严谨、又便于实际操作的择日指南。

### 1.2 学术地位

《选择求真》在择日学典籍中占据独特的中间地位，介于《协纪辨方书》（理论体系）和《玉匣记》（民间手册）之间，是一部专业实操指南。其学术地位体现在：

1. **承上启下**：上承《协纪辨方书》的理论框架，下启民间择日的实际应用，是理论转化为实践的桥梁。
2. **实操性强**：以实际择日操作为核心，提供大量案例，是专业择日师案头必备的参考书。
3. **简明精要**：在保持理论准确性的前提下，简化了部分繁琐的理论推导，更便于学习掌握。

## 二、核心内容体系

### 2.1 正宗择日法

《选择求真》以干支五行、建除十二神为基础，结合神煞体系，建立了完整的正宗择日方法。其核心要点包括：

1. **干支五行生克**：以日辰干支的五行属性为核心，分析其与年月时柱的生克关系，强调日柱与月令的协调。
2. **建除十二神运用**：系统阐述建、除、满、平、定、执、破、危、成、收、开、闭十二神的吉凶属性及适用事项，强调"以事配神"而非"以神定事"。
3. **神煞综合判断**：将年神、月神、日神、时神分层次综合考量，避免单一神煞决定吉凶的片面做法。

### 2.2 各事择日细则

《选择求真》对各类事项给出了详细的择日规则，主要包括：

1. **婚嫁择日**：需避开月破、岁破、四离四绝等大凶之日；宜取天德、月德、三合、六合之日；女方生年与日辰不宜相冲。
2. **安葬择日**：需避开重丧、三丧、月忌等凶日；宜取鸣吠、鸣吠对日；强调与亡者生年、祭主生年的配合。
3. **开市择日**：宜取成日、开日、满日，取"成就、开辟、圆满"之意；忌破日、闭日。
4. **动土择日**：需避开太岁方、三煞方；日辰与坐山不宜相冲；宜取天赦、天愿等吉日。

### 2.3 神煞取舍原则

《选择求真》对多神煞冲突时的取舍提出了明确原则：

1. **大吉压小凶**：当大吉之神（如天德、月德）与一般凶煞同日出现时，吉神可化解凶煞，仍可取用。
2. **天德月德可解诸煞**：天德、月德为最高级别吉神，所值之日百事皆宜，可化解多数凶煞。
3. **大凶不可犯**：月破、岁破、四离、四绝等大凶煞不可化解，必须避开。
4. **以事为纲**：同一日辰对不同事项的吉凶不同，需根据具体事项判断取舍。

### 2.4 真太阳时校正

《选择求真》特别强调择日需用真太阳时，而非钟表时间（平太阳时）。真太阳时是根据当地经度和时差校正后的实际太阳位置时间。书中指出，择日所用的时辰关乎神煞的判断，若时辰不准，则吉凶判断全盘皆错。真太阳时的校正需考虑：

1. **经度校正**：以当地经度与标准时区中央经线的差值进行校正，每差1度约4分钟。
2. **均时差校正**：根据地球椭圆轨道和自转轴倾角造成的均时差进行校正。

## 三、与《协纪辨方书》的对比

| 对比维度 | 《协纪辨方书》 | 《选择求真》 |
|----------|---------------|-------------|
| 理论深度 | 极高，理论系统完整 | 中高，注重实用 |
| 实用性 | 中等，偏重理论 | 极高，偏重实操 |
| 案例数量 | 较少 | 丰富，便于参考 |
| 入门难度 | 高，需深厚功底 | 中等，适合入门进阶 |
| 推导过程 | 详细，体系严密 | 简化，直指结论 |

**互补关系**：《选择求真》与《协纪辨方书》的理论框架一致，但前者更注重实操，提供大量案例便于学习参考，并简化了部分繁琐的理论推导。可以说《协纪辨方书》是"学的教材"，《选择求真》是"做的指南"。

## 四、商用价值

《选择求真》在现代商用场景中具有以下价值：

1. **专业择日师实操参考**：其详细的各事择日细则和丰富案例，是专业择日服务的核心参考。
2. **择日算法开发的规则依据**：其神煞取舍原则、真太阳时校正等内容，可作为择日算法开发的规则依据。
3. **择日培训教材**：简明的表述和丰富的案例，使其适合作为择日学入门进阶的培训教材。

## 五、引用说明

本知识库在择吉实操中以《选择求真》为主要实操参考，其理论与《协纪辨方书》保持一致，但更便于转化为可执行的择日规则。在涉及具体事项的择日细则和神煞取舍时，优先参考《选择求真》的方法和案例。
