# 择吉综合方法论

## 一、六大维度综合运用框架

### 1.1 择吉维度总览

传统择日学包含六大核心判断维度，在择吉实践中需要综合运用。六大维度按重要性排序如下：

| 优先级 | 维度名称 | 权重 | 核心作用 | 主要参考依据 |
|--------|----------|------|----------|-------------|
| 第1级 | 建除十二神 | 25% | 确定日辰基本吉凶框架 | 月令地支、日辰地支 |
| 第2级 | 黄道黑道 | 20% | 判断日辰的天道吉凶 | 日辰地支、十二天神循环 |
| 第3级 | 吉神凶煞 | 25% | 判定日辰的加持或破坏程度 | 年、月、日、时干支 |
| 第4级 | 二十八宿 | 10% | 辅助判断日辰气质 | 二十八宿值日周期 |
| 第5级 | 彭祖百忌 | 10% | 特定事项的具体忌讳 | 日辰干支 |
| 第6级 | 时辰吉凶 | 10% | 确定最佳行动时间窗口 | 时辰地支、日辰配合 |

**权重说明**：建除十二神和吉神凶煞权重最高（各25%），因为建除十二神为日辰吉凶的"骨架"，吉神凶煞为"血肉"。黄道黑道（20%）为"天道意志"，二十八宿（10%）、彭祖百忌（10%）、时辰吉凶（10%）为辅助维度。

### 1.2 综合运用方法论

综合运用六大维度的核心方法论为"五步择吉法"：

**第一步：建除定框架**

以建除十二神为纲，首先确定日辰的基本吉凶框架。建除十二神分为四等：

- **上等吉日**：成日、开日（百事皆宜，吉力最强）
- **中等吉日**：建日、除日、定日（有特定事项偏向，需配合其他维度）
- **中平日**：满日、平日、执日、收日（吉凶参半，需具体分析）
- **凶日**：破日、危日、闭日（百事不宜，应避开）

**第二步：黄道黑道定天道**

在建除框架的基础上，以黄道黑道为第二层判断，确定日辰的天道吉凶：

- 黄道日（青龙、明堂、金匮、天德、玉堂、司命）：提升吉日等级，可部分缓解凶日的不利。
- 黑道日（天刑、朱雀、白虎、天牢、玄武、勾陈）：降低吉日等级，与凶日叠加则大凶。

**第三步：吉神凶煞调吉凶**

在黄道黑道的基础上，以吉神凶煞为第三层判断，确定日辰的吉凶程度：

- 至吉神（天德、月德、天德合、月德合）：可提升1-2个等级，甚至可化解部分凶煞。
- 上吉神（天赦、天恩、天喜、三合、六合）：可提升1个等级，对特定事项特别有利。
- 中吉神（母仓、福生、圣心、阳德）：可提升半个等级，起辅助加持作用。
- 大凶煞（月破、岁破、四废、四离、四绝）：直接降为"大凶"，不可用。
- 中凶煞（往亡、灾煞、劫煞、死气）：降1-2个等级，需结合其他维度判断。
- 小凶煞（小耗、伏断等）：降半个等级，在吉神强势时可忽略。

**第四步：二十八宿与彭祖百忌微调**

在前三步的基础上，以二十八宿和彭祖百忌为微调维度：

- 二十八宿吉宿：加0.5级；凶宿：减0.5级。
- 彭祖百忌与事项相关：减0.5-1级；无关：不影响。

**第五步：时辰定最佳窗口**

在确定日辰吉凶等级后，以时辰吉凶为最后一步，确定最佳行动时间：

- 黄道时辰：为最佳行动窗口。
- 黑道时辰：为应避免的时间窗口。

### 1.3 综合判断流程图

```
日辰干支
    │
    ├── 建除十二神 → 确定基本框架（上吉/中吉/中平/凶）
    │
    ├── 黄道黑道 → 确定天道倾向（提升/降低）
    │
    ├── 吉神凶煞 → 确定吉凶程度（提升/降低等级）
    │
    ├── 二十八宿 → 微调（±0.5级）
    │
    ├── 彭祖百忌 → 微调（±0.5-1级）
    │
    └── 时辰吉凶 → 确定最佳时辰窗口
            │
            ▼
        综合等级评定
```

## 二、多维度冲突时的裁决规则

### 2.1 宜忌相冲的处理

当同一日辰中，不同维度给出相反的吉凶信号时，需要按照以下裁决规则处理：

#### 裁决规则一：大吉压小凶

当至吉神（天德、月德）与小凶煞同时出现时，大吉压小凶，日辰仍为吉日。

**示例**：某日建除为成日（大吉），但有"小耗"凶煞值日。裁决：成日 + 小耗 = 吉日（降级但不否定），因小耗力量不足以抵消成日的吉力。

#### 裁决规则二：大凶盖小吉

当大凶煞（月破、岁破、四废、四离、四绝）出现时，无论其他维度有多少吉兆，日辰均为凶日。

**示例**：某日建除为成日（大吉），黄道为青龙（大吉），但为月破日。裁决：月破日，虽有成日、青龙加持，仍为"大凶"，不可用。此规则为择日学中最为刚性的原则。

#### 裁决规则三：神煞等级决定胜负

吉神凶煞之间的冲突，以等级高低决定胜负：

| 吉神等级 | 可化解的凶煞等级 | 示例 |
|----------|-----------------|------|
| 至吉（天德、月德） | 中凶煞及以下 | 天德可化解往亡、灾煞 |
| 上吉（天德合、月德合、天赦） | 小凶煞及以下 | 天德合可化解小耗 |
| 中吉（天喜、三合、六合等） | 不可化解凶煞 | 天喜不能化解往亡，需降级 |

### 2.2 吉神与凶煞同时值日时的判断

#### 案例一：天德 + 往亡

- 天德（至吉）vs 往亡（中凶）
- 裁决：天德可化解往亡，日辰为吉。但若事项为出行，往亡为出行特定凶煞，此时天德之力虽可化解，但出行吉日应降为"中平"，建议谨慎。

#### 案例二：月德 + 劫煞

- 月德（至吉）vs 劫煞（中凶）
- 裁决：月德可化解劫煞，日辰为吉。但若事项为签约交易，劫煞有"遭劫受损"之意，签约吉日应降为"中平"，建议避开。

#### 案例三：天喜 + 灾煞

- 天喜（中吉）vs 灾煞（中凶）
- 裁决：天喜之力不足以化解灾煞，平级对抗。此时需看建除十二神和黄道黑道。若建除为成日、黄道日，则日辰偏吉；若建除为平日、黑道日，则日辰偏凶。

#### 案例四：三合 + 月破

- 三合（中吉）vs 月破（大凶）
- 裁决：月破为大凶，三合之力完全不足以化解。日辰为"大凶"，不可用。此为"大凶盖小吉"原则的典型应用。

### 2.3 多吉神与多凶煞叠加时的判断

当同一日辰中同时出现多个吉神和多个凶煞时，采用"加权求和"法：

**吉神加权值**：至吉神 +3，上吉神 +2，中吉神 +1，小吉神 +0.5

**凶煞加权值**：大凶煞 -3，中凶煞 -2，小凶煞 -1

**判断标准**：
- 总加权值 ≥ +3：大吉
- 总加权值 +1 至 +2：吉
- 总加权值 0 至 +1：中平
- 总加权值 -1 至 0：不宜
- 总加权值 ≤ -1：大凶

**但需注意**：若存在大凶煞（月破、岁破、四废、四离、四绝），无论总加权值如何，均直接判定为"大凶"。此为大凶煞的"一票否决"原则。

### 2.4 事项相关的冲突裁决

同一日辰，不同事项可能有不同的吉凶判断。冲突裁决时需"事项优先"：

1. **婚嫁择日**：天喜、天德、三合、六合等与婚嫁直接相关的吉神，其权重在婚嫁择日中提升50%。
2. **开业择日**：三合、五合、福生等与财运相关的吉神，其权重在开业择日中提升50%。
3. **出行择日**：驿马、阳德等与出行相关的吉神，其权重在出行择日中提升50%；往亡的权重在出行择日中提升100%。
4. **安葬择日**：鸣吠日、母仓等与安葬相关的吉神，其权重在安葬择日中提升50%；重丧日、三丧日的权重在安葬择日中提升100%。

## 三、择吉等级的综合评分体系

### 3.1 评分体系设计

本知识库采用的择吉综合评分体系，满分为100分，各维度分值分配如下：

| 维度 | 满分 | 评分标准 |
|------|------|----------|
| 建除十二神 | 30分 | 成日/开日：30分；建日/除日/定日：20分；满日/平日/执日/收日：10分；破日/危日/闭日：0分 |
| 黄道黑道 | 20分 | 黄道：20分；黑道：0分 |
| 吉神凶煞 | 25分 | 至吉神 +25分；上吉神 +15分；中吉神 +10分；大凶煞 -25分；中凶煞 -15分；小凶煞 -5分 |
| 二十八宿 | 10分 | 吉宿：10分；凶宿：0分 |
| 彭祖百忌 | 5分 | 无相关忌讳：5分；有相关忌讳：0分 |
| 时辰吉凶 | 10分 | 选最佳时辰：10分；选次佳时辰：5分；选不吉时辰：0分 |

### 3.2 加权计算公式

综合评分 = 建除分 × 0.25 + 黄道黑道分 × 0.20 + 吉神凶煞分 × 0.25 + 二十八宿分 × 0.10 + 彭祖百忌分 × 0.10 + 时辰吉凶分 × 0.10

### 3.3 等级划分

| 等级 | 综合评分 | 图标 | 建议 |
|------|----------|------|------|
| 大吉 | ≥ 85分 | ⭐⭐⭐⭐⭐ | 强烈推荐，为最佳选择 |
| 吉 | 70-84分 | ⭐⭐⭐⭐ | 推荐，可放心使用 |
| 中平 | 55-69分 | ⭐⭐⭐ | 可用，但非最优 |
| 不宜 | 35-54分 | ⭐⭐ | 不推荐，建议另选日期 |
| 大凶 | < 35分 | ⭐ | 强烈不建议，必须避开 |

### 3.4 评分计算示例

**示例一：婚嫁吉日计算**

- 建除：成日（30分 × 0.25 = 7.5）
- 黄道黑道：明堂日（20分 × 0.20 = 4.0）
- 吉神凶煞：天德（+25）+ 天喜（+10）+ 三合（+10）= 45分，但满分25分，取25分（25分 × 0.25 = 6.25）
- 二十八宿：房宿（吉，10分 × 0.10 = 1.0）
- 彭祖百忌：无相关忌讳（5分 × 0.10 = 0.5）
- 时辰吉凶：选巳时（最佳，10分 × 0.10 = 1.0）

**综合评分** = 7.5 + 4.0 + 6.25 + 1.0 + 0.5 + 1.0 = **20.25分（换算为百分制约85分）**

**等级**：大吉 ⭐⭐⭐⭐⭐

**示例二：签约日辰计算**

- 建除：定日（20分 × 0.25 = 5.0）
- 黄道黑道：金匮（20分 × 0.20 = 4.0）
- 吉神凶煞：六合（+10）+ 无凶煞（0）= 10分（10分 × 0.25 = 2.5）
- 二十八宿：壁宿（吉，10分 × 0.10 = 1.0）
- 彭祖百忌：无相关忌讳（5分 × 0.10 = 0.5）
- 时辰吉凶：选未时（次佳，5分 × 0.10 = 0.5）

**综合评分** = 5.0 + 4.0 + 2.5 + 1.0 + 0.5 + 0.5 = **13.5分（换算为百分制约70分）**

**等级**：吉 ⭐⭐⭐⭐

### 3.5 评分体系的局限性与使用说明

1. 评分体系为量化参考工具，实际择吉中还需结合个人命理、事项特殊性等无法量化的因素。
2. 大凶煞（月破、岁破、四废、四离、四绝）的"一票否决"原则优先于评分，即使其他维度得分再高，也应避开。
3. 不同事项对同一日辰的评分可能不同，因为吉神凶煞的事项相关权重不同。
4. 评分体系仅作为传统择吉文化的参考工具，实际决策应综合考量多种因素。

## 四、择吉与个人命理结合的基本原则

### 4.1 八字日柱配合

择吉与个人命理（八字）的结合，是择日学从"通用择吉"走向"个性化择吉"的关键步骤。核心原则如下：

#### 日辰不冲个人日柱

择选日辰的地支不宜与个人八字日柱地支相冲。日柱为个人命理之核心，日辰冲日柱，谓之"冲夫妻宫"，对人影响极大。

**六冲口诀**：子午相冲、丑未相冲、寅申相冲、卯酉相冲、辰戌相冲、巳亥相冲。

#### 日辰五行宜生个人日柱五行

择选日辰的天干五行宜生助个人日柱天干五行，或与个人日柱五行比和。如个人日柱为甲木（木），则日辰天干为壬癸水（水生木）或甲乙木（比和）为佳。

#### 日辰三合六合宜与个人日柱配合

择选日辰的地支若与个人日柱地支形成三合或六合，则为大吉，主事务顺利，得天地人三才之助。

- **六合**：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。
- **三合**：申子辰合水、亥卯未合木、寅午戌合火、巳酉丑合金。

### 4.2 生肖配合

对于无法获取完整八字的情况，至少应考虑生肖配合：

1. **日辰不冲个人生肖**：日辰地支不宜与个人生肖地支相冲。如属鼠者（子），不宜选午日。
2. **日辰三合六合个人生肖**：日辰地支与个人生肖地支形成三合或六合，为吉。
3. **本命日注意**：个人的本命日（日辰干支与个人出生年干支相同）需谨慎使用，虽为"本命日"，但传统上认为本命日气场较强，不宜用于重大事项，也未必不能用，需结合具体命理判断。

### 4.3 婚嫁择吉中的双方命理配合

婚嫁择吉中，需要同时考虑新郎和新娘双方的命理，难度最高：

1. **日辰不冲双方日柱**：择选日辰的地支不宜冲新郎或新娘任何一方的日柱地支。
2. **日辰不冲双方生肖**：日辰地支不宜冲新郎或新娘任何一方的生肖地支。
3. **日辰宜合双方日柱或生肖**：日辰地支与双方日柱地支或生肖地支形成三合或六合为佳。
4. **女命优先原则**：传统上，婚嫁择吉以新娘命理为主，新郎命理为辅。此原则源自"女命以夫家为归宿"的传统观念。

### 4.4 安葬择吉中的亡者命理配合

安葬择吉中，亡者命理与日辰的配合至关重要：

1. **日辰不冲亡者日柱**：安葬日辰地支不宜冲亡者出生日的日柱地支。
2. **日辰不冲亡者生肖**：安葬日辰地支不宜冲亡者生肖地支。
3. **日辰纳音生亡者纳音**：安葬日辰的纳音五行宜生助亡者出生年的纳音五行。
4. **安葬时辰不冲亡者去世时辰**：安葬时辰地支不宜冲亡者去世时辰地支。

### 4.5 命理配合的局限性说明

1. 命理配合需要专业的八字命理知识，本知识库仅提供基本原则，具体配合建议请咨询专业命理师。
2. 命理配合是择吉的"加分项"而非"必选项"，在无法获取完整八字信息时，通用择吉规则仍然有效。
3. 择吉与命理配合仅为传统文化参考，不应作为人生重大决策的唯一依据。

## 五、择吉综合方法论总结

### 5.1 择吉三大原则

1. **避凶为先**：首先排除所有大凶日辰，确保安全底线。月破、岁破、四废、四离、四绝日，绝对不可用。
2. **择吉为要**：在安全日辰中，寻找最佳吉日。建除、黄道、吉神、二十八宿、彭祖百忌、时辰，六大维度综合判断。
3. **命理为辅**：在通用择吉的基础上，结合个人命理，提升择吉的精准度。但命理配合为加分项，非必选项。

### 5.2 择吉操作流程

1. 明确事项类型和事项要求。
2. 确定目标日期范围。
3. 排除大凶日辰（月破、岁破、四废、四离、四绝等）。
4. 在剩余日辰中，按建除十二神、黄道黑道、吉神凶煞、二十八宿、彭祖百忌的优先级逐层筛选。
5. 计算综合评分，确定吉日等级。
6. 在确定吉日后，选择最佳时辰。
7. 如有可能，结合个人命理进行个性化调整。
8. 给出最终择吉建议。

### 5.3 注意事项

1. 择吉是概率性参考，不是绝对保证。即使选到最佳吉日，仍需"事在人为"。
2. 不同流派、不同典籍对同一日辰的吉凶判断可能有所不同，这是择日学的常态。本知识库以《协纪辨方书》的官方体系为基准。
3. 重大事项（婚嫁、安葬、动土等）择吉，建议结合多个流派的方法交叉验证。
4. 择吉仅为传统文化参考，不应替代理性决策和专业判断。
