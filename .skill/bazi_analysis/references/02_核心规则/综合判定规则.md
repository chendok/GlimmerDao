# 第一章 格局判定

## 1.1 月令藏干表

## 1.2 格局取定规则

**"透出"定义**：月令藏干出现在四柱天干中（年干、月干、日干、时干均可），即为透出。日干本身不算"透出"。

**取格优先级**：

| 优先级 | 条件 | 操作 |
|---|---|---|
| 第1优先 | 本气透出 | 取本气为格 |
| 第2优先 | 中气透出（本气不透） | 取中气为格 |
| 第3优先 | 余气透出（本气中气均不透） | 取余气为格 |
| 第4优先 | 均不透出 | 取本气为格 |

> **注意**：比肩/劫财透出时不以正格论，应回退取本气为格。如日主壬水，月令申月，壬水（中气）透出但为比肩，应回退取本气庚金为格（偏印格）。

|---|---|---|

# 第二章 旺衰判定

## 2.1 旺衰三维评分法

从得令、得地、得势三个维度综合评估，总分为100分。

### 旺衰判定阈值（唯一标准，不得自行调整）

> **跨模型一致性**：不同模型必须使用完全相同的评分标准和阈值。评分结果必须与 `analysis.dayMasterStrength` 一致。

| 旺衰结论 | 评分范围 | 扶抑方向 |
|---|---|---|
| **身强** | **> 60分** | 用克泄耗（官杀/食伤/财星） |
| **中和** | **40～60分（含40和60）** | 扶抑需求弱，以格局为主 |
| **身弱** | **< 40分** | 用生扶（印星/比劫） |

> **例外条款**：评分在40～60分区间（中和），但日主在天干被两个以上五行克泄、或地支本气根被冲合化严重受损者，可下调判为**身弱**。此例外必须在报告中明确标注克泄来源和受损根气。

> **边界值处理**：恰好40分判为中和，恰好60分判为中和，超过60分（即61分起）判为身强。此规则消除边界歧义，所有模型必须统一执行。

### 2.1.1 得令（满分40分）

| 条件 | 得分 |
|---|---|
| 月令本气为日主同类五行 | 40分 |
| 月令本气生日主（印星当令） | 28分 |
| 月令余气为日主同类五行 | 20分 |
| 月令本气与日主无直接生克 | 10分 |
| 月令本气克泄日主 | 0分 |

### 2.1.2 得地（满分35分）

| 根气类型 | 每根得分 |
|---|---|
| 本气根（如甲木见寅木） | 20分 |
| 帝旺根（如甲木见卯木） | 20分 |
| 余气根（如甲木见亥水、辰土） | 10分 |
| 墓库根（如甲木见未土） | 8分 |

地支根越多、越近，力量越强；日支力量最大，时支次之，年支最远。

### 2.1.3 得势（满分25分）

| 天干生扶 | 每项得分 |
|---|---|
| 比肩帮身 | 10分 |
| 印星生身 | 8分 |

## 2.2 综合修正

- 地支有冲合刑害，根气受损，按程度减分
- 天干有合化，按合化后的五行重新计算
- 格局为从格、专旺格时，不按普通旺衰判定

## 2.3 实战判定步骤

1. 先看季节，确定调候用神，明确第一优先级
2. 再用三维评分法，判定日主旺衰，确定扶抑用神
3. 再看月令格局，确定格局用神
4. 综合三层用神，排出优先级，确定核心用神、辅助用神
5. 对应确定忌神、闲神
6. 检查是否有特殊反断情况，进行修正
7. 最终得出完整的喜忌结论

# 第三章 调候判定

> **强制规则**：调候判定分两步——第一步查月令基础调候表确定月令的基础寒暖燥湿属性；第二步结合五行分布修正因子调整最终结论。两步缺一不可。模型不得凭主观感觉判断命局寒暖燥湿。

## 3.3 申月（立秋）特殊调候规则

申月金旺当令，金能生水，调候需求取决于五行分布对比：

```
申月（金旺当令，金生水）
  │
  ├─ 土分 ≥ 5（土重克水）
  │    └─ 判定：偏燥 → 调候用神 = 金（通关：化土生水）
  │         理由：土重克水，金能泄土生水，为最佳通关五行
  │
  ├─ 水分 ≥ 5（水多金寒）
  │    └─ 判定：偏寒 → 调候用神 = 火（暖局：驱寒温局）
  │         理由：金寒水冷，需火暖局激发活力
  │
  ├─ 土分 3～4 且 水分 3～4（土水基本平衡）
  │    └─ 判定：中和 → 调候用神 = 无（不需调候，以扶抑为主）
  │
  └─ 其他情况
       └─ 判定：偏凉 → 调候用神 = 火（轻度暖局）
```

**申月调候示例**：壬水日主，生于申月，五行分布：金2、木5、水4、火3、土6
1. 月令基础属性：申月 → 中→偏凉，中
2. 五行修正：土分6≥5 → 向燥偏移+1级 → 偏燥
3. 最终判定：偏燥（土重克水），调候用神 = 金（通关：化土生水）

## 3.5 调候与扶抑协调规则

| 情况 | 处理方式 |
|---|---|
| 调候用神与扶抑用神方向一致 | 直接取该方向为综合用神（最理想） |
| 调候用神与扶抑用神方向冲突 | 调候优先，扶抑让步（报告中说明冲突） |
| 调候无需求（中和） | 以扶抑用神为综合用神 |
| 调候需求与格局用神冲突 | 调候优先，格局用神为辅 |

## 3.6 使用流程

1. **查月令基础属性**：根据出生月令，查3.1节月令基础调候属性表
2. **算五行修正**：根据命局五行分布，按3.2节修正因子调整寒暖燥湿等级
3. **定调候用神**：根据最终寒暖燥湿等级，查3.4节调候用神判定总表
4. **协调扶抑**：按3.5节规则协调调候与扶抑用神
5. **输出结论**：在报告中明确标注寒暖等级、燥湿等级、调候用神及理由

> **禁止事项**：不得跳过月令基础表直接凭感觉判断；不得忽略五行修正因子；不得在申月等模糊月令随意选择寒暖方向。

# 第四章 用神选取与喜忌推导

> **强制规则**：用神选取按「调候 > 扶抑 > 格局」三级优先级执行。每一步必须有明确判定依据。喜忌系统由用神唯一推导，不得独立设定。

## 4.1 用神选取流程（严格按序执行）

### 第一步：判旺衰

按第二章旺衰三维评分法判定日主旺衰：

| 旺衰结论 | 评分范围 | 扶抑方向 |
|---|---|---|
| 身强 | > 60分 | 用克泄耗（官杀/食伤/财星） |
| 中和 | 40～60分（含40和60） | 扶抑需求弱，以格局为主 |
| 身弱 | < 40分（或在40～60区间但日主受两个以上五行克泄、本气根被冲合化严重受损者） | 用生扶（印星/比劫） |

> **注意**：排盘JSON中已提供 `dayMaster.strength.level` 和 `score`，直接使用，不得自行重新计算。

### 第二步：查调候

按第三章调候量化判定标准判定：
1. 查月令基础寒暖燥湿属性
2. 结合五行分布修正
3. 确定调候用神及调候急迫度

### 第三步：定扶抑

| 旺衰结论 | 扶抑用神方向 | 具体五行 |
|---|---|---|
| 身强 | 克泄耗 | 官杀、食伤、财星中选最有力的 |
| 身弱 | 生扶 | 印星、比劫中选最有力的 |
| 中和 | 视格局 | 以格局用神为主，轻量扶抑 |

**扶抑用神选取优先级（身弱时）**：

| 优先级 | 用神类型 | 条件 |
|---|---|---|
| 1 | 印星 | 月令为印星或印星不受冲克 |
| 2 | 比劫 | 天干有比劫透出或地支有比劫根 |
| 3 | 印比并用 | 印星和比劫均有但均不强 |

**特殊情况**：身弱但官杀极重（官杀分≥6）时，应取**食伤制杀**或**印星化杀**，具体取决于食伤和印星的力量对比。

### 第四步：验格局

检查所选用神是否与格局用神冲突（参见第一章1.4节格局用神协调规则）。

### 第五步：定综合用神

1. **调候与扶抑方向一致**：直接取该方向为综合用神（最理想）
2. **调候与扶抑方向冲突**：调候优先，扶抑让步（在报告中说明冲突）
3. **调候无需求**：以扶抑用神为综合用神
4. **格局用神与综合用神一致**：格局层次提升（报告中标注"格局用神有力"）
5. **格局用神与综合用神冲突**：格局层次下降（报告中标注"格局用神受损"）

## 4.2 喜忌系统推导规则

> **跨模型一致性核心规则**：喜忌系统必须由用神唯一推导，不同模型必须使用完全相同的推导规则，确保输出一致。

综合用神确定后，喜忌系统按以下规则唯一推导：

| 类别 | 推导规则 | 关键约束 |
|---|---|---|
| **用神** | 直接帮扶日主或平衡命局的五行 | 来自4.1节综合用神判定结果 |
| **喜神** | **生用神的五行**（非用神本身） | **禁止**将用神列为喜神。用神为多五行时，取生第一用神的五行 |
| **闲神** | 对命局无明显生扶或克泄的五行 | 既不生用神也不克用神、且非用神本身的五行 |
| **忌神** | 克泄耗用神的五行（包括克用神和泄用神两类） | 含克用神和泄用神两类 |
| **仇神** | 生忌神的五行 | — |

### 4.2.1 喜神推导详细规则（强制）

> **强制规则**：喜神必须由用神唯一推导。**绝对禁止**将用神本身列为喜神。以下是喜神推导的唯一正确方式：

| 用神情况 | 喜神推导 | 推导依据 | 示例 |
|---------|---------|---------|------|
| 用神=单一五行 | 喜神 = 生该用神的五行 | 五行相生：土生金、金生水、水生木、木生火、火生土 | 用神=金 → 喜神=土 |
| 用神=两个五行（如金、水） | 喜神 = 生第一用神的五行 | 取第一用神（优先级最高者），按3.5节排序规则确定第一用神 | 用神=金、水 → 第一用神=金 → 喜神=土 |
| 用神=三个五行 | 喜神 = 生第一用神的五行 | 同上 | 用神=木、火、土 → 第一用神=木 → 喜神=水 |

> **典型错误示例（禁止）**：
> - 用神=金、水 → 喜神=金、水 ✗（错误：将用神本身列为喜神）
> - 用神=金、水 → 喜神=金、水 ✓ 这是**常见错误**，喜神应该是生用神的五行，而非用神本身
>
> **正确示例**：
> - 用神=金 → 喜神=土（土生金）
> - 用神=金、水（金优先）→ 喜神=土（土生金，金为第一用神）
> - 用神=水 → 喜神=金（金生水）
> - 用神=木 → 喜神=水（水生木）

### 五行生克关系速查

| 用神五行 | 喜神（生用神） | 忌神（克/泄用神） | 仇神（生忌神） |
|---|---|---|---|
| **金** | 土 | 火（火克金）、水（金生水泄） | 木（木生火） |
| **水** | 金 | 土（土克水）、木（水生木泄） | 火（火生土） |
| **木** | 水 | 金（金克木）、火（木生火泄） | 土（土生金） |
| **火** | 木 | 水（水克火）、土（火生土泄） | 金（金生水） |
| **土** | 火 | 木（木克土）、金（土生金泄） | 水（水生木） |

### 喜神推导速查（多五行用神场景）

| 用神组合（第一用神在前） | 喜神 | 推导依据 |
|---|---|---|
| 金、水 | **土** | 生第一用神金（土生金） |
| 金、水、土 | **土** | 生第一用神金（土生金） |
| 水、金 | **金** | 生第一用神水（金生水） |
| 木、火 | **水** | 生第一用神木（水生木） |
| 火、土 | **木** | 生第一用神火（木生火） |

### 特殊情况处理

| 情况 | 处理方式 |
|---|---|
| 用神为两个五行（如金、水） | 喜神取生第一用神的五行（金优先→喜神=土），忌神取克第一用神的五行 |
| 用神为三个五行 | 喜神取生第一用神的五行，忌神取克第一用神的五行 |
| 闲神判定 | 既不生用神也不克用神、且非用神本身的五行，通常0-1个 |
| 忌神与仇神同源 | 忌神和仇神可能部分重叠 |

## 4.3 用神选取完整示例

### 示例1：身弱+偏燥（土重）→ 用神=金水

**命局**：壬水日主，生于申月，身弱（score: 35），五行：金2、木5、水4、火3、土6，偏印格

| 步骤 | 判定项 | 结论 | 依据 |
|---|---|---|---|
| 第一步 | 旺衰 | 身弱 | score: 35 < 40 |
| 第二步 | 调候 | 偏燥，调候用神=金 | 申月+土6分≥5→偏燥→金通关 |
| 第三步 | 扶抑 | 扶抑用神=金、水 | 身弱→印星(金)生身+比劫(水)帮身 |
| 第四步 | 格局 | 格局用神=金（印星） | 偏印格以印星为用，与调候/扶抑一致 |
| 第五步 | 综合 | 用神=金、水 | 三者一致 |

**喜忌推导**：用神=金、水（金为第一用神）；喜神=土（土生金）；忌神=火、土、木；仇神=木、火；闲神=无

### 示例2：身强+偏寒（水旺）→ 用神=火土

**命局**：壬水日主，生于亥月，身强（score: 72），五行：金3、木2、水6、火1、土3，建禄格

| 步骤 | 判定项 | 结论 | 依据 |
|---|---|---|---|
| 第一步 | 旺衰 | 身强 | score: 72 > 60 |
| 第二步 | 调候 | 寒冷，调候用神=火 | 亥月基础=寒冷+水分6≥5向寒偏移 |
| 第三步 | 扶抑 | 扶抑用神=火、土 | 身强→克泄耗 |
| 第四步 | 格局 | 格局用神=火（财星） | 建禄格喜财官，与调候/扶抑一致 |
| 第五步 | 综合 | 用神=火、土 | 三者一致 |

**喜忌推导**：用神=火、土；喜神=火、土；忌神=水、金、木；仇神=水、金；闲神=无

## 4.4 自检校验规则

用神和喜忌确定后，必须进行以下自检：

| 校验项 | 规则 | 违反时处理 |
|---|---|---|
| 用忌不重叠 | 用神五行与忌神五行不得重叠 | 重新检查推导过程 |
| 喜用相生 | 喜神五行必须生用神五行 | 重新查五行生克表 |
| 仇忌相生 | 仇神五行必须生忌神五行 | 重新查五行生克表 |
| 调候一致 | 调候用神方向必须与寒暖燥湿判断一致 | 重新查阅调候量化判定标准 |
| 扶抑一致 | 扶抑用神方向必须与旺衰判断一致 | 重新检查旺衰判定 |
| 格局不冲突 | 综合用神不得与格局用神完全对立 | 在报告中说明冲突原因 |

> **强制要求**：以上6项自检全部通过后方可输出用神结论。任何一项不通过，必须回溯修正。

## 4.5 禁止事项

1. 不得跳过调候步骤——即使命局寒暖燥湿基本平衡，也必须明确标注"调候无需求"
2. 不得凭感觉判断寒暖——必须查阅第三章调候量化判定标准
3. 不得自行设定喜忌——喜忌必须由用神唯一推导
4. 不得忽略格局用神——必须在报告中分析其与综合用神的关系
5. 不得在申月等模糊月令随意选择方向——必须严格按3.3节的决策树执行
6. 不得将十神组合名称当作用神——如"食神生财"是十神组合关系，不是用神名称

# 第五章 十神力量量化

> **强制规则**：十神力量计算分四步——第一步确定基础力量值，第二步叠加位置权重系数，第三步叠加十二长生旺衰系数，第四步执行冲合刑害修正。四步缺一不可。

## 5.1 基础力量值（第一步）

| 存在形式 | 基础力量 | 说明 |
|---|---|---|
| 天干透出 | +10 | 天干明现，力量最强 |
| 地支本气藏干 | +8 | 地支本气藏干，力量次强 |
| 地支中气藏干 | +5 | 地支中气藏干，力量中等 |
| 地支余气藏干 | +3 | 地支余气藏干，力量较弱 |
| 仅藏不透 | 基础值 × 0.5 | 藏于地支但未透天干，力量减半 |
| 命局不现 | 0 | 该十神不现于四柱 |

> **多源叠加规则**：同一十神在天干和地支多个位置的基础力量值累加后，再判断是否"仅藏不透"。若天干有透出，则不受减半惩罚；若天干无透出但地支有藏干，则累加后乘0.5。

## 5.2 位置权重系数（第二步）

### 天干位置权重

| 天干位置 | 权重系数 | 说明 |
|---|---|---|
| 月干 | × 1.3 | 月令提纲之干，力量最大 |
| 日干（日主本身） | × 1.0 | 日主为基准，不受额外加权 |
| 时干 | × 1.1 | 时干紧贴日主，力量较强 |
| 年干 | × 0.8 | 年干离日主最远，力量最弱 |

### 地支位置权重

| 地支位置 | 权重系数 | 说明 |
|---|---|---|
| 月支（月令） | × 1.3 | 月令为命局力量之源 |
| 日支 | × 1.1 | 日支为夫妻宫，紧贴日主 |
| 时支 | × 1.0 | 时支主晚年和结果 |
| 年支 | × 0.7 | 年支离日主最远 |

> 同一十神在天干和地支均有出现时，天干部分和地支部分分别计算位置权重后累加。日主本身的十神不参与位置权重计算。

## 5.3 十二长生旺衰系数（第三步）

| 十二长生状态 | 系数 | 说明 |
|---|---|---|
| 长生、冠带、临官、帝旺 | × 1.5 | 旺相状态，力量增强 |
| 沐浴、衰、病 | × 1.0 | 平衡状态，力量不变 |
| 死、墓、绝、胎、养 | × 0.5 | 衰弱状态，力量减弱 |

> 以日主天干为基准，查该十神对应五行在四柱地支中的十二长生状态，取该十神**最强根气**对应的十二长生状态为系数。

## 5.4 冲合刑害修正（第四步）

### 六冲修正

| 情况 | 修正方式 |
|---|---|
| 十神根气地支被冲 | 力量 × 0.6 |
| 十神根气地支冲他支且得令 | 力量 × 0.8 |

### 合化修正

| 情况 | 修正方式 |
|---|---|
| 十神根气地支参与六合且合化成功 | 力量 × 0.3 |
| 十神根气地支参与六合但合而不化 | 力量 × 0.7 |
| 十神根气地支参与三合局且成局 | 力量 × 1.4 |
| 十神根气地支参与三合局但局不全 | 力量 × 0.9 |

### 相刑/相害修正

| 情况 | 修正方式 |
|---|---|
| 十神根气地支参与相刑 | 力量 × 0.7 |
| 十神根气地支参与相害 | 力量 × 0.85 |

> **修正叠加规则**：同一十神的根气地支若同时受到多种关系影响，修正系数**连乘**。修正后力量值四舍五入保留整数。

## 5.5 完整计算公式

```
综合力量 = (天干基础力量 × 天干位置权重 + 地支基础力量 × 地支位置权重) × 十二长生系数 × 冲合刑害修正系数
```

**计算顺序**：
1. 查月令藏干（参见第一章月令藏干表）
2. 确定十神分布（列出全部十个十神在四柱中的出现位置）
3. 计算基础力量（天干部分 + 地支部分累加）
4. 叠加位置权重（天干和地支分别计算后累加）
5. 叠加长生系数（乘以最强根气的十二长生系数）
6. 冲合刑害修正（按5.4节规则修正）
7. 四舍五入保留整数
8. 排序输出（按综合力量从大到小排列全部十个十神）

## 5.6 力量等级划分

| 力量值范围 | 等级 | 说明 |
|---|---|---|
| ≥ 25 | 极旺 | 该十神在命局中占据主导地位 |
| 15～24 | 偏旺 | 该十神有力，对命局有明显影响 |
| 8～14 | 中等 | 该十神有一定力量，影响中等 |
| 1～7 | 偏弱 | 该十神力量不足，影响有限 |
| 0 | 不现 | 该十神不现于命局 |

|---|---|---|

## 6.2 核心组合判定流程

### 第一步：检查特殊组合

1. 检查是否满足从格条件
2. 检查是否满足化气格条件
3. 检查是否满足专旺格条件
4. 若任一特殊组合成立，取该组合为核心组合，不再检查普通组合

### 第二步：检查凶组合

按凶组合优先级从高到低检查。若命局中存在凶组合且力量达到要求，先标注凶组合，再检查吉组合。

### 第三步：检查吉组合

按吉组合优先级从高到低检查，**命中即取，不继续往下检查**。

### 第四步：确定核心组合

- 若吉组合成立：取该吉组合为核心组合
- 若吉组合不成立但凶组合成立：取该凶组合为核心组合，并标注"需化解"
- 若吉凶组合均不成立：标注"无明显核心组合，以格局用神为主线分析"

## 6.3 力量判定标准

| 力量等级 | 判定条件 | 对应分值 |
|---|---|---|
| 强旺 | 天干透出 + 地支有本气根 + 十二长生为旺相 | ≥20分 |
| 中等 | 天干透出或地支有本气根（满足其一） | 10-19分 |
| 弱 | 仅藏于地支中余气，不透天干 | 5-9分 |
| 微弱 | 仅藏于地支余气，力量微弱 | 1-4分 |
| 不现 | 不在命局中 | 0分 |

> 力量分值按第五章十神力量量化规则计算。

## 6.4 组合与用神的关系

| 情况 | 对格局层次的影响 |
|---|---|
| 组合中的"用神十神"与综合用神五行一致 | +5分（命局层次评分维度一） |
| 组合中的"用神十神"与综合用神五行冲突 | 0分（报告中说明冲突） |
| 组合成立但"用神十神"受冲克 | -3分 |
| 组合不成立 | 不加分 |

> "用神十神"定义：吉组合中起主导作用的十神。如杀印相生中印星为用神十神；食神生财中食神为用神十神。

## 6.5 歧义裁决规则

> **强制规则**：当多个十神组合同时满足条件时，必须按以下规则裁决，不得由模型自行判断。这是消除不同模型输出差异的关键规则。

### 6.5.1 食神制杀 vs 食神生财 优先裁决

| 情况 | 裁决结果 | 理由 |
|---|---|---|
| 食神在月干或时干（紧贴日主） | 取**食神制杀**（优先级2） | 食神贴身制杀，制杀有力 |
| 食神仅在年干（远离日主） | 取**食神生财**（优先级5） | 食神远隔，制杀无力，转而生财 |
| 食神在月干/时干，同时满足食神生财 | 取**食神制杀** | 按优先级，食神制杀(2) > 食神生财(5) |

> **核心原则**：食神制杀要求食神能"贴身"制杀。食神在年干时力不能及，不满足"贴身制杀"条件，降级检查次优组合。

### 6.5.2 杀印相生 vs 食神制杀 优先裁决

按优先级：杀印相生(1) > 食神制杀(2)。两者同时满足时，取杀印相生。但须满足"印在月干或日支"的贴身条件。

### 6.5.3 吉组合与凶组合并存时的裁决

若命局同时存在吉组合和凶组合：
1. 先标注凶组合为"需化解的组合"
2. 核心组合取吉组合
3. 在报告中说明"吉凶组合并存，吉中有凶，需注意化解XX"

### 6.5.4 多组合裁决总流程

```
第一步：检查特殊组合（从格/化气格/专旺格）
  └─ 成立 → 取特殊组合，终止
  └─ 不成立 → 第二步

第二步：按吉组合优先级（1→8）依次检查
  └─ 找到第一个满足的 → 取该吉组合，跳到第四步
  └─ 全部不满足 → 第三步

第三步：按凶组合优先级（1→5）依次检查
  └─ 找到第一个满足的 → 取该凶组合，标注"需化解"

第四步：输出核心组合
  └─ 吉组合成立 → 核心组合=该吉组合
  └─ 仅凶组合成立 → 核心组合=该凶组合，标注"需化解"
  └─ 均不成立 → 标注"无明显核心组合"
```

> **注意**：第二步中，食神制杀（优先级2）须额外检查食神是否在月干/时干。若食神仅在年干，跳过食神制杀，继续检查优先级3及以后的组合。

## 6.6 十神组合全量列出规则

> **强制规则**：报告中必须列出**所有成立的十神组合**（吉组合和凶组合分别列出），不得只列一个核心组合。这是消除"组合数量差异"的关键规则，也是确保不同模型输出一致的核心规则。

### 列出格式

```
吉组合（按优先级排序）：
  ★ 食神生财（核心组合）
  · 食神制杀
  · 杀印相生（若成立）

凶组合（需化解）：
  · 比肩合财
  · 财破印
```

### 组合判定全量扫描流程

1. 按吉组合优先级（1→8）**全部扫描**，不中断
2. 每个满足条件的吉组合都列入"吉组合"列表
3. 按凶组合优先级（1→5）**全部扫描**，不中断
4. 每个满足条件的凶组合都列入"凶组合"列表
5. 核心组合（优先级最高的吉组合）加★标注

> **与核心组合判定的区别**：6.5.4节的多组合裁决流程用于确定**唯一核心组合**；本节的全量扫描用于**报告列出所有组合**。两者并行不悖：核心组合只有一个（加★），但报告中列出所有成立的组合。

### 食神制杀组合的判定规则（强制）

> **强制规则**：食神制杀是否成立，取决于食神在天干的位置。不同模型必须使用同一判定标准。

| 食神位置 | 食神制杀判定 | 核心组合选取 | 全量列表中是否列出 |
|---------|------------|------------|-----------------|
| 食神在月干或时干（紧贴日主） | 成立（制杀有力） | 按优先级，食神制杀(2) > 食神生财(5) | **是**（列为吉组合） |
| 食神仅在年干（远离日主） | 成立（制杀力弱） | 取食神生财（优先级5），食神制杀不作为核心组合 | **是**（仍列为吉组合，但不加★） |
| 食神不透干（仅藏支） | 不成立 | 不取食神制杀 | 否 |

> **关键规则**：食神制杀即使因食神在年干而不作为核心组合，只要食神和七杀力量均满足条件（食神≥中等，七杀≥中等），仍应在全量扫描中**列为吉组合**（不加★）。这确保了不同模型在列出所有组合时的一致性。

### 比肩争财/比肩合财组合的判定规则（强制）

> **强制规则**：当命局中有比肩与财星同时出现时，必须检查比肩争财/比肩合财是否成立。

| 条件 | 判定 | 说明 |
|-----|------|------|
| 比肩/劫财在天干透出 + 正财/偏财在天干透出 + 比劫≥中等 + 财星≥中等 | 比劫夺财成立 | 合作中易有利益纠纷，财来财去 |
| 比肩与财星在天干相邻（月干比肩+时干正财） | 比肩合财成立 | 比肩合绊财星，主合作纠纷或配偶被争 |

> **注意**：比肩争财与比肩合财是同一类组合的不同表现形式，报告中统一列为"比肩争财"（凶组合），并在说明中描述具体表现形式。

# 第七章 天干五合判定

> **强制规则**：四柱天干中所有天干五合必须全部检查，不得遗漏。丁壬合是判断配偶星是否被合绊的关键依据，必须明确判定合化/合绊状态。

## 7.1 天干五合对照表

| 天干组合 | 合化五行 | 合化条件（必须同时满足） |
|---|---|---|
| 甲己合 | 土 | 月令为土（辰戌丑未月）或地支有辰戌丑未根 |
| 乙庚合 | 金 | 月令为金（申酉月）或地支有申酉根 |
| 丙辛合 | 水 | 月令为水（亥子月）或地支有亥子根 |
| 丁壬合 | 木 | 月令为木（寅卯月）或地支有寅卯根 |
| 戊癸合 | 火 | 月令为火（巳午月）或地支有巳午根 |

## 7.2 合化判定规则

### 合化成功的条件（必须同时满足）

1. **月令支持**：月令五行与合化后的五行相同或相生
2. **地支有根**：合化后的五行在地支中有本气根或帝旺根
3. **无严重冲克**：合化五行不被其他天干严重冲克

### 合化失败的处理

不满足合化条件时，判定为"合而不化"（仅论合绊）：
- 两干之间产生牵绊关系
- 各自保留原有五行属性
- 合绊力量受距离影响：相邻合绊力量强，遥隔合绊力量弱

## 7.3 丁壬合的特殊处理

> **强制规则**：丁壬合是判断配偶星是否被合绊的关键。丁火为正财（男命配偶星），壬水为日主或比肩。丁壬合必须按以下规则统一判定。

| 情况 | 判定结论 | 对命局的影响 |
|---|---|---|
| 月令为木（寅卯月）+ 地支有寅卯根 | **合化成功**（丁壬合化木） | 配偶星被合化，转化为食伤，配偶助力减弱 |
| 月令非木或地支无木根 | **合而不化**（仅合绊） | 配偶星被合绊，财星有争夺之象，配偶易被他人吸引 |
| 丁在时干、壬在月干（相邻） | 合绊力量**强** | 紧贴相合，影响显著 |
| 丁在时干、壬在年干（遥隔） | 合绊力量**弱** | 远隔相合，影响有限 |

> **关键判定**：丁壬合化木的条件极为苛刻，必须月令为木且地支有木根。大多数情况下丁壬合为"合而不化"，仅论合绊。不得在条件不满足时判定为合化成功。

## 7.4 天干五合对格局的影响

| 合化情况 | 对格局的影响 |
|---|---|
| 格局用神被合化 | 格局层次下降，报告中标注"格局用神被合化，格局受损" |
| 忌神被合化 | 格局层次提升，报告中标注"忌神被合化，格局得救" |
| 日主参与合化 | 日主化气，格局可能变为化气格（需综合判断） |
| 合而不化 | 仅论牵绊，不影响格局层次，但影响对应十神的力量发挥 |

# 第八章 五行流通路径判定

> **强制规则**：五行流通路径必须从日主五行出发，按相生顺序追踪。不同模型必须按同一规则确定路径起点、方向和归宿。

## 8.1 路径起点规则

> **强制规则**：不同模型必须使用完全相同的路径起点。这是消除"五行流通路径不一致"差异的关键规则。

| 规则 | 说明 |
|---|---|
| **起点必须为日主五行** | 无论全局五行力量如何分布，流通路径必须以日主为中心。不得从其他五行开始 |
| 示例（壬水日主） | 正确：水→木→火→土→金→水；错误：土→金→水→木→火→土 |

> **核心原则**：流通路径分析的目的是判断日主在全局中的能量流向，而非客观的五行闭环。起点为日主才能体现"以日主为中心"的分析视角。

> **禁止事项**：
> - 禁止从土（官杀）或其他五行开始追踪
> - 禁止以"寻找最旺五行"为起点
> - 禁止以"推动全局流通的五行"为起点
> - 起点只有一个：日主五行。违反此规则在任何模型下均视为分析错误

## 8.2 路径追踪规则

从日主五行出发，按五行相生链（金→水→木→火→土→金）追踪：

1. **日主生什么**：找到日主五行所生的五行在命局中是否存在（分值≥1即存在）
2. **存在则继续**：被生五行存在，继续追踪它生什么
3. **不存在则终止**：被生五行不存在，路径终止
4. **多分支处理**：若存在多个被生五行，取分值最高的分支

## 8.3 归宿判定规则

| 归宿类型 | 判定条件 | 含义 |
|---|---|---|
| **回归日主** | 路径最终回到日主五行（如：水→木→火→土→金→水） | 能量有自我修复能力，命局有内在循环 |
| **归宿忌神** | 路径终点为忌神/仇神五行 | 压力最终回到日主，需通关五行化解 |
| **归宿用神** | 路径终点为用神/喜神五行 | 能量最终流向有利方向，命局结局向好 |
| **中途断裂** | 路径在中间某处终止（被生五行不存在） | 能量不流通，需大运流年引动 |

## 8.4 归宿说明文字规范

归宿说明必须使用统一话术，不得自由发挥：

| 归宿 | 话术模板 |
|---|---|
| 水（比劫） | "能量回归于水（比劫），命局有自我修复和回归的能力，核心能量始终围绕自身" |
| 土（官杀） | "流通终点为土（官杀），压力最终仍回到日主身上，需印星（金）介入化解" |
| 火（财星） | "流通终点为火（财星），能量最终转化为财富，但需身强方能担财" |
| 金（印星） | "流通终点为金（印星），能量回归用神，格局有自我强化能力" |
| 木（食伤） | "流通终点为木（食伤），能量转化为才华输出，但需注意泄身过度" |

> **禁止**：归宿说明不得超出上述话术模板。归宿五行必须与 `analysis.wuXingFlow.finalDestinationWuXing` 一致。

# 第九章 命局层次评分

> **强制规则**：命局层次评分满分100分，分5个维度，各维度分值固定。不同模型必须按同一标准评分，确保结论一致。

| 格局有疵但成立 | 18-24 | 格局用神有力但受轻微冲克或被合，有救应 |

**加减分明细**：格局用神透天干+5分；不受冲克+5分；有相神辅助+5分；受冲但力量轻微-3分；受冲且力量较强-8分；被合化-10分。

| 用神无力或缺失 | 0-7 | 用神不现于命局，或被严重破坏 |

**加减分明细**：透天干+5分；地支有本气根+5分；地支有中余气根+3分；不受冲克+5分；逢生有生扶+3分；受克-5分；被合化-8分。

| 评分项 | 分值 | 判定标准 |
|---|---|---|

**判定方法**：按相生顺序（金→水→木→火→土→金）检查。每有一处相克阻断扣3分；每有一处相生链条完整加3分；若有"通关"五行化解相克则不扣分。

| 凶煞严重 | 0-3 | 凶煞多且有力，吉神缺失或被冲克 |

**神煞力量等级**：甲级（天乙贵人/太极贵人/月德贵人/天德贵人）每个±3分；乙级（文昌/福星/国印/天喜/天医/德秀/驿马等）每个±2分；丙级（丧门/勾煞/空亡/魁罡等）每个±1分。

### 维度五：地支关系和谐度（满分10分）

| 评分项 | 分值 | 判定标准 |
|---|---|---|
| 和谐稳定 | 8-10 | 有合局增强日主，无严重冲刑 |
| 基本稳定 | 5-7 | 有1组冲或刑，但有合局化解 |
| 不太稳定 | 3-4 | 有1组强冲且无化解，或有2组以上冲刑 |
| 严重动荡 | 0-2 | 多组冲刑害并存，无合局化解 |

**加减分明细**：每有一组三合/三会+3分；半合（含中神）+2分；六合+1分；六冲-3分；相刑-2分；相害-1分；相破-1分。冲刑有合局化解恢复50%扣分。

## 7.3 评定流程与示例

**评定流程**：
1. 格局成格度评分（满分30）
2. 用神有力程度评分（满分25）

**示例**：壬水日主，偏印格，身弱，五行金2木5水4火3土6，寅申六冲

| 维度 | 得分 | 依据 |
