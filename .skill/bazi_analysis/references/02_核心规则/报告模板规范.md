# 报告模板确定性数据填充规范

> **本文件为SKILL.md第五章「报告模板确定性数据填充规范」的详细附件。模型在填充报告模板时，必须按本规范区分确定性数据与解释性内容。**

---

## 一、确定性数据字段对照表

无论使用何种报告模板（用户提供的模板或缺省模板），以下字段为**确定性数据**，必须直接从排盘JSON的 `analysis` 预计算字段中取值填充，不得自行计算或修改。

| 报告模板中的字段/表格 | 数据来源（排盘JSON） | 填充规则 |
|---|---|---|
| 命局层次评定表（五维度得分+总分+等级） | `analysis.mingJuLevel` | 五维度得分、总分、等级必须与预计算结果完全一致 |
| 格局判断表（日主旺衰/格局名称/成败度/调候用神/扶抑用神/格局用神/喜神/忌神/仇神） | `analysis.geJuInfo` + `analysis.yongShen` + `analysis.tiaoHou` + `analysis.dayMasterStrength` | 各字段值必须与预计算结果完全一致 |
| 十神力量排序 | `analysis.shiShenPower` | 排序顺序、力量数值、等级必须与预计算结果完全一致 |
| 核心十神组合 | `analysis.shiShenCombination` | 组合名称、类型、力量评估必须与预计算结果完全一致 |
| 地支关系表（8种类型） | `analysis.diZhiRelations` | 每种关系的存在性、具体组合、力量等级必须与预计算结果完全一致 |
| 喜忌系统应用总表 | `analysis.yongShen` | 用神/喜神/忌神/仇神/闲神的五行归类必须与预计算结果完全一致 |
| 调候需求分析（寒暖/燥湿/调候用神） | `analysis.tiaoHou` | 寒暖等级、燥湿等级、调候用神、急迫度必须与预计算结果完全一致 |
| 日主旺衰判断（得令/得地/得势/综合结论） | `analysis.dayMasterStrength` | 旺衰等级、得分、扶抑方向必须与预计算结果完全一致 |
| 天干五合关系（丁壬合等） | `analysis.ganHe` | 是否存在合、合化/合绊状态、对配偶星的影响必须与预计算结果完全一致 |
| 五行流通路径 | `analysis.wuXingFlow` | 流通路径、归宿五行、通关五行、流畅度评分必须与预计算结果完全一致 |
| 纳音格局评估 | `analysis.naYinAssessment` | 纳音格局模式、生克关系方向、总体评价必须与预计算结果完全一致 |
| 大运预计算评估 | `analysis.daYunEvaluations` | 每步大运的吉凶等级、评分、三维度得分必须与预计算结果完全一致 |
| 神煞分类与等级 | `analysis.shenShaClassification` | 每个神煞的吉凶分类、等级、分值必须与预计算结果完全一致 |
| 关键流年预计算评估 | `analysis.liuNianAssessments` | 每个流年的吉凶等级、评分、风险等级必须与预计算结果完全一致 |
| 用神优先级排序 | `analysis.yongShen.priorityOrder` | 楼层选择、方位推荐中第一用神必须与 `priorityOrder[0]` 一致 |
| 健康五行判断 | `analysis.yongShen`（喜忌系统） | 每个五行的"补"或"抑"必须基于该五行在喜忌系统中的角色。忌神→抑制，用神/喜神→养护 |
| 五行体质类型 | `analysis.yongShen` + `analysis.dayMasterStrength` | 体质类型话术必须使用统一模板，不得添加"兼有XX"补充说明 |
| 十神组合全量列表 | 按综合判定规则6.6节全量扫描 | 报告中必须列出所有成立的吉组合和凶组合，核心组合加★标注 |

## 二、确定性数据填充示例

**命局层次评定表填充**：
```
模板原文：| 格局成格度 | 30 | __ |          |
填充结果：| 格局成格度 | 30 | 20 | 偏印格成立，但月令申金被寅冲，格局有疵 |
（20 和说明文字来自 analysis.mingJuLevel.scores[0].score 和 .reason）
```

**格局判断表填充**：
```
模板原文：| 日主旺衰 | 身强 / 身弱 / 从强 / 从弱 / 化气 / 专旺 |  |
填充结果：| 日主旺衰 | 身弱 | 申月庚金生水得令28分，但木5重泄+土6重克 |
（"身弱"来自 analysis.dayMasterStrength.level，推导来自 .detail）
```

**十神力量排序填充**：
```
模板原文：____________ > ____________ > ____________ > ...
填充结果：食神(25) > 偏印(18) > 七杀(15) > 比肩(12) > 偏财(10) > ...
（排序和数值来自 analysis.shiShenPower 数组）
```

## 三、解释性内容界定

以下内容为**解释性内容**，模型应在确定性数据基础上展开分析，不同模型可自由发挥（但不得与确定性数据矛盾）：

- 命局总评（对格局的整体文字描述）
- 十神组合对人生的核心影响解读
- 性格天赋分析
- 事业/财运/婚姻/健康等分领域详细分析
- 大运流年逐年详解
- 行事宜忌建议
- 风水/穿搭/养生等生活建议

> **关键约束**：解释性内容不得与确定性数据矛盾。例如，若 `analysis.yongShen` 确定用神为金水，则解释性内容中不得出现"用神为木火"的表述；若 `analysis.mingJuLevel` 评定为"中等"，则解释性内容中不得出现"命局层次为上等"的表述。

## 四、解释性内容统一话术模板

> **跨模型一致性规则**：以下解释性内容必须使用统一话术模板，不同模型只能在模板的 `[可替换]` 部分自由发挥，模板结构必须保持一致。

### 4.1 命局总评话术模板

```
本命局属于[格局名称]，日主[旺衰结论]，五行分布呈[五行特征描述]特征。格局成格的核心支点在于[核心支点描述]，破格风险点在于[破格风险描述]，综合格局成败度为[成败度]，在同类格局中处于[层级]层级。

从终身大运联动来看，命局与大运的交互呈现[运势规律总结]的规律：[早年/中年/晚年]大运[描述]，运势[评价]。整体人生节奏为[节奏总结]，人生上限高度取决于[关键因素]。

先天核心优势集中在[优势领域]领域，人生核心课题集中在[课题领域]方面，属于[命局类型]类型的命局，人生发展的最优路径是[最优路径]。
```

### 4.2 一句话定调话术模板

```
"[四字形容]，[四字形容]。[补充说明一句]"
```

> **示例**："金戈铁马，大器晚成。一生在冲突中寻求平衡，以智慧为舟，以坚韧为桨，终抵彼岸。"

### 4.3 四大核心特质话术模板

```
· [特质名称]（[命理依据]）
· [特质名称]（[命理依据]）
· [特质名称]（[命理依据]）
· [特质名称]（[命理依据]）
```

> **强制规则**：四大核心特质必须基于十神力量排序和用神喜忌系统，不得凭空编造。每个特质必须附带命理依据（括号内容）。

### 4.4 两大核心课题话术模板

```
· 核心课题一：[课题描述]
· 核心课题二：[课题描述]
```

### 4.5 命局结构综合评述话术模板

```
此命局结构为"[结构标签]"。[核心矛盾描述]。同时，[次要矛盾描述]。命局呈现"[底色描述]"的底色，需以[通关五行]为通关之神，化解冲突，生扶日主。[亮点描述]为巨大亮点，为[命局类型]之命提供了深厚的福泽与潜力，属于"[总结标签]"之命。
```

### 4.6 结语话术模板

```
你的命局，是"[命局定性]"的格局。你拥有[优势描述]，但也注定要经历[挑战描述]。[核心矛盾]是你的宿命，也是你的动力。它让你[正面转化描述]。

请记住，命运从来不是注定的剧本，而是先天禀赋与后天选择的合奏。真正能让人生越来越好的，不是一蹴而就的改运，而是持续、稳定、符合自身特质的选择与行动。[核心建议]。愿这份全案能成为你人生路上的长期参考，助你顺势而为，自在前行。
```

### 4.7 使用规则

1. **模板结构不可变**：话术模板的段落结构、句式顺序必须保持一致
2. **关键词可替换**：`[xxx]` 标记的部分可根据命局具体数据替换
3. **不得与L1数据矛盾**：替换的关键词必须与确定性数据一致
4. **长度控制**：每段话术不超过模板长度的150%，不少于模板长度的80%

## 五、模板字段缺失处理

当报告模板中包含不在上述对照表中的字段时：
1. 若该字段可通过预计算数据直接推导 → 使用预计算数据推导
2. 若该字段需要独立分析 → 按SKILL.md「六、核心判定规则」及 `references/03_原局分析系列/核心判定规则速查.md` 中的决策树和公式计算
3. 若该字段为纯主观建议 → 基于已有确定性数据合理展开

## 六、输出前一致性检查清单（强制）

> **强制规则**：模型在输出完整报告后，必须逐项完成以下跨章节一致性检查。任何一项不通过，必须修正后重新输出。

### 6.1 数据一致性检查

| # | 检查项 | 检查方法 | 常见错误 |
|---|--------|---------|---------|
| 1 | 命局层次评定表神煞数量 vs 神煞综合研判列表 | 数验吉神/凶煞详细列表个数，与表中统计数量对比 | 表中写"吉神9个"但详细列表有10个 |
| 2 | 十神力量排序 vs 十神藏干明细 | 检查所有藏干中的十神是否都体现在力量排序中 | 藏干中有劫财但十神力量标注"0（不现）" |
| 3 | 五行量化数据 vs 各五行养护章节 | 逐项核对全局五行量化得分与各养护章节的"命局状态" | 金行最弱（2分）但养护章节写"金行偏旺" |
| 4 | 日主旺衰结论 vs 格局判断表 | 两处对日主旺衰的表述必须一致 | 格局表写"身弱"，总评写"身强" |
| 5 | 用神五行 vs 各章节用神引用 | 所有章节中引用的用神五行必须一致 | 用神为金水，但某章写"用神为木火" |

### 6.2 文本描述准确性检查

| # | 检查项 | 检查方法 | 常见错误 |
|---|--------|---------|---------|
| 6 | 天干十神柱位标注 | 逐项检查报告中所有天干十神描述的柱位（年干/月干/时干） | 甲木在年干但写成"月干透甲木" |
| 7 | 神煞柱位标注 | 逐项检查每个神煞标注的柱位是否符合正确查法 | 月德贵人标在年柱（应在月柱） |
| 8 | 地支关系命名 | 检查拱合/半合/三合等术语使用是否正确 | 申辰拱合写成"半合水局" |
| 9 | 辰未关系 | 搜索报告中是否出现"辰未相破" | 辰未不是相破关系 |

### 6.3 完整性检查

| # | 检查项 | 检查方法 |
|---|--------|---------|
| 10 | 十神组合全量列表 | 确认列出了所有成立的吉组合和凶组合，核心组合加★标注 |
| 11 | 流月干支 | 确认流月干支来自 `liuYueList`，未自行推算 |

> **使用流程**：输出报告后 → 逐项完成本清单 → 通过后交付 → 任何一项不通过 → 修正后重新检查。
