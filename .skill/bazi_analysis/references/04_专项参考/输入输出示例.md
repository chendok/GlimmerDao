# 输入输出示例

> 本文件展示问答模式与报告模式的典型输入输出格式，供模型参考。

---

## 一、问答模式示例

### 用户输入
```
排盘JSON：
{...完整排盘JSON...}

问题：我2026年的事业运势如何？
```

### 模型输出

**2026丙午年事业运势：偏财透干，机遇与竞争并存，整体偏吉。**

命局身弱用金水，2026丙午年天干丙火偏财透出，地支午火为财星旺地。流年与大运丁丑形成"财星并透"，主当年财运机会增多，但身弱担财有限，需量力而行。

关键月份：农历三、四月（辰巳月）印星当令，贵人运旺，适合推进重要项目；农历九月（戌月）与命局寅午戌三合火局，财旺但压力大，注意财务风险。

建议：上半年积极进取，下半年稳守为主，避免大额投资。

## 二、报告模式示例

触发条件：用户明确要求"生成完整报告"或"完整命盘分析"。

输出格式：严格按 `references/02_核心规则/报告模板规范.md` 中的缺省模板或用户提供的模板填充，全维度覆盖。

确定性数据（如命局层次评分、十神排序、格局信息等）必须直接从排盘JSON的 `analysis` 字段取值，不得自行计算。
