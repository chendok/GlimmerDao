# 流派理论概述

## 传统子平派

以《渊海子平》《子平真诠》为核心经典，是八字命理的主流正统流派。以月令格局为分析核心，以十神生克为基本语言，建立正八格与变格的完整判定体系，通过用神与相神两分、格局成败救应、大运流年等维度，判断人生贵贱层次与事业高度。该派逻辑严谨、体系完整，有明确的规则可依，是命理界的通用语言，先学传统子平再学其他流派可快速上手，但偏重宏观判断，对具体事件的细节与应期断法相对不足。

## 新派命理

近现代发展起来的流派，以李涵辰等人为代表，追求将传统命理标准化、量化、公式化。核心特点为旺衰判定标准化（身强/身弱/从强/从弱四大格局）、用神忌神二分法、大运流年逐级作用链规则，否定神煞等玄学内容，重视风水环境调整。入门快、规则明确，符合现代人思维习惯，但过度量化容易忽略命理的模糊性与复杂性，进阶需回归传统经典夯实底蕴。

## 盲派命理

民间盲人传承的实战体系，口传心授，当代以段建业等人为代表进行整理传播。核心为"读象"与"做功"——通过干支类象、宫位类象、十神类象直接读出具体人事，通过宾主体用分析做功方式（制、生、合、冲）与效率，判断财富层次与取财方式。以断事精准、细节丰富、应期明确著称，擅长补充传统子平派在细节与应期方面的不足，但体系偏零散，缺乏完整的逻辑框架，取象与应期对经验悟性要求较高。
