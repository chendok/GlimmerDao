### 3.5 生克与旺衰规律

**相生**：木生火、火生土、土生金、金生水、水生木

**相克**：木克土、土克水、水克火、火克金、金克木

**反生为克**：生之太过反为害，如水多木漂、火多土焦、土多金埋

**旺相休囚死（月令视角）**：当令者旺，我生者相，生我者休，克我者囚，我克者死；春季木旺火相水休金囚土死，其余季节依此类推。

**五行改运逻辑**：补某五行，可从颜色、方位、行业、饰品、饮食、作息等多个维度同时发力，叠加效果更佳；忌某五行则对应规避。

### 6.3 "透出"定义与取格优先级

**透出**：月令藏干出现在四柱天干中（年干、月干、日干、时干均可），即为透出。

| 透出情况 | 说明 | 取格优先级 |
|----------|------|------------|
| 本气透出 | 月令本气出现在天干 | 第1优先，取本气为格 |
| 中气透出 | 月令中气出现在天干（本气不透） | 第2优先，取中气为格 |
| 余气透出 | 月令余气出现在天干（本气中气均不透） | 第3优先，取余气为格 |
| 均不透出 | 月令藏干均未出现在天干 | 第4优先，取本气为格 |

> **注意**：日干本身不算"透出"。如日主为壬水，月令为申，壬水为申之中气，但壬水是日主本身，不算"壬水中气透出"。此时应看其他天干是否有庚金（本气）或戊土（余气）透出。

## 八、常见格局判定

### 8.1 格局总论

**取格核心原则**：
- **月令为纲**：格局必须以月令为核心来源，月令是命局力量最大的地方，取格先看月令。
- **透干优先**：月令藏干透出天干者，优先取该藏干为格；本气透出优先，余气透出次之。
- **不透取本**：月令藏干均不透出天干，取月令本气为格。
- **格局分野**：分为正格（八格）与变格（从格、专旺格、化气格等）两大类。

**格局成败逻辑**：
- **成格**：用神清纯有力，相神辅助得当，无严重刑冲破害，为贵格、富格。
- **破格**：用神被克制、冲害，或相神受损，格局结构被破坏。
- **救应**：破格之后，若有其他五行克制忌神、保护用神，即为救应；有救应则为中平格局，不至大凶。
- **格局高低**：成格且救应得力为上格，成格有小瑕为中格，破格无救应为下格。

**用神与相神**：
- **用神**：月令所取之物，是格局的核心（如月令正官，则正官为用神）。
- **相神**：辅助用神成格的五行（如正官格用财生官、用印护官，财、印即为相神）。

### 8.2 正格（八格）

#### 正官格

**成格条件**：
1. 月令本气为正官，天干透出正官，为标准正官格。
2. 身强能担官，或有印星生身化官，身弱有依托。
3. 有财星生官，财官印相生，流通有情。
4. 官星清纯，不杂七杀，无严重刑冲害。

**喜忌**：喜财星生官、印星护官、身强担官；忌伤官克官、七杀混官、刑冲害官星、比劫分官。

**用神**：身弱取印、比为用；身强取财、官为用。

**破格**：伤官见官且无印制伤官为大破格；官星逢冲、逢刑、逢害；官杀混杂无去留清理。

#### 七杀格

**成格条件**：
1. 月令本气为七杀，天干透出七杀。
2. 有食神制杀，或有印星化杀，或有羊刃合杀，杀有制化。
3. 身强能担杀，或制化得当，身弱也可为格。
4. 七杀清纯，不杂正官，有制有化。

**核心口诀**："七杀有制化为权，七杀无制是祸端。"

**喜忌**：喜食神制杀、印星化杀、羊刃合杀、身强任杀；忌杀旺无制、身弱杀强、财星生杀、官杀混杂。

**用神**：身弱取印化杀、比劫帮身；身强取食伤制杀。

#### 正财格

**成格条件**：
1. 月令本气为正财，天干透出正财。
2. 身强能担财，或有比劫帮身，身弱有依托。
3. 有食伤生财，财源不断，财星清纯。
4. 无比劫重重夺财，无刑冲害财星。

**喜忌**：喜食伤生财、身强担财、官星护财；忌比劫夺财、财多身弱、刑冲财星、印星坏财。

**用神**：身弱取比劫、印星为用；身强取食伤、财星为用。

#### 偏财格

**成格条件**：
1. 月令本气为偏财，天干透出偏财。
2. 身强能担财，有食伤生财，财源广阔。
3. 偏财得地，逢财库更佳，主大富。
4. 有官杀护财，无比劫重重夺财。

**喜忌**：喜食伤生财、身强任财、官杀泄财护财；忌比劫夺财、财多身弱、冲克财库。

**用神**：同正财格，偏财更喜七杀护财、食伤生财。

#### 正印格

**成格条件**：
1. 月令本气为正印，天干透出正印。
2. 有官杀生印，印星有源，格局纯正。
3. 身弱得印生扶，印星有根，力量充足。
4. 无财星坏印，无刑冲印星。

**喜忌**：喜官杀生印、身弱得生、食伤泄秀；忌财星坏印、印多身滞、刑冲印星。

**用神**：身弱取印、比为用；身强取财、官为用。

#### 偏印格（枭神格）

**成格条件**：
1. 月令本气为偏印，天干透出偏印。
2. 身弱得印生，或有财星制印，印星不泛滥。
3. 搭配食伤，形成"食伤配印"或"枭神夺食"两种格局走向。
4. 有七杀配印，为偏贵格局，适合偏门领域。

**喜忌**：喜身弱得生、七杀配印、食伤配印；忌枭神夺食、印多身弱、财星坏印。

**用神**：身弱取印、比；身强取财、官、食伤。

#### 食神格

**成格条件**：
1. 月令本气为食神，天干透出食神。
2. 身强有食伤泄秀，秀气流通，或食神生财。
3. 食神有根，不被枭神克制，清纯有力。
4. 或食神制杀，为武贵格局。

**喜忌**：喜身强泄秀、食神生财、制杀为权；忌枭神夺食、身弱泄身太过、冲克食神。

**用神**：身强取食伤、财星；身弱取印、比。

#### 伤官格

**成格条件**：
1. 月令本气为伤官，天干透出伤官。
2. 身强伤官泄秀，才华横溢；或伤官生财，靠才华赚钱。
3. 或伤官配印，既有才华又懂分寸，为贵格。
4. 女命忌伤官太旺克官，不利婚姻。

**喜忌**：喜身强泄秀、伤官生财、伤官配印；忌伤官见官、身弱泄甚、枭神夺伤。

**用神**：身强取财、官；身弱取印、比。

### 8.3 变格

#### 从格（从弱格）

**核心成格条件**：
1. 日主无根、无比劫，满局官杀、财、食伤，日主弱极无依。
2. 无印星生扶，或印星被克制殆尽，生身之力全无。
3. 格局从势不逆，顺其弱势则吉，逆其弱势则凶。

**三类从格**：
- **从官杀格**：满局官杀，日主从官杀，喜财生官杀，忌印比帮身。
- **从财格**：满局财星，日主从财，喜食伤生财，忌比劫夺财、印星生身。
- **从儿格（从食伤）**：满局食伤，日主从儿，喜财星泄秀，忌印星克食伤。

> 真从格极少，多数为假从格，假从格局起伏大、不稳定。从格最忌印比大运，破格则灾祸连连；顺运则大富大贵。

#### 专旺格（从强格）

**核心成格条件**：
1. 日主得令、得地、得势，满局比劫、印星，无官杀克身。
2. 五行一气专旺，气势纯粹，不可逆其势。
3. 顺其气势则吉，逆其气势则凶。

**五类专旺格**：
- **曲直仁寿格**：木专旺，日主甲乙木，生于寅卯月，地支寅卯辰三会或亥卯未三合木局。
- **炎上格**：火专旺，日主丙丁火，生于巳午月，地支巳午未三会或寅午戌三合火局。
- **稼穑格**：土专旺，日主戊己土，生于辰戌丑未月，地支土多成势。
- **从革格**：金专旺，日主庚辛金，生于申酉月，地支申酉戌三会或巳酉丑三合金局。
- **润下格**：水专旺，日主壬癸水，生于亥子月，地支亥子丑三会或申子辰三合水局。

**喜忌用神**：用神为比劫、印星，顺其气势；喜食伤泄秀，流通气势。忌官杀克身，逆其气势；财星耗身亦为忌。

#### 化气格

**成格条件**：
1. 日干与月干或时干相合，化出专一五行，且得月令旺气。
2. 化神真且纯粹，无克制化神之物，无破格因素。
3. 化气成功，格局层次高，吉凶极端化。

**五组合化**：
- 甲己合化土：生于辰戌丑未月，土旺无木克，化气成。
- 乙庚合化金：生于申酉月，金旺无火克，化气成。
- 丙辛合化水：生于亥子月，水旺无土克，化气成。
- 丁壬合化木：生于寅卯月，木旺无金克，化气成。
- 戊癸合化火：生于巳午月，火旺无水克，化气成。

**喜忌用神**：以化神为用神，喜生化神之物；忌克泄化神之物，破格则凶，运势起伏极大。
