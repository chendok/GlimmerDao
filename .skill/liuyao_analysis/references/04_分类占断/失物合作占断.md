# 失物合作占断

## 一、失物占断详细指南

### 核心用神体系

失物占断需根据失物的类型确定用神，同时结合多个辅助爻位综合判断：

| 失物类型 | 主用神 | 辅助用神 | 说明 |
|---------|--------|---------|------|
| 贵重物品（金银珠宝、钱财） | 妻财爻 | 子孙爻为线索 | 财爻为物质财富的代表 |
| 文书证件（合同、证书、信件） | 父母爻 | 朱雀为文书信息 | 父母爻主文书、证件 |
| 日常用品 | 妻财爻 | 应爻为失物所在 | 日用之物亦属财的范畴 |
| 活物宠物（猫狗等） | 子孙爻 | 应爻为所在 | 子孙为动物、宠物 |
| 车辆工具 | 父母爻/妻财爻 | 应爻为所在 | 车船属父母，价值属财 |

### 失物能否找回的判断标准

**可找回的信号**：

1. **财爻旺相**：失物本身完好，未被损坏或转移，有找回的可能。
2. **财爻持世或生合世爻**：失物与自身缘分未断，可找回。
3. **财爻在内卦**：失物未出家门，在室内或近处，找回概率大。
4. **财爻在外卦但旺相**：失物在外面，但未被带走太远，仍可找回。
5. **子孙爻旺相发动**：有线索出现，有人提供信息或帮助寻找。
6. **财爻安静但得日辰冲动（暗动）**：失物突然有消息，意外找回。
7. **财爻被合**：失物在某处被固定，未被移动，待冲合之日可找回。

**难以找回的信号**：

1. **财爻休囚空破**：失物本身已损毁、被转移或彻底消失。
2. **财爻被月建冲破（月破）**：失物已遭破坏，或已远离本地。
3. **财爻旬空且休囚（真空）**：失物已不存在，或已无找回可能。
4. **财爻被兄弟爻发动克制**：失物被他人占有，难以追回。
5. **财爻在外卦且休囚**：失物在远处，且状态不佳，找回困难。
6. **财爻入墓**：失物被藏匿在隐蔽处，极难发现。
7. **财爻化回头克**：失物因自身原因导致损毁（如跌落摔坏）。
8. **世爻克财爻且世爻休囚**：自身无力寻找，找回无望。

### 被盗与遗失的判断

**被盗的信号**：

- **官鬼爻发动**：最核心的信号，官鬼为盗贼、灾祸。官鬼爻发动，尤其临玄武，明确指向被盗。
- **玄武临官鬼爻**：玄武主暗昧、盗贼，临官鬼爻则为盗窃无疑。
- **玄武临财爻**：财爻临玄武，主暗财被窃，或监守自盗。
- **官鬼爻在内卦**：内贼作案，可能是家人、熟人、同事。
- **官鬼爻在外卦**：外贼作案，陌生人盗窃。
- **官鬼爻旺相**：盗贼能力强，可能为惯犯，破案难度大。
- **官鬼爻休囚受制**：盗贼能力弱，可能被抓获，失物可追回。

**遗失（非盗窃）的信号**：

- **财爻安静无克**：单纯遗失，非他人所为。
- **财爻内卦休囚**：自己遗忘在某处，仔细寻找可发现。
- **官鬼爻安静或旬空**：非盗窃，无外人介入。

### 失物方位判断

失物方位主要通过财爻所纳地支的五行方位和八卦方位综合判断：

**地支五行方位**：

| 地支 | 方位 | 地支 | 方位 |
|------|------|------|------|
| 子 | 正北 | 午 | 正南 |
| 丑、寅 | 东北 | 未、申 | 西南 |
| 卯 | 正东 | 酉 | 正西 |
| 辰、巳 | 东南 | 戌、亥 | 西北 |

**八卦方位**（以财爻所在卦判断）：

| 卦 | 方位 | 卦 | 方位 |
|------|------|------|------|
| 乾 | 西北 | 坤 | 西南 |
| 震 | 东 | 巽 | 东南 |
| 坎 | 北 | 离 | 南 |
| 艮 | 东北 | 兑 | 西 |

**具体判断方法**：以财爻所纳地支的方位为主，以财爻所在卦的方位为辅。若二者一致，则该方位可能性极高；若不一致，则两个方位都需排查，以地支方位为优先。

### 失物所在环境判断

- **财爻在内卦初爻、二爻**：失物在地面或低处，如地面、床下、桌下。
- **财爻在内卦三爻、四爻**：失物在中等高度，如桌面、柜中、抽屉。
- **财爻在外卦五爻、上爻**：失物在高处，如柜顶、阁楼、高处架子上。
- **财爻临勾陈**：失物在土中、地下、与土地相关之处。
- **财爻临玄武**：失物在水中、近水处，或被隐藏。
- **财爻入墓**：失物在密闭空间中，如箱子、柜子、包裹内。

### 寻找时机

- **财爻旬空**：当前找不到，待填实或出旬之日可找到。
- **财爻入墓**：待冲墓之日可找到。
- **财爻被合**：待冲合之日可找到。
- **子孙爻发动**：近期有线索，可主动寻找。
- **官鬼爻受制（被克或化退）**：盗贼运衰，失物可追回。

## 二、合作占断详细指南

### 核心用神体系

| 角色 | 爻位 | 说明 |
|------|------|------|
| 自身 | 世爻 | 自身的状态、实力、诚意 |
| 对方/合伙人 | 应爻 | 对方的状态、实力、诚意 |
| 合作伙伴 | 兄弟爻 | 合作关系本身，兄弟爻为合伙人 |
| 共同利益 | 妻财爻 | 合作的经济目标和利益 |
| 官方/手续 | 官鬼爻 | 合作中的法律、合同、手续问题 |
| 文书/合同 | 父母爻 | 合作协议、合同文本 |

### 世应关系判断

合作占断中，世应关系是判断合作能否成功、是否顺利的第一要素：

**吉利组合**：

1. **应爻生世爻**：对方主动来找我合作，对方诚意十足，合作对我有利。此为最佳格局。
2. **世应比和**：双方志趣相投，实力相当，合作平等。适合长期合作。
3. **世应相合（六合）**：双方投缘，合作默契，如鱼得水。
4. **应爻旺相生合世爻**：对方实力强且愿意帮助我，合作中我受益最大。

**不利组合**：

1. **应爻克世爻**：对方压制我，合作中我处于被动，利益受损。需看世爻是否有救应。
2. **世爻克应爻**：我压制对方，合作中对方可能不满，长期合作有隐患。世爻旺相方可克制应爻，世爻休囚则克不动。
3. **世应相冲**：双方根本性矛盾，意见不合，合作难以长久。
4. **应爻空破**：对方无诚意，或实力不足，不可信赖。应爻旬空主对方心意不诚，月破主对方有变故。

### 兄弟爻的判断

兄弟爻在合作中代表"合伙人"或"竞争关系"，具有双重含义：

**兄弟爻为吉的条件**：

- 兄弟爻旺相生合世爻：合伙人能力强，且真心帮助我。
- 兄弟爻持世：自身在合作中投入全力，可作为合作伙伴。
- 兄弟爻与应爻相合：对方与合作伙伴关系良好，团队稳定。
- 兄弟爻安静：合作中无竞争和纠纷。

**兄弟爻为凶的条件**：

- 兄弟爻发动克财爻：合作中出现财务纠纷，利益分配不均，有人暗中侵吞。
- 兄弟爻旺相发动且无制：竞争激烈，多方争利，合作难以维系。
- 兄弟爻临玄武：合作伙伴有私心，暗中动手脚。
- 兄弟爻多现：参与者众多，利益关系复杂，易生纠纷。

**兄弟爻的化解**：若有官鬼爻发动克制兄弟爻，则兄弟不能为害，财务纠纷可解。

### 财爻的判断

财爻代表合作的经济目标和共同利益：

- 财爻旺相：合作项目有利可图，财运亨通。
- 财爻生合世爻：利益向我倾斜，我在合作中获利最大。
- 财爻被兄弟爻克：利益被瓜分，或合作中有经济纠纷。
- 财爻旬空：合作项目暂时无利可图，或利润未到位。
- 财爻月破：合作项目可能亏损，或无利可图。

### 卦象参考

- **游魂卦**：合作关系不稳定，易变动，需谨慎。
- **归魂卦**：合作关系稳定，可长久，但也不宜再变。
- **六合卦**：合作牢固，双方绑定紧密。
- **六冲卦**：合作易散，难以长久，不宜深度合作。

### 合作应期

- 世应相合，合日即为合作达成之期。
- 应爻旬空，填实之日为对方出现或表态之期。
- 财爻安静，被冲动之日为获利之期。

## 三、诉讼占断

### 核心用神体系

| 角色 | 爻位 | 说明 |
|------|------|------|
| 原告（主动方） | 世爻 | 世爻通常为原告或主动提起诉讼的一方 |
| 被告（被动方） | 应爻 | 应爻为被告或被诉方 |
| 法官/判决 | 官鬼爻 | 官鬼爻代表司法、裁决 |
| 诉状/证据 | 父母爻 | 父母爻为文书、诉状、证据材料 |
| 口才/辩论 | 朱雀 | 临世爻或应爻，代表口才辩论能力 |
| 诉讼结果 | 官鬼爻与世应关系 | 官鬼生合谁，谁胜诉 |

### 世应关系判断

诉讼中世应关系是判断胜负的关键：

- **世爻旺相，应爻休囚**：我胜诉，对方败诉。
- **应爻旺相，世爻休囚**：对方胜诉，我败诉。
- **世应比和**：双方势均力敌，可能和解。
- **世应相合**：有和解可能，合日可和解。
- **世应相冲**：矛盾不可调和，诉讼激烈。

### 官鬼爻的判断

- **官鬼爻生合世爻**：法官偏向我，判决对我有利。
- **官鬼爻生合应爻**：法官偏向对方，判决对我不利。
- **官鬼爻旺相**：司法程序严肃，判决有力度。
- **官鬼爻旬空**：司法程序空转，或判决难以执行。
- **官鬼爻临白虎**：判决严厉，可能有刑罚。
- **官鬼爻临朱雀**：以口舌辩论定胜负。

### 父母爻的判断

- 父母爻旺相：诉状有力，证据充分。
- 父母爻临朱雀：文书写得好，辩论占优势。
- 父母爻旬空：证据不足，文书有漏洞。
- 父母爻生合世爻：证据对我有利。

### 诉讼应期

- 官鬼爻安静，待被冲动之日为开庭或判决之期。
- 官鬼爻旬空，待填实之日为判决之期。
- 世应相合，合日可和解。

## 四、投资占断

### 核心用神体系

| 角色 | 爻位 | 说明 |
|------|------|------|
| 投资本金 | 妻财爻 | 财爻为资金、投资标的 |
| 投资回报 | 妻财爻的旺衰变化 | 财爻旺相则回报丰厚 |
| 风险因素 | 兄弟爻 | 兄弟爻为风险、亏损、竞争 |
| 自身决策 | 世爻 | 世爻为投资人的判断力和运势 |
| 投资环境 | 应爻 | 应爻为市场环境、投资对象 |
| 政策法规 | 官鬼爻 | 官鬼爻为政策风险、监管 |

### 财爻旺衰判断

**财爻旺相**：市场环境好，投资标的优质，有盈利空间。财爻持世，自身财运旺，投资容易获利。财爻临青龙，正当投资，光明正大；财爻临玄武，投机性投资，风险与收益并存。

**财爻休囚**：市场低迷，投资标的欠佳，盈利困难。财爻月破，本金可能受损；财爻旬空，资金被套，暂时无法变现。

**财爻与世爻关系**：

- 财生世：投资容易获利，财来找我。
- 世克财：需主动管理，付出努力方可获利。
- 财克世：投资反噬，可能因投资而受困。
- 世生财：为投资过度付出，回报与付出不成比例。

### 风险信号识别

1. **兄弟爻发动克财爻**：最大的风险信号，主投资亏损、破财。需看有无官鬼爻克制兄弟爻（有则风险可控）。
2. **财爻化退**：收益递减，投资回报率下降，宜及时退出。
3. **财爻化回头克**：投资反噬，本金受损，极为不利。
4. **财爻入墓**：资金被套牢，无法变现。
5. **财爻被月建冲破**：市场突变，本金可能大幅亏损。
6. **世爻休囚克财爻**：自身判断力不足，盲目投资导致亏损。
7. **官鬼爻发动克世爻**：政策风险或法律风险，投资可能触雷。
8. **游魂卦**：投资方向不定，市场变化快，不宜长期持有。

### 投资应期

- **买入时机**：财爻旬空，待填实之日为买入时机。财爻被合，待冲合之日买入。
- **卖出时机**：财爻旺相至极（如临月建日辰），为获利了结之机。财爻化退，应尽早卖出。财爻被克，待克制财爻之神被制之日为最后卖出时机。
- **盈利应期**：财爻旺相持世，当日或当月可获利。财爻安静，待被冲动之日月。财爻发动化进，待进神当值之日月。

### 不同类型投资的卦象参考

- **长期投资**：宜遇归魂卦、六合卦，主稳定长久。
- **短期投机**：宜遇动爻多、暗动之卦，主变化快、机会多。
- **稳健理财**：宜遇财爻临青龙，子孙爻旺相生财。
- **风险投资**：需慎重，若玄武临财爻且兄弟爻发动，风险极高。
