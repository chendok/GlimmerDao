# 起卦方法详解

## 一、起卦总论

起卦是六爻占断的第一步，也是最基础、最关键的操作环节。起卦方法是否正确，直接影响后续装卦、断卦的准确性。古人云"起卦如奠基"，地基不牢，则大厦将倾。六爻起卦方法有多种，其中铜钱摇卦法（以钱代蓍法）最为经典和常用，数字起卦法最为便捷，时间起卦法则有特定应用场景。

无论采用何种起卦方法，都需要遵循以下基本原则：

- **心诚则灵**：起卦时需心无杂念，专注所问之事。心不诚则卦不应，卦不应则占不准。
- **一事一占**：一次起卦只问一件事，不可一卦多问。若有多件事，需分别起卦。
- **不动不占**：没有明确的事情发生或疑问，不宜随意起卦。无事占卦，卦象容易混乱，无法准确解读。
- **不戏不占**：不可将占卦当作游戏或玩笑，亵渎之心不得正卦。

## 二、铜钱摇卦法

### 准备工具

- **铜钱**：三枚铜钱（以"乾隆通宝"等古铜钱为佳，现代硬币亦可替代，但需注意正反面的统一）。
- **记录工具**：纸和笔，用于记录每次摇卦的结果。

### 铜钱正反面的确定

铜钱摇卦法需要明确铜钱的"字面"和"背面"：

- **字面**（正面）：有文字的一面，如"乾隆通宝"字样，为"字"。
- **背面**（背面）：无文字或满文的一面，为"背"。

若使用现代硬币替代，通常以有面值数字的一面为"字"，另一面为"背"。一旦确定了正反面的定义，在整个起卦过程中不可更改。

### 完整摇卦步骤

#### 第一步：焚香静心

起卦前，净手、焚香（可选），静坐片刻，排除杂念，将注意力集中在所问之事上。心中默念所问之事，将问题清晰化、具体化。例如："我欲求问此次投资是否可行？"问题的表述宜简明具体，不宜模糊笼统。

#### 第二步：摇卦

双手合扣三枚铜钱，摇动数次（通常摇六至七次），然后松开手，让铜钱自然落在桌面或卦盘上。观察三枚铜钱的正反面情况，记录结果。此为"一摇"，得到一爻。

#### 第三步：记录结果

每次摇卦后，记录铜钱的正反面组合，并按以下规则确定爻的性质：

| 铜钱正反面 | 符号 | 爻的性质 | 说明 |
|-----------|------|---------|------|
| 一个背面，两个字面 | — | 少阳（阳爻，不发动） | 阳爻，为静爻（1背2字=7=少阳） |
| 一个字面，两个背面 | - - | 少阴（阴爻，不发动） | 阴爻，为静爻（1字2背=8=少阴） |
| 三个全是背面 | ○ | 老阳（阳爻，发动） | 阳爻发动，阳极变阴（3背=9=老阳） |
| 三个全是字面 | × | 老阴（阴爻，发动） | 阴爻发动，阴极变阳（3字=6=老阴） |

**记忆口诀**："一背为单（少阳），两背为拆（少阴），三背为重（老阳），三字为交（老阴）。"

#### 第四步：重复六次

重复第二步和第三步，共摇六次，从下往上依次记录六爻，形成完整的卦象。**第一次摇出的为初爻（最下面一爻），第六次摇出的为上爻（最上面一爻）**。此顺序不可颠倒。六次摇卦的过程中，需保持专注，不可中途中断或分心。

#### 第五步：排卦

六次摇卦完成后，得到一个六爻卦象，即为**本卦**（主卦）。将本卦中所有动爻（老阳○、老阴×）按"老阳变阴，老阴变阳"的规则变化，得到**变卦**（之卦）。若六次摇卦均无老阳或老阴（即六爻皆为少阳或少阴），则为静卦，无变卦。

### 摇卦示例

假设某次摇卦六次的结果如下（从下往上）：

| 次数 | 爻位 | 铜钱结果 | 符号 | 爻的性质 |
|------|------|---------|------|---------|
| 第6次 | 上爻 | 一字二背 | - - | 少阴 |
| 第5次 | 五爻 | 三背 | ○ | 老阳（动） |
| 第4次 | 四爻 | 二字一背 | — | 少阳 |
| 第3次 | 三爻 | 三字 | × | 老阴（动） |
| 第2次 | 二爻 | 一字二背 | - - | 少阴 |
| 第1次 | 初爻 | 二字一背 | — | 少阳 |

本卦：从下往上为 少阳、少阴、老阴、少阳、老阳、少阴，即 —、- -、- -、—、—、- -。
下卦为震（初阳二阴三阴），上卦为兑（四阳五阳上阴），本卦为《泽雷随》。

变卦：三爻老阴变阳，五爻老阳变阴。变后下卦为离（初阳二阴三阳），上卦为震（四阳五阴上阴），变卦为《雷火丰》。

## 三、数字起卦法

数字起卦法起源较晚，但因其便捷灵活，在现代使用广泛。数字起卦法以数字对应八卦，通过计算确定上下卦和动爻。

### 八卦与数字的对应

| 数字 | 卦名 | 卦象 | 五行 |
|------|------|------|------|
| 1 | 乾 | ☰ | 金 |
| 2 | 兑 | ☱ | 金 |
| 3 | 离 | ☲ | 火 |
| 4 | 震 | ☳ | 木 |
| 5 | 巽 | ☴ | 木 |
| 6 | 坎 | ☵ | 水 |
| 7 | 艮 | ☶ | 土 |
| 8 | 坤 | ☷ | 土 |

数字大于8时，除以8取余数。余数为0则为8（坤）。

### 三位数起卦法

这是最常用的数字起卦方法，需要三个数字（可以随机想到、报数、翻书页码、车牌号等）：

- **第一个数字**：除以8，余数对应上卦。
- **第二个数字**：除以8，余数对应下卦。
- **第三个数字**：除以6，余数对应动爻（余数为0则为第6爻）。

**示例**：三个数字为 7、15、9。

- 7 ÷ 8 = 0 余 7 → 上卦为艮（☶）
- 15 ÷ 8 = 1 余 7 → 下卦为艮（☶）
- 9 ÷ 6 = 1 余 3 → 动爻为第3爻

本卦为《艮为山》（上艮下艮），动爻为第3爻。变卦为：第3爻阴变阳，上卦艮变坤，下卦不变，变卦为《山地剥》。

### 报数起卦法

请求卦者随口报出三个数字（1-100之间的整数），按三位数起卦法处理。注意：报数时不必刻意选择，想到什么数字就报什么数字，越自然越好。

### 时间起卦法

以起卦时的年、月、日数字为依据起卦：

- **年数**：取年份的后两位数字。如2024年，取24。（或以农历年地支序数：子1、丑2……亥12）
- **月数**：取农历月份。（正月为1，二月为2，……十二月为12）
- **日数**：取农历日期。

**上卦**：（年数 + 月数 + 日数）÷ 8，取余数。
**下卦**：（年数 + 月数 + 日数 + 时辰数）÷ 8，取余数。
**动爻**：（年数 + 月数 + 日数）÷ 6，取余数。

**说明**：时间起卦法的变体较多，不同流派对年、月、日、时的处理方式略有差异。上述为较常见的通用方法。时间起卦法的优势在于不需要求卦者主动参与（如摇卦、报数），适合用于客观事件的时间推演。

### 其他数字起卦变体

- **手机号起卦**：取手机号后三位数字，按三位数起卦。
- **车牌号起卦**：取车牌号数字部分，按三位数起卦（不足三位向前补0）。
- **随机数起卦**：使用随机数生成器生成三个数字，按三位数起卦。但需注意，电子设备生成的随机数并非真正的"随机"，其"灵应"程度可能不如人工摇卦。

## 四、起卦注意事项

### 心诚则灵

"心诚则灵"不是迷信，而是心理学上的专注与投射。起卦时若能心无杂念、专注一事，则潜意识能够通过卦象进行表达。反之，若心猿意马、三心二意，卦象容易混乱，无法准确反映所问之事。

**具体做法**：起卦前深呼吸三次，闭上眼睛，在心中清晰地说出所问之事。例如："弟子XXX，今有XX之事，敢问吉凶如何？"这既是仪式，也是心理聚焦。

### 一事一占

一次起卦只能问一件事。若同时有多件事需要占问，应分别起卦。不可一卦多问，否则卦象信息混杂，无法准确解读。

**正确做法**：先问最重要的事，起一卦，解卦；再问次重要的事，另起一卦，再解卦。

**错误做法**：摇一次卦，问"我今年财运如何？婚姻如何？健康如何？"——此为大忌。

### 不动不占

没有明确的事情发生或真正的疑问，不宜随意起卦。古人云"无事不占"，"不动不占"。所谓"动"，是指事情已经有了变化或引起了你的关注，而不是凭空想象。

**可占的情况**：实际发生了某事、即将做出某个决定、对某件事有明确的疑虑。

**不可占的情况**：纯粹出于好奇、想测试占卦是否准确、闲来无事随便问问。

### 不戏不占

不可将占卦当作游戏。戏占不仅得不到准确的卦象，长此以往还会形成不良的心理暗示，影响对自身判断力的信心。

### 起卦环境

- 尽量选择安静、整洁的环境，避免嘈杂、杂乱。
- 使用专门的卦盘、卦布或干净桌面，保持铜钱落点的清晰。
- 起卦过程中不可被打断，若被打断，应重新开始。

### 起卦工具

- 铜钱以三枚为一套，不可混用不同套的铜钱。
- 铜钱应保持清洁，不用时妥善保管，不可随意丢弃。
- 若使用现代硬币，应固定使用同一套硬币，不可随意更换。

## 五、月建日辰的确定方法

### 月建的确定

月建即起卦当月的月令地支，是判断爻之旺衰的第一主宰。月建根据农历月份确定：

| 农历月份 | 月建 | 四季 | 五行旺衰 |
|---------|------|------|---------|
| 正月 | 寅 | 春 | 木旺、火相、水休、金囚、土死 |
| 二月 | 卯 | 春 | 木旺、火相、水休、金囚、土死 |
| 三月 | 辰 | 春末 | 土旺、金相、火休、木囚、水死 |
| 四月 | 巳 | 夏 | 火旺、土相、木休、水囚、金死 |
| 五月 | 午 | 夏 | 火旺、土相、木休、水囚、金死 |
| 六月 | 未 | 夏末 | 土旺、金相、火休、木囚、水死 |
| 七月 | 申 | 秋 | 金旺、水相、土休、火囚、木死 |
| 八月 | 酉 | 秋 | 金旺、水相、土休、火囚、木死 |
| 九月 | 戌 | 秋末 | 土旺、金相、火休、木囚、水死 |
| 十月 | 亥 | 冬 | 水旺、木相、金休、土囚、火死 |
| 十一月 | 子 | 冬 | 水旺、木相、金休、土囚、火死 |
| 十二月 | 丑 | 冬末 | 土旺、金相、火休、木囚、水死 |

**注意**：月建的确定以农历（阴历）为准，而非公历。农历月份与公历月份有大约一个月的偏差。同时，需注意二十四节气中的"节"为月建更替的时间点（如立春为寅月之始），而非农历初一。

### 日辰的确定

日辰即起卦当日的日干支，是判断爻之旺衰的第二主宰，也是确定旬空、六神排布的基础。

日辰的推算需要借助万年历进行查询，因为干支纪日没有简单的计算公式。现代可以通过手机APP、万年历网站等工具快速查询。

**日辰的作用**：
- 与月建共同判断爻的旺衰（日辰生克各爻）。
- 确定旬空（根据日辰所在旬，判断旬空地支）。
- 确定六神（根据日干，确定初爻六神）。
- 判断暗动/日破（日辰冲动静爻）。

### 确定月建日辰的实用工具

在数字化时代，推荐使用以下工具快速确定月建和日辰：

1. **万年历APP**：可快速查询农历日期、月建、日干支。
2. **六爻排盘工具**：输入公历日期和时间，自动计算月建、日辰、旬空，并完成排卦。
3. **传统万年历书籍**：在没有电子设备的情况下使用。

## 六、六神排布方法

### 六神排布的基本规则

六神（青龙、朱雀、勾陈、螣蛇、白虎、玄武）的排布以起卦当日的**日干**为依据，确定初爻六神，然后自初爻至上爻按固定顺序排列。

### 日干与初爻六神的对应

| 日干 | 初爻六神 | 别名 |
|------|---------|------|
| 甲、乙 | 青龙 | 甲乙为木，青龙属木，同气相求 |
| 丙、丁 | 朱雀 | 丙丁为火，朱雀属火，同气相求 |
| 戊 | 勾陈 | 戊为阳土，勾陈属土，同类相配 |
| 己 | 螣蛇 | 己为阴土，螣蛇属土，同类相配 |
| 庚、辛 | 白虎 | 庚辛为金，白虎属金，同气相求 |
| 壬、癸 | 玄武 | 壬癸为水，玄武属水，同气相求 |

**六神循环顺序**：青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武 → 青龙 → ……

### 排布步骤

**第一步**：确定起卦当日的日干。例如：甲子日，日干为甲；丙寅日，日干为丙；戊辰日，日干为戊。

**第二步**：根据日干确定初爻六神。甲日 → 初爻为青龙；丙日 → 初爻为朱雀；戊日 → 初爻为勾陈；以此类推。

**第三步**：从初爻开始，按六神循环顺序向上排列至六爻。

### 排布示例

**示例一**：甲子日起卦，日干为甲。

| 爻位 | 六神 |
|------|------|
| 上爻（第六爻） | 玄武 |
| 五爻 | 白虎 |
| 四爻 | 螣蛇 |
| 三爻 | 勾陈 |
| 二爻 | 朱雀 |
| 初爻（第一爻） | 青龙 |

**示例二**：丙寅日起卦，日干为丙。

| 爻位 | 六神 |
|------|------|
| 上爻（第六爻） | 青龙 |
| 五爻 | 玄武 |
| 四爻 | 白虎 |
| 三爻 | 螣蛇 |
| 二爻 | 勾陈 |
| 初爻（第一爻） | 朱雀 |

**示例三**：庚午日起卦，日干为庚。

| 爻位 | 六神 |
|------|------|
| 上爻（第六爻） | 螣蛇 |
| 五爻 | 勾陈 |
| 四爻 | 朱雀 |
| 三爻 | 青龙 |
| 二爻 | 玄武 |
| 初爻（第一爻） | 白虎 |

### 六神排布口诀

"甲乙起青龙，丙丁起朱雀，戊日起勾陈，己日起螣蛇，庚辛起白虎，壬癸起玄武。"

记住此口诀，根据日干即可快速确定初爻六神，然后按顺序向上排布即可。

### 注意事项

- 六神排布与变卦无关，变卦不另排六神，沿用本卦的六神分布。
- 六神为辅助判断因素，不可脱离六亲、爻位、旺衰等核心要素单独使用。
- 六神的吉凶含义需结合具体占问场景、所临爻的六亲和旺衰等综合判断。
