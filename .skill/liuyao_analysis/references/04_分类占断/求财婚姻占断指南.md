# 求财婚姻占断指南

## 一、求财占断

### 核心用神

求财占断以妻财爻为用神，兼看子孙爻（财之原神）、兄弟爻（财之忌神）和世爻（自身财运）。

### 财爻旺衰判断

**财爻旺相**：财爻得月建日辰生扶，或自身发动，为财气旺盛。财爻临青龙，主正当财利，财路亨通。财爻持世，主财来找我，得财容易。

**财爻休囚**：财爻被月建日辰克制，或休囚安静，为财气不足。财爻月破，为财源枯竭；财爻旬空，为财不入手。

**财爻多现**：一卦中财爻多现，主财路多端，但需看哪个财爻旺相，以旺者为用。

### 财爻与世爻关系

| 关系 | 含义 | 吉凶 |
|------|------|------|
| 财生世 | 财来就我，不劳而获 | 大吉 |
| 世克财 | 我去求财，需主动经营 | 中吉，需努力 |
| 财克世 | 财来伤我，得财反有祸 | 凶 |
| 世生财 | 为财所累，付出多回报少 | 凶 |
| 财世比和 | 财运平稳，不多不少 | 平 |

### 兄弟爻克财

兄弟爻为财爻之忌神，兄弟爻发动（尤其是动爻化进）必克财爻，主破财、损耗、竞争。应对之法：

1. 若有官鬼爻发动克制兄弟爻（制忌神），则破财可免。
2. 若子孙爻发动生财爻（原神有力），财有源，可弥补兄弟之克。
3. 兄弟爻旬空或月破，克力大减，破财不严重。

### 得财应期判断

- 财爻旺相持世，当日、当月即可得财。
- 财爻旬空，待填实或出旬之日得财。
- 财爻安静，待被冲动之日得财。
- 财爻被合，待冲开之日得财。
- 财爻发动化进，日进斗金，待进神之日得财。
- 财爻发动化退，财运渐退，宜早收手。

### 破财信号识别

1. 兄弟爻发动克财爻，且无官鬼爻克制兄弟。
2. 财爻被月建冲破，财源枯竭。
3. 财爻旬空且休囚，真空之财，得而复失。
4. 世爻克财爻且世爻休囚，力不从心，求财难成。
5. 财爻发动化回头克，得财反有损失。

### 正财偏财区分

- **正财**：财爻临青龙，或财爻持世，为正当职业收入。
- **偏财**：子孙爻生财爻，或财爻临玄武，为投资、投机、意外之财。
- **暗财**：财爻临玄武且旺相，为灰色收入、不可告人之财。

## 二、婚姻占断

### 核心用神

| 占问者 | 配偶用神 | 辅助用神 |
|--------|---------|---------|
| 男占婚姻 | 妻财爻 | 世爻为自身，应爻为对方/婚姻宫 |
| 女占婚姻 | 官鬼爻 | 世爻为自身，应爻为对方/婚姻宫 |

### 世应关系分析

世应关系是婚姻占断的核心，代表夫妻双方的关系状态：

- **世应相生**：夫妻互相扶持，感情深厚。应生世，对方爱慕我；世生应，我爱慕对方。
- **世应相合**（六合）：夫妻恩爱，婚姻美满，天作之合。
- **世应比和**：夫妻志同道合，平等相处。
- **世应相冲**：夫妻性格不合，矛盾冲突多。
- **世应相克**：夫妻相克，关系紧张。应克世，对方压制我；世克应，我压制对方。

### 财爻/官爻旺衰判断

**财爻旺相**（男占）：妻子贤惠，旺夫益子，婚姻幸福。财爻临青龙，主妻子美貌贤淑。

**财爻休囚**（男占）：妻子体弱，或婚姻不美满。财爻月破，主妻子有灾；财爻旬空，主缘分未到或妻子不在身边。

**官爻旺相**（女占）：丈夫有才干，事业有成，婚姻稳定。官爻临青龙，主丈夫正直有为。

**官爻休囚**（女占）：丈夫平庸，或婚姻不幸。官爻月破，主丈夫有灾；官爻旬空，主缘分未到或丈夫不在身边。

### 桃花星判断

桃花星为子、午、卯、酉四正位：

- 财爻/官爻纳地支为子、午、卯、酉，且为桃花位，主配偶容貌出众。
- 桃花临青龙，为正当桃花，主婚姻美满。
- 桃花临玄武，为暗桃花，主婚外情或第三者。
- 桃花爻发动，主感情活跃，但也主感情多变。

### 婚姻质量判断

1. **财官爻持世**：夫妻感情好，婚姻美满。
2. **财官爻临应爻**：对方主动，婚姻缘分深。
3. **世应皆旺相**：夫妻二人条件匹配，婚姻稳定。
4. **兄弟爻发动克财爻**（男占）：妻子有灾，或婚姻有第三者（兄弟为竞争者）。
5. **子孙爻发动克官爻**（女占）：丈夫有灾，或对丈夫不满。

### 二婚/多婚信号

1. 财爻/官爻多现且皆旺相，主有多段婚姻或感情经历。
2. 财爻/官爻化退，主婚姻走下坡路，有离婚风险。
3. 世应相冲克，且无解救，主婚姻难长久。
4. 桃花爻临玄武发动，主婚外情导致婚姻破裂。
5. 游魂卦主婚姻不稳定，归魂卦主婚姻有归着。

### 婚姻应期判断

- 财爻/官爻旬空，待填实之日为婚期。
- 财爻/官爻安静，待被冲动之日为婚期。
- 世应相合，合日即为婚期。
