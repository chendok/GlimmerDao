# 官运疾病出行占断

## 一、官运/考试占断

### 核心用神

| 占问类型 | 主用神 | 辅助用神 |
|---------|--------|---------|
| 求官/升迁 | 官鬼爻 | 世爻为自身，财爻为官之原神，父母爻为文书 |
| 考试/功名 | 父母爻（文书） | 官鬼爻为名次，朱雀主文采，世爻为自身 |

### 官鬼爻旺衰判断

**官爻旺相**：得月建日辰生扶，或自身发动，主官运亨通，有晋升之机。官爻临青龙，主名正言顺升迁；官爻临白虎，主武职、执法类官职。

**官爻休囚**：被月建日辰克制，或休囚安静，主官运不济，难有升迁。官爻月破，主有降职或罢免之灾；官爻旬空，主职位不保或有名无实。

**官爻持世**：官运在身，求官易得，在职者位高权重。

**官爻克世**：被权势所累，或官场倾轧，需有解救（如子孙爻制官，或得月建日辰生世）。

### 父母爻与考试

父母爻为文书、成绩、证书，在考试占断中至关重要：

- 父母爻旺相，主成绩优异，考试顺利。
- 父母爻临朱雀，主文采出众，口试/面试表现好。
- 父母爻持世，主自己准备充分，把握大。
- 父母爻旬空，主准备不足或考试落空。
- 父母爻月破，主成绩不理想或有意外。

### 官鬼爻与考试

官鬼爻在考试中代表名次、录取：

- 官爻旺相生合世爻，主金榜题名。
- 官爻克制世爻，主考试压力大，或名落孙山。
- 朱雀临官爻，主口试/面试中有官非口舌。

### 综合判断要点

1. 世爻旺相为自身条件好，有竞争力。
2. 官爻与父母爻皆旺相，为最吉，求官考试皆利。
3. 财爻旺相生官爻，主以财力得官，或通过经济手段促进仕途。
4. 子孙爻旺相克官爻，求官不利（子孙为克官之神），但考试中子孙爻为解压之神，可缓解紧张。

## 二、疾病占断

### 核心用神

| 角色 | 爻位 | 说明 |
|------|------|------|
| 患者 | 世爻 | 世爻为问卦者自身（或代占时以相应六亲为用神） |
| 疾病 | 官鬼爻 | 官鬼为病，官鬼旺则病重，官鬼衰则病轻 |
| 医药 | 子孙爻 | 子孙为医药、医生，子孙旺则药有效 |
| 病因 | 官鬼爻所临五行 | 火为热症，水为寒症，金为筋骨伤，木为肝胆，土为脾胃 |

### 疾病轻重判断

**官鬼爻旺相**：病重。官鬼发动，病势发展快；官鬼临白虎，为急症、重症、需手术；官鬼临螣蛇，为怪病、精神类疾病。

**官鬼爻休囚**：病轻。官鬼旬空，病不严重或为虚惊；官鬼月破，病情好转或痊愈。

**世爻旺衰**：世爻旺相，患者抵抗力强，恢复快；世爻休囚空破，患者体弱，恢复慢。

### 医药判断

**子孙爻旺相**：医药有效，医生得力。子孙爻临青龙，名医良药；子孙爻临白虎，手术有效。

**子孙爻休囚**：医药无效，药不对症。子孙爻被克，医药难以发挥作用。

### 六神断病

| 六神 | 疾病类型 |
|------|---------|
| 青龙 | 以酒色过度为主因，或肝病、经络病 |
| 朱雀 | 热症、炎症、发烧、口舌之疾 |
| 勾陈 | 慢性病、肿瘤、脾胃病、肿胀 |
| 螣蛇 | 怪病、精神疾病、神经衰弱、虚惊 |
| 白虎 | 急症、血光、外伤、手术、骨折 |
| 玄武 | 隐疾、肾病、泌尿系统、暗病、阴虚 |

### 疾病应期判断

- 官鬼爻旺相发动，逢官鬼爻被克之日（子孙爻当值之日）为病愈之期。
- 子孙爻旺相发动，当日或近期即可痊愈。
- 官鬼爻旬空，待填实之日病发。
- 世爻入墓，病情危重，需待冲墓之日。

## 三、出行占断

### 核心用神

世爻为出行者，克世之神为路途障碍，应爻为目的地。

### 出行判断要点

1. **世爻旺相**：出行顺利，行者精神饱满。
2. **世爻休囚空破**：不宜出行，或出行有险。
3. **世爻被官鬼爻克制**：出行有灾，需注意。
4. **世爻临白虎**：出行有血光之险，注意交通安全。
5. **世爻被合**：出行被绊，难以成行或途中滞留。
6. **应爻生世爻**：目的地有利，出行有收获。
7. **应爻克世爻**：不宜去该方向，可能有险。

### 出行应期

- 世爻旬空，待填实或出旬之日出行。
- 世爻被合，待冲开之日出行。
- 世爻安静，待被冲动之日出行。

## 四、失物占断

### 核心用神

- 贵重物品：妻财爻
- 文书包裹：父母爻
- 失物所在：应爻
- 盗贼：官鬼爻（临玄武为盗贼）

### 判断要点

1. 财爻旺相，失物可寻；财爻休囚空破，失物难寻。
2. 财爻临玄武，被盗，难以寻回。
3. 财爻入墓，失物在隐蔽处，或被藏匿。
4. 财爻在内卦，失物在家中；在外卦，失物在外面。
5. 官鬼爻临玄武，确为被盗；官鬼爻受制，盗贼可擒。

## 五、合作占断

### 核心用神

世爻为自身，应爻为对方/合伙人，兄弟爻为合作伙伴。

### 判断要点

1. **世应相生相合**：合作顺利，双方投缘。
2. **世应相冲相克**：合作困难，不宜合作。
3. **兄弟爻旺相**：合伙人能力强，但也要防其有私心。
4. **兄弟爻克财爻**：合作中财务纠纷，需注意利益分配。
5. **应爻生世爻**：对方诚意足，合作对我有利。
6. **世爻生应爻**：我需付出更多，需评估是否值得。
7. **游魂卦**：合作关系不稳定，易变动。
8. **归魂卦**：合作关系稳定，可长久。
