# 旬空月破暗动详解

## 一、旬空（空亡）

### 旬空概念

旬空是六爻筮法中的重要概念。天干有十，地支有十二，以天干配地支，每旬（十天）必有两个地支无天干相配，这两个地支即为"旬空"或"空亡"。爻所纳地支若逢旬空，则该爻力量暂时不显，待出旬或填实后方可发挥效用。

### 六甲旬空表

六甲旬空以日辰干支为依据推算：

| 旬 | 起止日干支 | 旬空地支 | 说明 |
|----|----------|---------|------|
| 甲子旬 | 甲子 → 癸酉 | 戌、亥 | 子丑寅卯辰巳午未申酉（戌亥空） |
| 甲戌旬 | 甲戌 → 癸未 | 申、酉 | 戌亥子丑寅卯辰巳午未（申酉空） |
| 甲申旬 | 甲申 → 癸巳 | 午、未 | 申酉戌亥子丑寅卯辰巳（午未空） |
| 甲午旬 | 甲午 → 癸卯 | 辰、巳 | 午未申酉戌亥子丑寅卯（辰巳空） |
| 甲辰旬 | 甲辰 → 癸丑 | 寅、卯 | 辰巳午未申酉戌亥子丑（寅卯空） |
| 甲寅旬 | 甲寅 → 癸亥 | 子、丑 | 寅卯辰巳午未申酉戌亥（子丑空） |

**推算方法**：先确定日辰干支属于哪一旬，然后查表中该旬对应的旬空地支。例如日辰为"甲子"日，属甲子旬，则戌、亥为旬空。卦中若有爻纳戌或亥，则该爻旬空。

### 旬空在不同情况下的含义

**1. 旺不为空**

爻虽旬空，但得月建或日辰生扶而旺相，虽有空之形，实有旺之气，待出旬即可发挥作用。此为"旺不为空"，占事仍有成功之机。

**2. 动不为空**

爻虽旬空，但自身发动，发动即有力，旬空之弊大减。动爻旬空，待出旬或填实之日即为应期。

**3. 出旬填实**

爻旬空后，待日辰轮转到空亡地支之日（填实），或过了该旬（出旬），爻的力量恢复。如戌亥空，待戌日或亥日即为填实；过了甲子旬进入甲戌旬，戌亥不再为空，即为出旬。

**4. 真空与假空**

- **假空**：爻虽旬空但旺相、发动、得生扶，此为假空，待时而用。
- **真空**：爻旬空且休囚无气、安静、受克，此为真空，虽有若无，难以发挥作用。

**5. 旬空在各占问中的含义**

| 占问类型 | 旬空含义 |
|---------|---------|
| 求财 | 财爻旬空，财不入手，待填实之日可得 |
| 出行 | 世爻旬空，行期未定，心不在焉 |
| 婚姻 | 财/官爻旬空，对方心意不诚，或缘分未到 |
| 疾病 | 官鬼爻旬空为病不重，世爻旬空则患者精神萎靡 |
| 失物 | 财爻旬空，失物难寻，或尚未丢失（虚惊） |
| 行人 | 世爻旬空，行人暂不归 |

## 二、月破

### 月破概念

爻所纳地支与月建地支相冲，即为月破。月破之爻力量衰弱，难以为用。月破是判断爻之旺衰的重要负面因素。

### 月破判断

| 月建 | 月破地支 |
|------|---------|
| 正月（寅月） | 申 |
| 二月（卯月） | 酉 |
| 三月（辰月） | 戌 |
| 四月（巳月） | 亥 |
| 五月（午月） | 子 |
| 六月（未月） | 丑 |
| 七月（申月） | 寅 |
| 八月（酉月） | 卯 |
| 九月（戌月） | 辰 |
| 十月（亥月） | 巳 |
| 十一月（子月） | 午 |
| 十二月（丑月） | 未 |

### 月破的含义

1. **月破主衰败**：爻逢月破，力量大减，如枯木朽株，难以为用。

2. **月破之爻**：爻逢月破，即使得日辰生扶，力量也有限。月破又逢日克，则彻底无用。

3. **出月不破**：月破之爻，过了该月则不再为破。如申月破寅，到了酉月，寅爻不再月破。

4. **填实不破**：当日辰轮转到月破地支之日，如寅月逢申日，申爻得日辰填实，月破之弊暂消。

5. **月破与旬空同现**：某爻既月破又旬空，为"真空真破"，极其不利，该爻所代表的人事物难以发挥作用。

## 三、暗动与日破

### 暗动

静爻被日辰冲动，且该爻旺相有力，即为"暗动"。暗动之爻力量强于静爻，弱于明动之爻，但仍有生克能力。

**暗动条件**：
- 爻为静爻（非动爻）
- 爻所纳地支被日辰所冲
- 爻旺相有力（得月建生扶，或自身旺相）

**暗动含义**：事情突然发生，出乎意料，或暗中有人相助/阻挠。

### 日破

静爻被日辰冲动，但该爻休囚无力，即为"日破"。日破之爻形同虚设，毫无力量。

**日破条件**：
- 爻为静爻
- 爻所纳地支被日辰所冲
- 爻休囚无力（被月建克制，或自身休囚）

**暗动与日破的区分**：关键在于爻的旺衰。旺相被冲为暗动，有力量；休囚被冲为日破，无力量。

## 四、入墓

### 入墓概念

入墓是六爻中重要的特殊状态，爻入墓后被"关住"，力量暂时无法发挥。入墓分三种：

1. **日墓**：爻所纳地支被日辰所墓。如辰为水土之墓，若爻纳辰或戌或丑或未，日辰逢辰，即为入墓。但需注意：辰为水土之墓，戌为火之墓，丑为金之墓，未为木之墓。

2. **动墓**：爻被其他动爻所墓。如寅爻动变出未爻，木入未墓。

3. **化墓**：爻发动后，变爻为墓库之地。如子爻动变出辰爻，水入辰墓。

### 入墓的含义

入墓之爻，力量被压制，暂时无法发挥作用。在占病中，用神入墓为病情严重甚至昏迷；在占行人中，世爻入墓为被困不能归；在求财中，财爻入墓为财被冻结。

## 五、动变规则

### 化进

爻动化出同类五行，且地支向前推进一位，为化进。如寅化卯（木化进）、巳化午（火化进）、申化酉（金化进）、亥化子（水化进）。化进为吉，主事情向前发展，力量增强。

### 化退

爻动化出同类五行，且地支向后倒退一位，为化退。如卯化寅（木化退）、午化巳（火化退）、酉化申（金化退）、子化亥（水化退）。化退为凶，主事情倒退，力量减弱。

### 化生

爻动化出变爻，变爻回头生原爻，为化生。如寅爻动化出子爻，子水生寅木。化生为吉，主事情有转机，得贵人相助。

### 化绝

爻动化出变爻，变爻为原爻之绝地。如子水绝于巳，若子爻动化出巳爻，即为化绝。化绝为凶，主事情走到尽头，难以挽回。十二长生绝地：木绝于申、火绝于亥、金绝于寅、水绝于巳、土绝于巳。

### 化回头克

爻动化出变爻，变爻回头克原爻。如寅爻动化出酉爻，酉金克寅木。化回头克为最凶的动变之一，主自身行为反受其害。
