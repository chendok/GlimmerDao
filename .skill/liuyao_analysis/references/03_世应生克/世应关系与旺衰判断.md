# 世应关系与旺衰判断

## 一、世应关系总论

世爻和应爻是六爻卦中最重要的两个爻位，世爻代表占问者自身或所问之事的主体，应爻代表所问之事的外部对象、对方或环境。世应关系是判断事情成败、人际关系、合作前景的核心依据。

## 二、世应生克分析

### 应爻生世爻

应爻生世爻，主对方主动来就我，事情顺遂，对方有利我之意。在合作中表示对方诚意十足；在婚姻中表示对方钟情于我；在诉讼中表示对方愿意和解。吉爻生世更吉，凶爻生世虽有不利但仍有转机。

### 世爻生应爻

世爻生应爻，主我主动去就对方，需要付出努力。在求财中表示需要主动经营；在婚姻中表示我追求对方，付出较多；在合作中表示我需要主动推进。世爻旺相则付出有回报，世爻休囚则力不从心。

### 世应比和

世爻与应爻五行相同（比和），主双方地位平等、志趣相投。在合作中为良好伙伴关系；在婚姻中为夫妻志同道合；在竞争中也主势均力敌。但比和也可能意味着竞争或僵持。

### 世爻克应爻

世爻克应爻，主我方能克制对方，占据主动。在竞争中表示我胜于对方；在合作中表示我主导局面。但需注意，世爻旺相方可制应，世爻休囚则克不动应爻，反而可能被反噬。

### 应爻克世爻

应爻克世爻，主对方克制我，形势对我不利。在求财中表示财来伤我，得财反有祸；在合作中表示对方压制我；在婚姻中表示对方强势，关系不和谐。此为凶象，需看世爻是否有救应（如月建日辰生扶或被其他爻生合）。

### 世应相冲

世爻与应爻地支相冲（子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲），主双方有根本矛盾，关系紧张，事情多变。若世应旺相相冲，冲突激烈但可化解；若休囚相冲，则关系破裂。

### 世应相合

世爻与应爻地支相合（六合或三合），主双方关系融洽，事情顺利。其中六合（子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合）为最吉，主天然契合；三合（申子辰、亥卯未、寅午戌、巳酉丑）次之，主有第三方因素促成。

## 三、世应在不同占问中的角色

| 占问类型 | 世爻角色 | 应爻角色 |
|---------|---------|---------|
| 求财 | 自身财运 | 财源环境、交易对象 |
| 婚姻 | 自身 | 配偶/对象 |
| 官运 | 自身 | 职位/上司 |
| 考试 | 自身 | 考官/成绩 |
| 合作 | 自身 | 合伙人 |
| 诉讼 | 原告（或被告） | 对方 |
| 出行 | 行者 | 目的地 |
| 失物 | 失主 | 失物所在 |

## 四、爻的旺衰判断

爻的旺衰是判断吉凶的核心基础，需综合月建、日辰、动爻三方面因素。

### 月建旺衰

月建（占卦当月的月令地支）对爻的影响最大，分五个层次：

| 月建关系 | 名称 | 含义 |
|---------|------|------|
| 月建生爻 | 相 | 旺相，爻得月建生扶，力量增强 |
| 月建同爻 | 旺 | 最旺，爻与月建五行相同 |
| 爻生月建 | 休 | 休囚，爻生月建，泄气 |
| 爻克月建 | 囚 | 休囚，爻克月建，耗力 |
| 月建克爻 | 死 | 最衰，爻被月建克制 |

**月建旺衰口诀**："当令者旺，我生者相，生我者休，克我者囚，我克者死。"即：与月建五行相同为旺，月建生之为相，生月建者为休，克月建者为囚，被月建克者为死。

### 日辰旺衰

日辰（占卦当日的日支）对爻的影响仅次于月建：

| 日辰关系 | 名称 | 含义 |
|---------|------|------|
| 日辰生爻 | 相 | 得日生扶，有力 |
| 日辰同爻 | 旺 | 临日，最有力 |
| 爻生日辰 | 休 | 泄气于日 |
| 爻克日辰 | 囚 | 耗力于日 |
| 日辰克爻 | 死 | 受日克制 |

日辰的作用较为即时和短暂，月建的作用较为持久和深远。爻既得月建生扶又得日辰生扶，为最旺；既被月建克制又被日辰克制，为最衰。

### 动爻的影响

1. **动爻生克**：动爻对静爻有生克权。动爻为兄弟则克财爻，动爻为子孙则生财爻。动爻对静爻的生克力量强于静爻之间的生克。

2. **动而化变**：爻发动后产生变爻，变爻对原爻有回头生、回头克、化进、化退等影响。变爻回头生为吉，变爻回头克为凶。

3. **三合局**：三个动爻可形成三合局（如申子辰合水局），力量极大，能直接改变卦中五行格局。

## 五、原神、忌神、仇神

### 原神

生用神者为原神。如财爻之原神为子孙爻，官爻之原神为财爻。原神旺相，用神有根，事有转机；原神休囚受克，用神失其根源，事难成。

### 忌神

克用神者为忌神。如财爻之忌神为兄弟爻，官爻之忌神为子孙爻。忌神发动，用神受克，事有不吉；忌神安静或受制，用神无忧。

### 仇神

克原神而生存忌神者为仇神。如财爻之原神为子孙，子孙之忌神为父母，父母即为仇神（克子孙而生存兄弟忌神）。仇神发动，间接损害用神，不可不察。

### 生克关系链

```
原神 →（生）→ 用神 →（被克）→ 忌神
  ↑                ↑
  └（被克）── 仇神 ──（生）┘
```

**断卦要诀**：用神旺相，原神有力，忌神被制，则为吉象；用神休囚，忌神发动，原神被克，则为凶兆。
