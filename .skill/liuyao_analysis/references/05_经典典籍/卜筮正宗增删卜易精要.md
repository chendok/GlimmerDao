# 卜筮正宗与增删卜易精要

## 一、《卜筮正宗》精要

### 成书背景与作者

《卜筮正宗》由清代王洪绪（字维德，号林屋山人）编纂，成书于康熙年间。王洪绪出身医学世家，其父王若谷为当时名医。王洪绪本人精通医术，尤擅外科，著有《外科证治全生集》。同时，他深研易学，博采众长，将六爻纳甲筮法的各家理论进行了系统化整理，编纂成《卜筮正宗》一书。

王洪绪在自序中言："卜筮之道，原本于《易》，其流为京房、郭璞、李淳风、袁天罡、陈抟、邵雍诸家，代有传人。然其书浩繁，学者望洋而叹。"他编纂此书的目的，正是为了"删繁就简，撮其精要"，使六爻筮法成为一门可以系统学习的学问。

### 学术地位

《卜筮正宗》在六爻筮法史上的地位，好比《伤寒论》在中医史上的地位——它是六爻纳甲筮法的集大成之作和标准化教材。在《卜筮正宗》之前，六爻筮法散见于《火珠林》《易隐》《易林补遗》等各家著作中，理论体系庞杂不一，断卦方法各家各说各话。王洪绪以"正宗"为书名，表明了其统一六爻理论体系的雄心。

此书问世后，迅速成为六爻学习者的标准教材，后世学习六爻者，几乎人手一册。至今仍是六爻入门和深造的首选参考书。

### 体系框架

1. **基础篇**：详细阐述阴阳五行、天干地支、八卦象义、八宫卦序、纳甲纳支、六亲六神等基础理论，为后续断卦奠定根基。

2. **方法篇**：系统讲解起卦方法（以钱代蓍法）、装卦步骤（安世应、纳干支、排六亲、布六神）、动变规则，形成完整的操作流程。

3. **断卦篇**：提出"用神"为核心的断卦体系，以世爻为体、用神为用，强调"用神旺相、原神有力、忌神被制"为吉，反之则为凶。

4. **分类篇**：按求财、婚姻、官运、疾病、出行、失物、诉讼等分类，逐类详述占断方法和要诀。

### 核心断卦原则（逐条详解）

#### 1. 用神为本

一切断卦以用神为核心，用神旺相为吉，休囚为凶。用神与世爻的关系决定吉凶的性质。王洪绪在《卜筮正宗》中强调："凡占，用神者，事之主也。用神旺相，事必成；用神休囚，事必败。"这是六爻断卦的第一原则。

用神的选取需根据所占之事确定：求财取财爻，求官取官爻，男占婚姻取财爻，女占婚姻取官爻，求子取子孙爻，占文书取父母爻，等等。用神明确，方能有的放矢。

#### 2. 月建为纲

月建为卦中第一主宰，月建生克直接影响各爻旺衰。爻值月建为最旺，爻被月破为最衰。王洪绪指出："月建乃万卜之纲领，能生克冲合卦中之爻，动爻不能伤月建，而月建能制动爻。"月建如同四季之气候，万物皆受其影响，爻之旺衰首先取决于月建。

#### 3. 日辰为权

日辰为第二主宰，日辰生克冲合各爻，影响即时吉凶。暗动、日破皆由日辰决定。王洪绪言："日辰为六爻之主宰，掌一日之权，司四时之柄。"日辰与月建的关系，如同君与相——月建为长远之计，日辰为当前之权。

#### 4. 动变为机

动爻为卦中变数，动爻对静爻有生克权，变爻对原爻有回头生克作用。动爻是事情发展的关键推动力。《卜筮正宗》强调："动则变，变则通。动爻乃事之机，变爻乃机之兆。"一卦之中，动爻所在即为事情的关键节点。

#### 5. 世应为枢

世爻为自身，应爻为对方，世应关系是判断事情成败的枢纽。王洪绪指出："世爻为问卦之人，应爻为所问之事。世应相生，事易成；世应相克，事难就。"世应是判断人际关系、合作、婚姻、诉讼等占断的核心框架。

#### 6. 原忌仇神体系

《卜筮正宗》完整建立了原神、忌神、仇神的三层关系体系：
- **原神**：生用神者为原神，如财爻之原神为子孙爻。原神旺相，用神有根源。
- **忌神**：克用神者为忌神，如财爻之忌神为兄弟爻。忌神发动，用神受损。
- **仇神**：克原神而生忌神者为仇神，如财爻之仇神为父母爻（克子孙原神而生兄弟忌神）。

王洪绪总结："用神旺相，原神有力，忌神受制，乃为全吉；用神休囚，忌神发动，原神被克，乃为全凶。"

### 重要分类占断法则

- **求财**：财爻旺相，子孙爻发动生财为吉，兄弟爻发动克财为凶。
- **婚姻**：男占财爻旺相，女占官爻旺相，世应相合为吉。
- **官运**：官爻旺相生合世爻为吉，子孙爻发动克官为凶。
- **疾病**：官鬼旺相为病重，子孙旺相为药灵，世爻旺相为自身抵抗力强。
- **出行**：世爻旺相为出行顺利，克世之爻为路途障碍。

## 二、《增删卜易》精要

### 成书背景与作者

《增删卜易》由清代野鹤老人（李文辉）编著，成书于乾隆年间，晚于《卜筮正宗》。野鹤老人本名李文辉，号野鹤子，生平事迹记载不多，但从其著作中可以看出，他是一位长期从事六爻占卜实践的民间术士。他一生占卦无数，积累了丰富的实战经验，并将这些经验整理成书。

野鹤老人在自序中言："余自幼好易，三十年来，凡有所占，无不记录。日积月累，得卦数千，乃择其验者，删其不验者，汇成一编，名曰《增删卜易》。"这段话揭示了该书的独特价值——它不是纯理论的推演，而是经过大量实战检验的经验总结。

### 学术特色

《增删卜易》的核心特色是"以实战为本、以卦例为证"，这与《卜筮正宗》的"以理论为纲"形成鲜明对比。野鹤老人不迷信前人理论，而是通过实际占卦案例来验证和修正，对不合实际的理论进行"增删"——增加经过验证的法则，删除不切实际的陈说。这种实证精神在传统术数著作中极为罕见。

### 核心贡献

1. **实践检验**：野鹤老人以大量实际占卦案例验证前人理论，对不合实际的理论进行"增删"，保留经得起检验的法则，形成了极具实战价值的断卦体系。例如，他通过大量实例验证了"旬空"在不同季节、不同旺衰状态下的实际表现，纠正了前人"凡空皆凶"的简单论断。

2. **全备理论**：提出"全备"概念，即占断需综合月建、日辰、动变、六亲、六神、世应等全部因素，不可偏废。野鹤老人强调："观卦者，须通盘打算，不可执一而论。"这一理念使六爻断卦从单因素判断走向多因素综合判断。

3. **应期精要**：对应期判断有深入论述，归纳出"出旬填实""冲开合局""合起冲爻"等应期法则。野鹤老人尤其重视应期判断，他认为："断吉凶易，断应期难。能断应期，方为高手。"

4. **分类详实**：对各类占问的断法进行了详细分类和大量案例验证，尤其对求财、婚姻、疾病、官运等常见占断有精辟论述。书中每个分类都附有多个真实卦例，包括成功和失败的案例，并分析失败原因，这种"正面+反面"的教学方法非常实用。

### 核心断卦原则

1. **用神多现取旺相**：当一卦中用神多现时，取旺相发动者为主，休囚安静者为辅。野鹤老人指出，用神多现并非坏事，但需分清主次，不可混淆。

2. **动爻为机**：强调动爻是事情发展的关键，动爻生合用神为吉，动爻克用神为凶。野鹤老人的实践表明，动爻的力量远超静爻，一爻独动时，该爻几乎决定了整个卦的吉凶走向。

3. **三合局力量最大**：三个动爻形成三合局，力量极大，可改变整个卦的五行格局。野鹤老人通过大量案例证明，三合局一旦形成，即使月建日辰的力量也难以抗衡。

4. **化进为吉，化退为凶**：爻动化进主事情向前发展，力量增强；化退主事情倒退，力量减弱。野鹤老人特别强调化进化退在应期判断中的作用——化进待进日，化退待退日。

5. **伏吟反吟**：伏吟（爻动而地支不变）主事情停滞不前；反吟（爻动而地支相冲）主事情反复无常。这两种特殊动变格局在实战中具有重要的吉凶指示意义。

### 两书对比分析

| 对比维度 | 《卜筮正宗》 | 《增删卜易》 |
|---------|------------|------------|
| 成书时间 | 康熙年间（较早） | 乾隆年间（较晚） |
| 作者 | 王洪绪（学者型） | 野鹤老人（实战型） |
| 风格 | 理论化、系统化 | 实战化、案例化 |
| 核心价值 | 理论体系建立 | 实践经验验证 |
| 适合人群 | 初学者打基础 | 进阶者提升实战 |
| 编排方式 | 按知识体系分类 | 按占问类型分类 |
| 案例数量 | 少，以理论阐述为主 | 多，大量真实卦例 |
| 创新性 | 集大成，统一规范 | 实证检验，去伪存真 |

**侧重点差异**：
- 《卜筮正宗》侧重于"是什么"——告诉你六爻的基础理论和规范标准。
- 《增删卜易》侧重于"怎么用"——告诉你如何在实际占断中灵活运用这些理论。

**适用场景差异**：
- 系统学习六爻时，先读《卜筮正宗》建立框架，再读《增删卜易》丰富实战。
- 遇到具体断卦难题时，查阅《增删卜易》的同类案例，往往能获得启发。
- 需要查阅标准规范时，参考《卜筮正宗》的体系化描述。

**两书互补关系**：《卜筮正宗》侧重于理论体系的建立和规范，条理清晰，适合系统学习；《增删卜易》侧重于实战经验的总结和验证，案例丰富，适合提升断卦水平。两书合参，理论与实践并重，是六爻学习的标准路径。古人云："学六爻者，正宗为骨，增删为肉，骨肉相合，方能立人。"

## 三、其他重要典籍详解

### 《易隐》

《易隐》由明代曹九锡编著，成书于万历年间，是六爻筮法史上最具特色的著作之一。曹九锡为明代术数大家，精通六爻、奇门、六壬等多种术数。

**核心特色**：

1. **术数融合**：曹九锡将六爻筮法与奇门遁甲、六壬等术数体系结合，开创了"三式合一"的占断范式。例如，在六爻卦中引入奇门的"八门"（休、生、伤、杜、景、死、惊、开）和六壬的"十二天将"作为辅助判断。

2. **飞宫体系**：《易隐》最突出的贡献是建立了完整的"飞宫"体系。飞宫是一种在六爻卦中模拟人事关系的推演方法，以世爻为起点，按特定的生克关系和爻位顺序"飞"至其他爻位，推导出父母、兄弟、妻财、子孙等六亲的具体关系。飞宫体系使六爻的应用范围从"一事一占"扩展到"身命推演"。

3. **身命占断**：《易隐》尤其擅长"身命占"——即推算一个人的终身命运，包括出身、事业、婚姻、子女、寿元等。书中详细论述了如何通过卦象推断一个人的一生命运走向，这在传统六爻著作中极为罕见。曹九锡提出了"卦身""命爻""身宫"等概念，将六爻与命理学结合。

4. **深度技法**：《易隐》中包含了大量其他六爻著作中罕见的深度技法，如：
   - **飞伏神**：在常规伏神之外，还引入了更深层的飞伏神体系。
   - **卦身**：将卦身作为判断事情的关键参照点，卦身吉则事有根基。
   - **命爻**：以出生年地支定命爻，用于终身占断。
   - **神煞**：引入了大量神煞（如天乙贵人、文昌、驿马、桃花等）作为辅助判断。

**适用场景**：身命推演、终身运势、家族命运、复杂人事关系等长期和深度的占断。曹九锡的体系较为庞杂，对学习者的要求较高，适合有一定基础的学者深入研究。

**历史评价**：《易隐》在江湖卜者中影响深远，明清时期走街串巷的卜者，许多都使用《易隐》的技法进行身命占断。但因为其体系庞杂、技法繁多，在正规学术体系中一直处于边缘地位。

### 《火珠林》

《火珠林》传为唐代麻衣道者所著，是六爻纳甲筮法现存最早的经典之一。麻衣道者生卒年不详，传说为唐代隐士，精通易学和相术。

**历史地位**：《火珠林》是六爻纳甲筮法从理论走向实践的关键转折点。在《火珠林》之前，京房的纳甲筮法主要用于灾异预测和气候推演；《火珠林》将其转化为面向日常人事的占卜工具，开启了六爻筮法的"实用化"时代。

**核心贡献**：

1. **六十四卦为纲**：全书以六十四卦为纲，每卦配以诗文断语，简洁明了。这种编排方式使《火珠林》成为最早的"六爻速查手册"。

2. **卦辞断事**：将六爻论断与《周易》卦爻辞相结合，形成了独特的占断风格。每卦配以"火珠林曰"断语，便于快速查阅和参考。

3. **以钱代蓍**：《火珠林》最早系统论述了"以钱代蓍"的起卦方法（铜钱摇卦法），大大简化了起卦流程，使六爻占卜从贵族走向平民。在此之前，起卦需要使用五十根蓍草进行复杂的操作，门槛极高。

4. **六亲体系雏形**：书中初步建立了六亲（父母、兄弟、妻财、官鬼、子孙）的类象体系，为后世六爻断卦奠定了基础。

**适用场景**：快速断卦参考、卦辞辅助解读、六爻历史研究。

**现存版本**：目前流传的《火珠林》版本较多，各版本内容有差异，使用时需注意版本选择。较权威的版本包括《古今图书集成》收录本和《四库全书》收录本。

### 《京氏易传》

《京氏易传》为西汉京房（字君明）所著，是纳甲筮法的源头之作。京房是西汉著名的易学家，师从焦延寿（焦赣），深研《周易》，创立了以阴阳灾异为核心的易学体系。

**历史背景**：京房生活在西汉元帝时期，是汉易象数学派的代表人物。他将《周易》与阴阳五行、天文历法相结合，创立了"纳甲""八宫""世应""飞伏"等核心理论，为后世的六爻筮法奠定了理论基础。京房曾以易学预测灾异、劝谏皇帝，最终因政治斗争被处死，年仅四十一岁。

**核心贡献**：

1. **八宫卦序**：京房将六十四卦按八宫分组，每宫八卦，以八纯卦为首，通过逐步变爻形成一世卦至五世卦、游魂卦、归魂卦的完整序列。八宫体系是六爻筮法的骨架，后世所有六爻著作都以此为基础。

2. **纳甲纳支**：京房创立了将天干地支纳入卦爻的系统——天干纳甲（八卦配十天干）和地支纳支（每爻配固定地支）。这一体系将抽象的卦象与具体的时空能量对应，使占卦从"义理解读"走向"术数推演"。

3. **世应飞伏**：京房提出了世爻和应爻的概念，并建立了世爻定位规则（根据八宫卦序确定世爻位置）。同时提出了"飞伏"概念（飞神和伏神），为卦中用神不现的情况提供了解决方案。

4. **五行六亲**：京房将五行生克引入卦爻分析，建立了初步的六亲关系（生我者父母，克我者官鬼，我生者子孙，我克者妻财，同我者兄弟），为后世六亲体系奠定了基础。

**文本特点**：《京氏易传》文字古奥，理论深邃，以阴阳灾异、气候推演为主，重在阐述天人感应的易学哲学，而非日常人事的占卜实务。因此，此书虽然理论价值极高，但不适合直接用于实战占卜。

**适用场景**：纳甲理论溯源、八宫卦变研究、易学理论研究、汉易象数学研究。

**学术地位**：《京氏易传》是六爻纳甲筮法的"源头活水"，虽不能直接用于实战，但理解此书有助于从根本上把握六爻筮法的理论逻辑。《四库全书总目提要》评价京房易学为"汉易之宗"，可见其地位之崇高。

### 《周易尚氏学》

《周易尚氏学》为晚清民国易学大家尚秉和（1870-1950）所著，是民国时期象数易学的代表作。尚秉和字节之，号石烟道人，河北行唐人，光绪年间进士，曾任京师大学堂教习。他一生潜心易学，著述宏富，除《周易尚氏学》外，尚有《焦氏易林注》《焦氏易诂》《易卦口诀》等传世，于近代易学界影响深远。

**成书背景**：

尚秉和所处的时代，正值中国传统学术与西学交汇激荡之际。清代中后期，易学研究以义理派为主流，王弼"得意忘象"与程颐《伊川易传》的传统占据主导，象数之学长期被视为"术数末流"。尚秉和对此深以为憾，立志恢复汉易象数传统，回归《周易》"立象以尽意"的本源。他积数十年之功，遍阅先秦两汉典籍，辑佚钩沉，著成此书。

**学术地位**：

尚秉和与传统义理派（王弼、程颐）迥然不同，主张"以象解《易》"，回归汉易象数传统。其对六爻筮法的贡献尤为深远：系统整理了八卦取象体系，为纳甲筮法的万物类象提供了最完整的理论基础；又通过对《焦氏易林》的辑佚与解读，恢复了失传千年的易林取象法，使后学得以窥见汉代象数易学的全貌。

**核心理论贡献**：

1. **八卦逸象的恢复**：尚氏从《左传》《国语》《尔雅》《说文》等先秦两汉典籍中辑出大量逸象，补充了八卦取象体系。如《左传》中"震为足""坎为弓轮"等取象，多不见于《说卦传》，尚氏一一钩沉，恢复了八卦取象的完整面貌。

2. **取象法则系统化**：尚氏归纳出同气相求、同类相取、反象、覆象、互象、半象等系统化取象方法，使取象不再是零散的对应，而成为有规律可循的体系。同气相求指同五行之象相通，同类相取指同性质之物归类，反象覆象则是从卦象的翻转反复中衍生新象。

3. **对六爻解卦的意义**：六爻中的六神取象、六亲类象均可追溯至尚氏整理的逸象体系。如青龙主喜庆、白虎主丧凶的类象，其理论源头正在八卦取象之中。

**与六爻筮法的关系**：

尚秉和并非六爻纳甲派学者，但其象学体系是六爻万物类象的理论根基。六爻中的"用神类象"——如财爻为财物、官鬼为职权、子孙为医药——其理论源头可追溯至尚氏整理的八卦取象。断卦时若遇"取象困难"，如财爻临白虎代表何种具体事物，可参考尚氏逸象拓展思路：白虎属金，财爻临之可象刀剑、金属器物、医院、丧事之属。

**在不同场景下的使用**：

- 遇到用神取象不明确时，参考逸象体系拓展类象，使断卦更为具体。
- 研究六爻理论本源时，追溯至尚氏象学，明其所以然。
- 深度断卦时，结合覆象、反象等法则，丰富卦象解读的层次。

**商用价值**：为六爻解卦提供更丰富的类象工具，提升解读的具体性和画面感，使占断从抽象的吉凶判断走向具象的画面描绘，对专业卦师提升解读深度与说服力颇有助益。

## 四、现代六爻筮法的典籍选用建议

### 学习路径建议

**第一阶段：入门筑基（1-3个月）**
- 首选：《卜筮正宗》——系统学习六爻基础理论、装卦方法、断卦框架。
- 辅助：《火珠林》——快速查阅六十四卦卦辞和基本断语，建立对卦象的感性认识。

**第二阶段：实战提升（3-6个月）**
- 必读：《增删卜易》——通过大量真实卦例，学习实战断卦技巧和应期判断。
- 辅助：《卜筮正宗》——反复查阅，将理论框架与实战案例相互印证。

**第三阶段：深度拓展（6个月以上）**
- 选读：《易隐》——研究身命占断、飞宫体系和深度技法，拓展六爻的应用范围。
- 溯源：《京氏易传》——了解纳甲筮法的理论源头，提升对六爻原理的深层理解。

### 不同场景的典籍选择

| 使用场景 | 推荐典籍 | 原因 |
|---------|---------|------|
| 日常占卜 | 《卜筮正宗》+《增删卜易》 | 体系完整，实用性强 |
| 快速参考 | 《火珠林》 | 卦辞简洁，查阅方便 |
| 终身占断 | 《易隐》 | 身命占断的专门著作 |
| 理论研究 | 《京氏易传》 | 纳甲筮法的源头 |
| 教学授课 | 《卜筮正宗》 | 系统规范，逻辑清晰 |
| 疑难杂症 | 《增删卜易》 | 大量真实案例可供参考 |

### 综合运用原则

在实际断卦中，应以《卜筮正宗》和《增删卜易》的体系为主，以其他典籍为补充，在实践中融会贯通。具体而言：

1. **理论框架用《卜筮正宗》**：装卦、用神选取、世应定位、旺衰判断等基础操作，以《卜筮正宗》的规范为准。

2. **实战技法用《增删卜易》**：遇到具体断卦难题时，优先参考《增删卜易》中同类占问的案例和断法。

3. **深度占断用《易隐》**：涉及终身运势、身命推演等深度占断时，可引入《易隐》的飞宫、卦身、命爻等技法。

4. **快速参考用《火珠林》**：需要快速查阅卦辞或进行初步判断时，可参考《火珠林》。

5. **理论溯源用《京氏易传》**：研究六爻筮法的深层原理时，可追溯至《京氏易传》的原始理论。

**最终建议**：六爻筮法的学习，重在实践。典籍是前人的经验总结，但每个人的断卦风格和感悟不同。建议在掌握基本理论后，多实践、多总结、多反思，形成自己的断卦体系。正如野鹤老人所言："卦不欺人，人自欺耳。"心中有法，手中无书，方为最高境界。
