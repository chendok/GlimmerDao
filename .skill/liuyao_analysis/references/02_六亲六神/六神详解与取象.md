# 六神详解与取象

## 一、六神概述

六神（又称六兽）是六爻筮法中重要的辅助判断系统，包括青龙、朱雀、勾陈、螣蛇、白虎、玄武。六神临爻，赋予爻位额外的吉凶属性和取象含义，对断卦有重要的细化和补充作用。六神本身并无绝对的吉凶，其含义需结合所临爻的六亲、旺衰、动变等综合判断。

## 二、六神排布规则

六神以占卦当日的日干为依据，按以下规则确定初爻六神，然后自初爻至上爻依次排列：

| 日干 | 初爻六神 |
|------|---------|
| 甲、乙 | 青龙 |
| 丙、丁 | 朱雀 |
| 戊 | 勾陈 |
| 己 | 螣蛇 |
| 庚、辛 | 白虎 |
| 壬、癸 | 玄武 |

排布口诀："甲乙起青龙，丙丁起朱雀，戊日起勾陈，己日起螣蛇，庚辛起白虎，壬癸起玄武。"确定初爻六神后，按青龙→朱雀→勾陈→螣蛇→白虎→玄武→青龙的顺序循环排列至六爻。

## 三、六神详解

### 青龙

- **五行属性**：木
- **吉凶属性**：吉神，主喜庆、吉祥
- **主事**：喜事、婚姻、酒色、财利、升迁、文雅、新生
- **性格**：仁慈、正直、文雅、有风度
- **临不同爻位**：临世爻主自身有喜；临财爻主得财有喜；临子孙爻主添丁进口；临官爻主升迁
- **各场景取象**：
  - 求财：临财爻为正当财利，财路通畅
  - 婚姻：临财/官爻主婚姻美满，郎才女貌
  - 官运：临官爻主官运亨通，名正言顺
  - 疾病：临子孙爻主医药有效，病可痊愈
  - 出行：临世爻主旅途顺利，平安吉庆

### 朱雀

- **五行属性**：火
- **吉凶属性**：中性偏吉，主口舌文书
- **主事**：口舌、文书、消息、诉讼、争吵、火烛
- **性格**：能言善辩、急躁、好表现
- **临不同爻位**：临父母爻主文书喜讯；临官鬼爻主官司口舌；临兄弟爻主口舌争端
- **各场景取象**：
  - 考试：临父母爻主文采出众，成绩优异
  - 官运：临官鬼爻主以口才得官，但也主口舌是非
  - 婚姻：临财/官爻主能说会道，但也易有口角
  - 疾病：临官鬼爻主热症、炎症
  - 诉讼：临世爻主原告善辩，临应爻主被告善辩

### 勾陈

- **五行属性**：土
- **吉凶属性**：中性偏滞，主迟滞、牵连
- **主事**：田土、房产、迟滞、牵连、牢狱、旧事
- **性格**：固执、稳重、迟缓、守信
- **临不同爻位**：临世爻主自身行动迟缓；临官爻主官司牵连；临财爻主不动产之财
- **各场景取象**：
  - 求财：临财爻主田土房产之财，或得财较慢
  - 官运：临官爻主牢狱之灾或与土地相关的官职
  - 疾病：临官鬼爻主慢性病、肿瘤、脾胃病
  - 出行：临世爻主行期拖延，出行受阻
  - 失物：临财爻主失物在土中或近地之处

### 螣蛇

- **五行属性**：土（亦有说属火）
- **吉凶属性**：凶神，主怪异、虚惊
- **主事**：怪异、虚惊、噩梦、欺诈、邪祟、缠绕
- **性格**：多疑、阴险、诡诈、神经质
- **临不同爻位**：临世爻主自身心神不宁；临官鬼爻主邪祟缠绕；临子孙爻主怪梦
- **各场景取象**：
  - 求财：临财爻为不义之财或来路不明的财
  - 婚姻：临财/官爻主婚姻中有隐瞒欺骗
  - 官运：临官爻主阴谋得官，或以不正当手段
  - 疾病：临官鬼爻主怪病、精神疾病、神经衰弱
  - 出行：临世爻主途中虚惊，或遭遇怪异之事

### 白虎

- **五行属性**：金
- **吉凶属性**：凶神，主刑伤、血光
- **主事**：刑伤、血光、丧事、疾病、威猛、刚强
- **性格**：刚猛、果决、威严、暴躁
- **临不同爻位**：临世爻主自身有灾；临官爻主血光之灾或大权在握；临子孙爻主医生、手术
- **各场景取象**：
  - 求财：临财爻为风险之财，如军警、医疗行业之财
  - 婚姻：临财/官爻主配偶性格刚烈，或有刑伤
  - 官运：临官爻主武职、军警、司法之官，权柄在握
  - 疾病：临官鬼爻主急症、血光、手术、外伤
  - 出行：临世爻主出行有险，注意交通安全

### 玄武

- **五行属性**：水
- **吉凶属性**：凶神，主盗贼、暗昧
- **主事**：盗贼、暗昧、私情、阴私、水厄、遗失
- **性格**：阴险、狡猾、好色、暧昧
- **临不同爻位**：临世爻主自身有隐秘之事；临财爻主暗财；临官鬼爻主盗贼之患
- **各场景取象**：
  - 求财：临财爻为暗财、灰色收入或不可告人之财
  - 婚姻：临财/官爻主私情、婚外情、暗恋
  - 官运：临官爻主以不正当手段谋官，或从事机密工作
  - 疾病：临官鬼爻主隐疾、肾病、泌尿系统疾病
  - 失物：临财爻主被盗，失物难寻

## 四、六神综合使用原则

1. **六神为辅，六亲为主**：六神不能单独决定吉凶，必须依附于六亲、爻位、旺衰等综合判断。

2. **旺相则显，休囚则隐**：爻旺则六神特性明显，爻衰则六神特性微弱，甚至不显。

3. **动变增强**：爻发动时，六神特性更为突出；爻安静时，六神特性相对内敛。

4. **吉神遇凶爻则减吉，凶神遇吉爻则减凶**：青龙临官鬼受克，喜庆中亦有烦恼；白虎临子孙旺相，可为名医良药。
