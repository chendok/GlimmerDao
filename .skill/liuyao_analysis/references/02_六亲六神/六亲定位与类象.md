# 六亲定位与类象

## 一、六亲定位规则

六亲（父母、兄弟、妻财、官鬼、子孙）是六爻纳甲筮法的核心人事分类体系。六亲以卦宫五行为"我"，通过各爻所纳地支五行与卦宫五行的生克关系来确定。

### 基本规则

以卦宫五行为"我"：

| 生克关系 | 六亲 | 说明 |
|---------|------|------|
| 生我者 | 父母 | 卦宫五行被爻之五行所生 |
| 克我者 | 官鬼 | 卦宫五行被爻之五行所克 |
| 我生者 | 子孙 | 爻之五行被卦宫五行所生 |
| 我克者 | 妻财 | 爻之五行被卦宫五行所克 |
| 同我者 | 兄弟 | 爻之五行与卦宫五行相同 |

### 举例

乾宫八卦属金，以金为"我"：
- 爻纳地支为**土**（辰、戌、丑、未）→ 土生金 → 生我者为**父母**
- 爻纳地支为**火**（巳、午）→ 火克金 → 克我者为**官鬼**
- 爻纳地支为**水**（亥、子）→ 金生水 → 我生者为**子孙**
- 爻纳地支为**木**（寅、卯）→ 金克木 → 我克者为**妻财**
- 爻纳地支为**金**（申、酉）→ 金同金 → 同我者为**兄弟**

### 八卦宫五行速查

| 卦宫 | 五行 | 卦宫 | 五行 |
|------|------|------|------|
| 乾宫 | 金 | 坤宫 | 土 |
| 震宫 | 木 | 巽宫 | 木 |
| 坎宫 | 水 | 离宫 | 火 |
| 艮宫 | 土 | 兑宫 | 金 |

## 二、六亲详细类象

### 父母爻类象

**人**：父母、长辈、师长、上司、保护者、监护人。

**事**：文书、合同、证书、考试、学业、消息、信件、房屋、车船、衣物、雨具。

**概念**：庇护、保护、辛苦、劳累、知识、文化、法律、规则、庇护所。

**性格**：仁慈、保守、稳重、有责任心，但也可能固执、啰嗦。

**身体**：头面、皮肤、背部。

### 兄弟爻类象

**人**：兄弟姐妹、同辈、朋友、同事、合伙人、竞争者。

**事**：口舌、争斗、破财、分家、合伙、竞技、比赛。

**概念**：竞争、消耗、分享、分担、劫财、阻力。

**性格**：讲义气、好胜、大方、冲动，但也可能争强好斗。

**身体**：手足、四肢、肩臂。

### 妻财爻类象

**人**：妻子、情人、女性伴侣、下属、佣人。

**事**：钱财、货物、粮食、薪资、收益、利润、饮食。

**概念**：财富、享受、物质、欲望、控制、占有。

**性格**：善于理财、务实、节俭，但也可能吝啬、物质。

**身体**：饮食相关（脾胃）、津液、分泌物。

### 官鬼爻类象

**人**：丈夫、官员、上司、公职人员、敌人、盗贼、鬼祟。

**事**：官运、职位、功名、官司、诉讼、疾病、灾祸、约束。

**概念**：权力、制约、危险、疾病、压力、管理、纪律。

**性格**：威严、刚强、有魄力，但也可能霸道、阴险。

**身体**：疾病、疼痛、不适的部位。

### 子孙爻类象

**人**：子女、晚辈、学生、下属、僧道、医生。

**事**：娱乐、游玩、医药、治疗、创作、技术、福气、解忧。

**概念**：快乐、自由、福气、医药、解神、克官。

**性格**：乐观、活泼、聪明、有创造力，但也可能贪玩、任性。

**身体**：生育系统、生殖器官、免疫系统。

## 三、各类占问中的用神选择

| 占问类型 | 用神 | 补充说明 |
|---------|------|---------|
| 求财 | 妻财爻 | 正财看财爻，偏财看子孙爻生财 |
| 求官/考试 | 官鬼爻 | 辅以父母爻看文书、成绩 |
| 婚姻（男占） | 妻财爻 | 兼看世应关系 |
| 婚姻（女占） | 官鬼爻 | 兼看世应关系 |
| 疾病 | 官鬼爻为病 | 子孙爻为医药，世爻为患者 |
| 出行 | 世爻 | 看克世之神、道路之象 |
| 失物 | 妻财爻/父母爻 | 财爻为贵重物，父母爻为文书包裹 |
| 子女/孕产 | 子孙爻 | 看子孙爻旺衰 |
| 天气 | 父母爻为雨 | 妻财爻为晴，官鬼爻为雷电 |
| 诉讼 | 世爻为原告 | 应爻为被告，官鬼爻为判决 |
| 合作 | 世爻为自身 | 应爻为对方，兄弟爻为合伙人 |

## 四、用神使用要点

1. **用神宜旺相**：用神得月建日辰生扶，或自身发动，为吉。用神休囚空破，为凶。

2. **用神与世爻关系**：用神生合世爻为吉，用神冲克世爻为凶。用神虽旺但克世爻，反为不利。

3. **原神与忌神**：生用神者为原神（如财爻之原神为子孙），克用神者为忌神（如财爻之忌神为兄弟）。原神旺相则用神有根，忌神发动则用神受损。

4. **用神多现**：一卦中若用神多现（多个爻同位六亲），取旺相发动者为主，休囚安静者为辅。若皆安静，取持世或临应者为主。
