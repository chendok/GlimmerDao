# 纳甲理论与干支配卦

## 一、纳甲概述

纳甲是六爻筮法的基础理论，源自西汉京房易学体系。其核心思想是将天干地支纳入卦爻之中，使抽象的卦象与具体的时空能量对应，从而将《周易》的卦爻辞体系转化为可量化推演的占筮系统。纳甲之法，以八卦配十天干，以六爻配十二地支，形成了完整的干支纳卦体系。

## 二、天干纳甲规则

天干纳甲遵循"乾坤为阴阳之宗，六子分纳其余"的原则。具体规则如下：

| 卦名 | 所纳天干 | 备注 |
|------|---------|------|
| 乾卦 | 甲、壬 | 乾为阳之极，内卦纳甲，外卦纳壬 |
| 坤卦 | 乙、癸 | 坤为阴之极，内卦纳乙，外卦纳癸 |
| 震卦 | 庚 | 震为长男，纳庚 |
| 巽卦 | 辛 | 巽为长女，纳辛 |
| 坎卦 | 戊 | 坎为中男，纳戊 |
| 离卦 | 己 | 离为中女，纳己 |
| 艮卦 | 丙 | 艮为少男，纳丙 |
| 兑卦 | 丁 | 兑为少女，纳丁 |

记忆口诀："乾甲壬、坤乙癸、震庚、巽辛、坎戊、离己、艮丙、兑丁"。乾卦纳甲壬二干，是因为乾为天，统领阴阳，甲为十干之首，壬为十干之中，寓意乾道贯通始终。坤卦同理，纳乙癸二干。

## 三、地支纳支规则

地支纳支以八宫卦为单位，每宫八卦的六爻各配固定地支，依爻位递进排列。阳卦（乾、震、坎、艮）纳阳支，自下而上顺行；阴卦（坤、巽、离、兑）纳阴支，自下而上逆行。

注意：乾宫八卦的纳支规则是——下卦变则内三爻（初、二、三爻）纳支随新下卦而定，上卦变则外三爻（四、五、上爻）纳支随新上卦而定。具体而言：一世卦（姤）下卦变为巽，内三爻纳巽支（丑亥酉）；二世卦（遁）下卦变为艮，内三爻纳艮支（辰午申）；三世卦（否）下卦变为坤，内三爻纳坤支（未巳卯）；四世卦（观）下卦坤、上卦变为巽，内三爻纳坤支、外三爻纳巽外支（未巳卯）；五世卦（剥）下卦坤、上卦变为艮，内三爻纳坤支、外三爻纳艮外支（戌子寅）；游魂卦（晋）下卦坤、上卦变为离，内三爻纳坤支、外三爻纳离外支（酉未巳）；归魂卦（大有）下卦恢复本宫乾、上卦保持离，内三爻纳乾支、外三爻纳离外支。

### 其他六宫纳支简表

**震宫**（阳顺行）：初爻子、二爻寅、三爻辰、四爻午、五爻申、上爻戌。纳支规则与乾宫同理：下卦变则内三爻随新下卦，上卦变则外三爻随新上卦。游魂卦为大过，归魂卦为随。

**坎宫**（阳顺行）：初爻寅、二爻辰、三爻午、四爻申、五爻戌、上爻子。游魂卦为明夷，归魂卦为师。

**艮宫**（阳顺行）：初爻辰、二爻午、三爻申、四爻戌、五爻子、上爻寅。游魂卦为中孚，归魂卦为渐。

**巽宫**（阴逆行）：初爻丑、二爻亥、三爻酉、四爻未、五爻巳、上爻卯。游魂卦为颐，归魂卦为蛊。

**离宫**（阴逆行）：初爻卯、二爻丑、三爻亥、四爻酉、五爻未、上爻巳。游魂卦为讼，归魂卦为同人。

**兑宫**（阴逆行）：初爻巳、二爻卯、三爻丑、四爻亥、五爻酉、上爻未。游魂卦为小过，归魂卦为归妹。

## 四、纳甲在解卦中的应用

1. **干支五行生克**：纳甲之后，每爻皆有干支五行属性，可据以判断爻与爻之间的生克冲合关系，这是六爻断卦的核心逻辑。

2. **六亲定位基础**：纳甲干支是确定六亲（父母、兄弟、妻财、官鬼、子孙）的前提。先定卦宫五行，再以各爻所纳地支的五行与卦宫五行比较，得出六亲归属。

3. **六神排布依据**：六神的排布以日干和各爻纳干为基础，按"甲乙起青龙、丙丁起朱雀、戊日起勾陈、己日起螣蛇、庚辛起白虎、壬癸起玄武"的规则，自初爻起依次排列。

4. **旬空判断**：日辰干支确定后，可据六甲旬空表判断各爻所纳地支是否逢空，空亡之爻其力不显，出旬填实方可用事。

5. **应期推断**：纳甲干支是断应期的核心工具。用神旺相但逢空，待出旬或填实之日为应期；用神休囚，待生旺之月日；用神被克，待制克之神被制之日。

6. **时空对应**：纳甲将卦爻与具体时间（年、月、日、时）和空间方位对应，使占断结果具有明确的时空指向性，是"以卦象推人事"的关键桥梁。
