# 动变规则与伏神飞神

## 一、六爻动变规则总论

动变是六爻占断中最核心的变数机制。卦中有动爻，则事情有变化；动爻产生变爻，变爻对原爻有回头作用。理解动变的规则，是准确断卦的前提。

### 老阴老阳的识别

在起卦过程中，每一次摇卦得到一个爻，根据所得爻的阴阳属性以及是否"变"，将爻分为四种状态：

| 状态 | 符号 | 属性 | 说明 |
|------|------|------|------|
| 少阳 | — | 阳爻不变 | 一背二字（一个背面），为阳爻，不发动 |
| 少阴 | - - | 阴爻不变 | 一字二背（两个背面），为阴爻，不发动 |
| 老阳 | ○ | 阳爻变阴 | 三个背面，为阳爻发动，阳极变阴 |
| 老阴 | × | 阴爻变阳 | 三个字面，为阴爻发动，阴极变阳 |

**老阳变阴**：三个铜钱全为背面，记为"○"，爻性为阳，但因阳至极而变，故为动爻，阳变阴。此即"阳极生阴"之理。

**老阴变阳**：三个铜钱全为字面，记为"×"，爻性为阴，但因阴至极而变，故为动爻，阴变阳。此即"阴极生阳"之理。

少阳和少阴为"不变之爻"，不参与动变。老阳和老阴为"变爻"，产生变卦。

### 本卦与变卦

六次摇卦完成后，以所得六爻排出的卦为**本卦**（主卦），代表事情的当前状态。将本卦中所有动爻（老阳、老阴）按"老阳变阴、老阴变阳"的规则变化后，得到的新卦为**变卦**（之卦），代表事情的发展趋势和最终结果。

若一卦之中无动爻（六爻皆为少阳或少阴），则只有本卦，无变卦，称为"静卦"。静卦主事情稳定，变化不大，以本卦卦象及爻象直接判断。

### 动爻的生克权

动爻在卦中具有特殊地位，其对静爻有生克权，而静爻不能主动生克动爻。动爻越多，卦中变化越复杂，事情越不稳定。

- **一爻独动**：格局最清晰，该动爻为事情的关键枢纽，吉凶主要由该动爻决定。
- **多爻发动**：格局复杂，需综合各动爻的力量，分析它们之间的生克关系。若多动爻形成合局，则合局之力大于单个动爻。
- **六爻全动**：极为少见，主事情变化剧烈，乾坤颠倒，吉凶难定，需结合具体卦象和月建日辰综合判断。

### 动爻之间的生克

多个动爻之间存在生克关系时，遵循"动爻之间可以互相生克"的原则。例如：

- 动爻A为兄弟（克财），动爻B为官鬼（克兄弟），则B克制A，A克财之力被削弱。
- 动爻A为子孙（生财），动爻B为兄弟（克财），则A生财、B克财，二者力量对比决定财爻的最终吉凶。

动爻之间的生克，其力量大于静爻之间的生克，但小于动爻与变爻之间的回头作用。

## 二、化进化退详解

动爻变化后，变爻与动爻的五行相同且地支方向变化，称为化进化退。化进化退是判断事情发展趋势的重要依据。

### 化进神

化进神，指爻动化出同类五行且地支在十二地支顺序中向前推进：

| 五行 | 化进 | 说明 |
|------|------|------|
| 木 | 寅化卯 | 寅为木之初，卯为木之盛，向前推进 |
| 火 | 巳化午 | 巳为火之初，午为火之盛，向前推进 |
| 金 | 申化酉 | 申为金之初，酉为金之盛，向前推进 |
| 水 | 亥化子 | 亥为水之初，子为水之盛，向前推进 |

此外，丑化辰、辰化未、未化戌、戌化丑（土之化进），也属于化进范畴，但力度稍弱。

**化进神的吉凶含义**：

- 用神化进：事情向前发展，越来越好，力量逐步增强。如财爻化进，财运日增；官爻化进，仕途步步高升。
- 忌神化进：凶象加剧，事情恶化。如兄弟爻化进克财，破财愈演愈烈；官鬼爻化进克世，灾祸日益加重。
- 原神化进：用神之根源日益强大，为间接吉象。如子孙爻化进，财源滚滚而来。
- 世爻化进：自身力量增强，运势上升，事情由我主导。

### 化退神

化退神，指爻动化出同类五行且地支在十二地支顺序中向后倒退：

| 五行 | 化退 | 说明 |
|------|------|------|
| 木 | 卯化寅 | 由盛转衰，向后退缩 |
| 火 | 午化巳 | 由盛转衰，向后退缩 |
| 金 | 酉化申 | 由盛转衰，向后退缩 |
| 水 | 子化亥 | 由盛转衰，向后退缩 |

同样，未化辰、辰化丑、丑化戌、戌化未（土之化退），也属于化退范畴。

**化退神的吉凶含义**：

- 用神化退：事情走下坡路，力量衰退。如财爻化退，财运渐退，宜早收手；官爻化退，仕途有退步之虞。
- 忌神化退：凶象消退，转危为安。如兄弟爻化退，克财之力渐减，破财不严重；官鬼爻化退，灾祸渐消。
- 世爻化退：自身运势衰退，精力不济，事情难以为继。

### 化进化退的应期

- 化进神，待进神当值之日（如寅化卯，待卯日）为应期。
- 化退神，待退神当值之日（如卯化寅，待寅日）为退尽之期。

## 三、化生化绝化克化墓

除了化进化退，动爻的变爻还可能对原爻产生回头生、回头克、化绝、化墓等复杂关系。

### 化回头生

动爻化出的变爻，其五行回头生原爻，称为"化回头生"或"化生"。例如：寅木爻动化出子水爻，子水生寅木，此为回头生。

**化回头生的吉凶含义**：

- 化回头生为吉象，主事情有转机，得到外力相助。如财爻化回头生，财源不断，有贵人暗中相助。
- 用神化回头生，即使原爻休囚，亦有生机可寻。
- 世爻化回头生，自身得贵人扶持，事情转危为安。

**注意**：化回头生虽然为吉，但变爻本身若被月建日辰冲克，则回头生之力大打折扣。

### 化回头克

动爻化出的变爻，其五行回头克原爻，称为"化回头克"或"化克"。例如：寅木爻动化出酉金爻，酉金克寅木，此为回头克。

**化回头克的吉凶含义**：

- 化回头克为六爻中最凶的动变之一，主自身行为反受其害，自取灭亡。如世爻化回头克，主自身决策失误，自招祸患。
- 用神化回头克，事情原本有利，但因自身原因走向失败。如财爻化回头克，求财反有损失，因贪致祸。
- 忌神化回头克，则为吉象，凶神受制，不能为害。如兄弟爻化回头克，克财之力消失，破财之危解除。

**化回头克的解救**：

- 若变爻被月建日辰冲克（变爻受制），回头克之力大减。
- 若有其他动爻克制变爻，亦能化解回头克之危。

### 化绝

动爻化出的变爻，为原爻地支之"绝"地（依据十二长生），称为"化绝"。十二长生绝地如下：

| 五行 | 绝地 | 说明 |
|------|------|------|
| 木 | 申 | 木绝于申，秋季金旺木衰 |
| 火 | 亥 | 火绝于亥，冬季水旺火灭 |
| 金 | 寅 | 金绝于寅，春季木旺金囚 |
| 水 | 巳 | 水绝于巳，夏季火旺水涸 |
| 土 | 巳 | 土绝于巳（水土同宫） |

**化绝的吉凶含义**：

- 化绝主事情走到尽头，气数已尽，难以挽回。
- 用神化绝，为最凶之象，所求之事绝无希望。
- 世爻化绝，自身运势衰败至极，需另寻出路。
- 忌神化绝，则为吉象，凶事自消。

**化绝的特殊情况**：若动爻旺相（得月建日辰生扶），或变爻被月建日辰克制，化绝之凶可减。但化绝的本质是"气数消尽"，即使有救，也难以恢复到理想状态。

### 化墓

动爻化出的变爻，为原爻地支之"墓"库，称为"化墓"。十二长生墓库如下：

| 五行 | 墓库 | 说明 |
|------|------|------|
| 木 | 未 | 木墓于未 |
| 火 | 戌 | 火墓于戌 |
| 金 | 丑 | 金墓于丑 |
| 水、土 | 辰 | 水土墓于辰 |

**化墓的吉凶含义**：

- 化墓主事情被"关住"，力量无法发挥，如人被囚禁，事被搁置。
- 用神化墓：所求之事被阻滞，难以推进。如财爻化墓，钱财被冻结；官爻化墓，仕途受阻。
- 世爻化墓：自身被困，行动受限，如人被关押，或心灰意冷。
- 忌神化墓：凶神被收，不能为害，为吉象。

**出墓的条件**：待冲墓之日（如辰墓待戌日冲开），用神方可发挥作用。

## 四、伏神飞神体系

伏神和飞神是六爻中独特的"隐藏"机制，用于处理卦中用神不现的情况。

### 伏神的定义

当所问之事对应的用神在本卦和变卦中均不出现（即卦中没有该六亲的爻），则需从本宫卦（八纯卦）中寻找该六亲对应的爻，将其"伏藏"于本卦同位爻之下，此即为**伏神**。

例如：占求财，本卦为《天风姤》，姤卦属乾宫。姤卦中无妻财爻，则需从乾宫首卦《乾为天》中寻找妻财爻。乾卦二爻为妻财寅木，将寅木妻财伏藏于姤卦二爻之下，寅木即为伏神。

### 伏神的查找方法

1. 确定本卦所属的八宫。
2. 确认本卦和变卦中均无所需的用神六亲。
3. 查该宫首卦（八纯卦），找到对应六亲的爻位。
4. 将该爻伏藏于本卦同位爻之下，即为伏神。

**伏神查找口诀**："用神不上卦，即向本宫寻。首卦同位取，伏神此中存。"

### 飞神的概念

伏神所伏藏位置之上的本卦爻位，称为**飞神**。飞神是伏神所处的"环境"，飞神对伏神有生克压制或生扶出伏的作用。

以上例说明：姤卦二爻本为子孙亥水，乾宫妻财寅木伏于其下。此时子孙亥水为飞神，妻财寅木为伏神。飞神（亥水）生伏神（寅木），为"飞来生伏"，伏神得飞神生扶，有出伏之机。

### 飞伏生克关系

飞神与伏神之间的生克关系，决定了伏神能否发挥作用：

| 关系 | 名称 | 含义 | 吉凶 |
|------|------|------|------|
| 飞神生伏神 | 飞来生伏 | 伏神得飞神生扶，有出伏之机 | 吉 |
| 伏神生飞神 | 伏去生飞 | 伏神泄气于飞神，力量减弱 | 次吉 |
| 飞神克伏神 | 飞来克伏 | 伏神被飞神压制，难以出伏 | 凶 |
| 伏神克飞神 | 伏去克飞 | 伏神有力量冲破飞神而出 | 次吉，待时而发 |
| 飞伏比和 | 飞伏同气 | 伏神与飞神力量相当，持平 | 平 |

### 伏神出伏的条件

伏神并非永远"伏藏"，在特定条件下可以"出伏"发挥作用：

1. **日辰冲动伏神**：当日辰地支冲动伏神所纳地支时，伏神被冲而出，发挥作用。此为伏神出伏最直接的方式。

2. **日辰冲动飞神**：日辰冲飞神，飞神被冲开，伏神得以出头。此即"冲飞露伏"。

3. **伏神临日辰**：伏神所纳地支恰好为日辰地支，伏神得日辰之力，自然出伏。

4. **伏神临月建**：伏神所纳地支恰好为月建地支，伏神得月建之力，亦能出伏。

5. **伏神旺相**：伏神得月建日辰生扶，自身旺相，即使飞神压制，亦能待时而发。

6. **飞神休囚空破**：飞神休囚无力，或被月破、旬空，无力压制伏神，伏神自然出伏。

7. **飞神被其他动爻克制**：若有动爻克制飞神，飞神之力被削弱，伏神得以出伏。

### 伏神在各占问中的含义

- **求财**：财爻伏藏，主财不显露，需静待时机。伏神旺相则终可得财，伏神休囚则财路不通。
- **婚姻**：财/官爻伏藏，主缘分未到，对方尚未出现，或对方有意隐藏。
- **官运**：官爻伏藏，主官职不显，或暂时没有升迁机会。
- **疾病**：官鬼爻伏藏，主病根隐藏，不易诊断；子孙爻伏藏，主良医难求。
- **失物**：财爻伏藏，主失物在隐蔽处，不易找到。

## 五、卦身与命爻

### 卦身的定位

卦身又称"月卦身"，是六爻中一个特殊的参照点，用于辅助判断事情的吉凶走向。卦身的定位方法依据世爻的地支和月建推算：

**卦身定位法则**：

以世爻所纳地支为基准，按"阳世从子起、阴世从午起"的原则，顺数至世爻所在的爻位，即可得到卦身。

具体推算方法为：世爻若为阳爻（初爻、三爻、五爻为阳位），从子顺数；世爻若为阴爻（二爻、四爻、上爻为阴位），从午顺数。数至世爻所在爻位，所得地支即为卦身。若卦身地支不在卦中，则此卦无卦身，为"身不入卦"。

另一种常见的卦身确定方法是根据世爻爻位：

| 世爻位置 | 卦身地支 |
|---------|---------|
| 初爻（一世） | 子（阳世）/ 午（阴世） |
| 二爻（二世） | 丑 / 未 |
| 三爻（三世） | 寅 / 申 |
| 四爻（四世） | 卯 / 酉 |
| 五爻（五世） | 辰 / 戌 |
| 上爻（六世） | 巳 / 亥 |

**卦身的作用**：

1. **辅助判断事情吉凶**：卦身旺相，主事情有根基；卦身休囚空破，主事情缺乏支撑。
2. **判断事情的时间性**：卦身可作应期参照，卦身当值之日为事情的关键节点。
3. **身命占断**：在终身卦中，卦身代表一个人的安身立命之所，卦身吉则一生安稳，卦身凶则颠沛流离。
4. **卦身与世爻的关系**：卦身生合世爻为吉，卦身冲克世爻为凶。

### 命爻的定位

命爻是六爻中用于终身占断和特定人事占断的特殊概念，代表一个人的"命"或"天命"所在。

**命爻的定位方法**：

命爻以占卦者出生年的地支来确定。根据出生年地支，在卦中找到纳该地支的爻，即为命爻。例如：

- 子年生人，命爻为卦中纳子之爻。
- 丑年生人，命爻为卦中纳丑之爻。
- 以此类推。

**命爻的作用**：

1. **终身卦的核心**：在终身占断中（如《易隐》的身命占），命爻代表一个人的天赋命运，命爻旺相则命好，命爻休囚则命蹇。
2. **流年运势判断**：命爻与流年地支的关系，决定该年的吉凶。流年生合命爻为吉，流年冲克命爻为凶。
3. **与世爻的关系**：命爻生合世爻，主命运与自身努力方向一致；命爻冲克世爻，主天命与人事相违，需以柔克刚。
4. **特殊占断**：在占卜终身大事（如婚姻、择业、迁居）时，命爻可作为重要参考，判断该选择是否与自身命运相符。

### 卦身与命爻的联合使用

在《易隐》等书的体系中，卦身和命爻经常联合使用：

- 卦身代表"立足之地"，命爻代表"天命所归"。
- 卦身与命爻相生相合，主安身立命，顺天应人。
- 卦身与命爻相冲相克，主身命不合，需调整方向。
- 世爻、卦身、命爻三者皆吉，为最佳格局，主一生顺遂。

卦身和命爻在常规占断中并非必需，但在身命占、终身卦等深度占断中具有重要参考价值。初学者可先掌握基本的用神、世应体系，再逐步深入研究卦身和命爻的用法。
