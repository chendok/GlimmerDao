# 八宫卦序与世应定位

## 一、八宫卦序概述

八宫卦序是京房易学的核心体系，将六十四卦按八宫分为八组，每宫八卦，以八纯卦为首，依次变化各爻，形成一世卦、二世卦、三世卦、四世卦、五世卦、游魂卦、归魂卦的完整序列。八宫体系的建立，使六十四卦有了系统的内在逻辑关系。

## 三、世爻与应爻定位规则

世爻代表占问者自身或所问之事的主体，应爻代表所问之事的对象、对方或环境。世应相隔二爻，即世爻与应爻之间始终间隔两个爻位。

### 世爻定位规则

| 卦的类型 | 世爻位置 | 应爻位置 |
|----------|---------|---------|
| 八纯卦（六世卦） | 上爻（第六爻） | 三爻 |
| 一世卦 | 初爻（第一爻） | 四爻 |
| 二世卦 | 二爻 | 五爻 |
| 三世卦 | 三爻 | 上爻 |
| 四世卦 | 四爻 | 初爻 |
| 五世卦 | 五爻 | 二爻 |
| 游魂卦 | 四爻 | 初爻 |
| 归魂卦 | 三爻 | 上爻 |

### 游魂卦与归魂卦

**游魂卦**：五世卦之后，第四爻变回本宫卦的第四爻之象，世爻在四爻。游魂卦主事有变动、迁移、心神不定之象，占行人则在外将归而未归，占事业则有变动之机。

**归魂卦**：游魂卦之后，下卦全变回本宫卦的下卦之象，世爻在三爻。归魂卦主事有归着、稳定、返回之象，占行人可归，占事有结果，但不宜再变。

## 四、世应爻在解卦中的核心作用

1. **主体定位**：世爻为占问者自身，代表问卦人的状态、能力、运势。世爻旺相有力，则问卦人事有根基；世爻休囚空破，则自身力量不足。

2. **关系判断**：世应与用神之间的关系是断卦核心。如求财，财爻为用神，需看财爻与世爻的关系：财生世为财来就我，世克财为我去求财，财克世为财来伤我。

3. **吉凶枢纽**：世爻宜旺相得生，不宜休囚受克。应爻宜生合世爻，不宜冲克世爻。世应相生为顺，相克为逆，比和为平。

4. **应期判断**：世爻为事之始，应爻为事之终。世爻发动则事在自身，应爻发动则事在对方。世应之间的生克冲合关系，直接决定事情的成败和应期。
