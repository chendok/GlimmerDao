# 三大主线辅纹商用完整版

## 总论

古法相理以三大主线为手相核心，配辅纹为用。三大主线为先天所成，主一生大趋势；辅纹为后天所生，主阶段性运势与细节。传统典籍记载，主线看先天格局，辅纹看后天变化，二者合参方准。

【三大掌纹主线文字示意图】
```
1. 最上方横向：天纹=感情线（婚恋情绪人际）
2. 中间斜向下：人纹=智慧线（思维决策事业）
3. 环绕大拇指弧形：地纹=生命线（体质精力起伏）
辅纹：竖直事业线、小指下方婚姻线、细碎财运线
```

## 一、三大主线

### 1. 天纹（感情线）

| 项目 | 内容 |
|------|------|
| 起点 | 小指下方水星丘侧 |
| 走向 | 横向延伸至食指下方（木星丘）或食指与中指之间 |
| 主宰 | 感情婚恋、人际交往、情感能量 |

**判断标准**：

| 纹相 | 论断 |
|------|------|
| 清晰深长 | 感情顺利、重情义、感情稳定 |
| 有分叉 | 感情多波折，或易因情破财 |
| 有断裂 | 感情有重大变故，需注意情感创伤 |
| 链状纹 | 感情多纠葛、情绪敏感 |
| 平直 | 理性冷静、感情不外露 |
| 弯曲上翘 | 重感情、易投入 |
| 末端止于食指下 | 重感情、专一 |
| 末端止于食指中指间 | 感情平衡、兼顾理智 |

古法相理认为天纹主"心之所向"，清晰深长者为重情重义之相，断裂链状者需注意情感管理与人际边界。对应运势为感情婚恋与人际交往。

### 2. 人纹（智慧线）

| 项目 | 内容 |
|------|------|
| 起点 | 与生命线同源（食指与拇指之间） |
| 走向 | 横向或斜向延伸，止于掌中或掌边 |
| 主宰 | 思维模式、决策能力、事业方向 |

**判断标准**：

| 纹相 | 论断 |
|------|------|
| 平直 | 思维理性务实、重逻辑 |
| 弯曲向下（向太阴丘） | 想象力丰富、感性、宜文艺 |
| 短 | 思维直接、不善深谋、决策快 |
| 长至掌边 | 深思熟虑、善计划、多谋 |
| 清晰深长 | 聪慧理智、决策力强 |
| 分叉为双线 | 多才多艺、思维多元（"作家叉"为吉） |
| 与生命线同源且长 | 独立性强、自主决策 |
| 与生命线分离起 | 早独立、敢闯敢为 |

传统典籍记载人纹主"思之所至"，平直者务实、弯曲者感性，长短看谋略深浅。对应运势为思维模式、决策能力与事业方向。

### 3. 地纹（生命线）

| 项目 | 内容 |
|------|------|
| 起点 | 食指与拇指之间（与人纹同源） |
| 走向 | 弧形环绕金星丘至手腕 |
| 主宰 | 体质、生命力、人生起伏 |

**判断标准**：

| 纹相 | 论断 |
|------|------|
| 深长清晰 | 体质好、精力充沛、生命力强 |
| 短浅 | 体质偏弱、需注重养生 |
| 有分叉 | 人生方向多选择、转折多 |
| 有断裂 | 健康需注意，或人生有阶段性转变 |
| 弧度大（环绕金星丘宽） | 精力旺盛、热情奔放 |
| 弧度小（贴近拇指） | 精力有限、宜节制用度 |
| 末端分叉 | 晚年多外出或迁移 |
| 有岛纹 | 对应年龄段健康需注意 |

古论多视作地纹主"命之所基"，深长者为先天禀赋厚，短浅断裂者需后天补益。**特别注意**：地纹不主寿命长短，主体质与人生起伏，断不可作寿命论断，此为商用合规红线。

## 二、辅纹详解

辅纹为后天所生，随人生经历变化，主阶段性运势与细节补充。

### 1. 婚姻线（小指下方短横线）

| 纹相 | 论断 |
|------|------|
| 清晰一条 | 婚姻稳定、感情专一 |
| 多条 | 感情经历多、易有多次婚姻 |
| 上翘 | 未婚或晚婚、感情独立 |
| 下弯 | 婚姻有波折、需用心经营 |
| 分叉 | 婚姻有裂痕、需加强沟通 |
| 清晰深长 | 婚姻质量高 |

婚姻线位于小指下方掌侧，古法相理多看感情经历与婚恋状态。婚姻线须与天纹（感情线）合参，方能定感情全貌。

### 2. 事业线（命运线·从手腕向中指方向）

| 纹相 | 论断 |
|------|------|
| 清晰深长 | 事业稳定、有方向、有毅力 |
| 中断 | 事业有变动、转折 |
| 分叉 | 有多个事业方向 |
| 无事业线 | 事业多变、自由发展 |
| 起自地纹 | 早立志、早创业 |
| 起自月丘 | 借外力成名、贵人扶助 |

事业线主一生事业轨迹，传统典籍记载清晰深长者为事业有成之相。事业线须与木星丘、土星丘旺衰合参。

### 3. 财运线（成功线·无名指下方竖线）

| 纹相 | 论断 |
|------|------|
| 清晰 | 有偏财运、易得名利 |
| 多条细线 | 财路多但不聚 |
| 无财运线 | 正财为主、需靠积累 |
| 与事业线平行 | 名利双收 |

财运线主偏财与名声，古论多视作"成功线"，与太阳丘合参。财运线清晰者利于投资与名气变现。

### 4. 健康线

从手腕斜向小指方向的细线。古法相理认为，健康线**有则需注意健康**，无则为佳。健康线深长者提示需注重养生与作息，断续者提示体质波动。健康线须与地纹（生命线）合参。

### 5. 贵人线

生命线内侧的平行短线。有则贵人运好、遇难呈祥；多条者一生贵人不断；清晰深长者贵人助力大。古论多视作"护身线"，主逢凶化吉、得人提携。贵人线须与面相福德宫、迁移宫合参。

## 三、主线交叉判断法

三大主线构成不同格局，古法相理以交叉形态定大格。

| 格局 | 论断 |
|------|------|
| 三大主线构成"M"字形 | 大吉之格，主事业、感情、生命三线皆顺 |
| 天纹与人纹间距宽 | 心胸开阔、包容性强 |
| 天纹与人纹间距窄 | 心胸较窄、易钻牛角尖 |
| 人纹与地纹同源长短 | 独立性强、自主决策 |
| 人纹与地纹分离起 | 早独立、敢闯敢为、离家发展 |
| 三线同源（同一起点） | 依赖性强、宜合伙 |
| 三线清晰深长不杂乱 | 一生平稳顺遂 |

**重要交叉原则**：
- 天纹主情、人纹主智、地纹主命，三者均衡为佳
- 主线清晰胜于辅纹，主线有缺辅纹难补
- 主线交叉须与八丘、五行掌型合参，不可单看

## 结语

三大主线为先天之基，辅纹为后天之应。古法相理强调"主线看底色、辅纹看变化、交叉定格局"。三大主线构成"M"字为吉，间距宽窄看心胸，同源分离看独立。主线、辅纹、八丘、掌型四者合参，方能完成手相五维（性格、事业、财运、感情、健康）的完整解读。
