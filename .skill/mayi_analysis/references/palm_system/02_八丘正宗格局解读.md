# 手掌八丘正宗格局解读

## 总论

掌丘者，掌中肉起之处也，古法相理以八丘配五星七曜，各主一域。八丘的饱满与低陷，反映不同领域的天赋强弱与运势旺衰。传统典籍记载，八丘须合参，不可单看一丘定论。

【手掌八丘分布文字示意图】
```
掌心向上视角：
左上：木星丘（食指下）｜中上：土星丘（中指下）｜右上：太阳丘（无名指下）｜右外上：水星丘（小指下）
右侧下方：太阴丘（月丘）
左下角大鱼际：金星丘
掌心中间：火星平原
掌根最下方：地丘
```

## 一、八大掌丘详解

### 1. 木星丘（食指下方）

| 状态 | 论断 |
|------|------|
| 饱满丰隆 | 权力欲强、有领导力、事业心重，主上进显达 |
| 低陷平坦 | 缺乏上进心、随遇而安，宜安分守成 |
| 过分饱满 | 野心过大、易独断，需注意人际 |
| 对应运势 | 事业地位、社会名望、领导权柄 |

古论多视作木星丘为"仕禄之丘"，饱满者主一生有上进心，能在组织中崭露头角。木星丘与食指相呼应，须与食指长短合参。

### 2. 土星丘（中指下方）

| 状态 | 论断 |
|------|------|
| 饱满适度 | 责任心强、稳重、有哲学思维，主中年有成 |
| 低陷 | 轻浮、缺乏耐心，主中年多波折 |
| 过分饱满 | 孤僻内向、易钻牛角尖 |
| 对应运势 | 中年运、思考能力、宗教哲学缘 |

传统典籍记载土星丘为"思虑之丘"，主中年（31-50岁）运势与心智成熟度。土星丘与中指相呼应，中指端正者此丘更验。

### 3. 太阳丘（无名指下方）

| 状态 | 论断 |
|------|------|
| 饱满丰隆 | 艺术天赋高、名声显达、人缘好 |
| 低陷 | 缺乏艺术感、名声平淡 |
| 过分饱满 | 虚荣心强、好面子 |
| 对应运势 | 中年财运、名声、艺术成就 |

古法相理认为太阳丘为"名望之丘"，亦主偏财与贵人，饱满者中年后多有名气积累。太阳丘与无名指、财运线相呼应，须三者合参。

### 4. 水星丘（小指下方）

| 状态 | 论断 |
|------|------|
| 饱满 | 口才好、商业头脑、机智灵活 |
| 低陷 | 不善表达、缺乏商业嗅觉 |
| 过分饱满 | 狡黠多辩、易招是非 |
| 对应运势 | 商业财运、人际沟通、子女缘 |

传统典籍记载水星丘为"商贾之丘"，主商业天赋与口才表达。水星丘与小指、婚姻线相呼应，饱满者利于从商与传播。

### 5. 金星丘（大鱼际·拇指根部）

| 状态 | 论断 |
|------|------|
| 饱满有弹性 | 精力充沛、感情丰富、有爱心、人缘佳 |
| 低陷 | 精力不足、感情冷淡 |
| 过分饱满 | 感情用事、易纵欲 |
| 对应运势 | 生命力、爱情运、情感能量 |

古论多视作金星丘为"生命之丘"，是八丘中最大者，主一生精力与情感底色。金星丘亦为地纹（生命线）所环绕区域，须与地纹深浅合参。

### 6. 太阴丘/月丘（掌外侧下方·小指根部至掌根）

| 状态 | 论断 |
|------|------|
| 饱满 | 想象力丰富、有艺术直觉、善旅行、灵感多 |
| 低陷 | 缺乏想象力、不安于现状 |
| 过分饱满 | 幻想过多、不切实际 |
| 对应运势 | 出行运、灵感、异地机缘 |

传统典籍记载太阴丘为"灵感之丘"，主想象力与外出机缘，饱满者多有旅行运或异地发展之兆。太阴丘与金星丘隔火星平原相对，一阴一阳须均衡。

### 7. 火星平原（掌心中央）

| 状态 | 论断 |
|------|------|
| 适度凹陷 | 内心平静、有定力、能抗压 |
| 过分平坦 | 缺乏热情、行事冷淡 |
| 过分凹陷 | 容易消极、抗压弱 |
| 对应运势 | 中年转折、内心力量、情绪格局 |

古法相理认为火星平原为"心境之丘"，平原（非丘）特殊，主内心世界与情绪格局。适度凹陷为吉，与金星丘、太阴丘形成"凹"形为佳格。火星平原分上下两区，上区主勇气、下区主耐心。

### 8. 地丘（掌根最下方·手腕上方）

| 状态 | 论断 |
|------|------|
| 饱满 | 健康长寿、根基稳固、晚运佳 |
| 低陷 | 体质偏弱、根基不牢 |
| 过分饱满 | 保守固执、不思变 |
| 对应运势 | 晚年运、健康根基、祖业 |

传统典籍记载地丘为"根基之丘"，主晚年运与先天体质。地丘饱满者晚年安泰，与面相下停（地阁）相呼应。地丘亦主祖业根基，饱满者多有家学或祖产。

## 二、八丘综合判断法

### 1. 配合判断原则

古法相理强调"八丘相不独论"，须注意以下配合：

- **整体旺衰**：八丘整体饱满者为大福之相，整体低陷者需后天补益
- **主次分明**：以木星丘、土星丘、太阳丘、金星丘为四大主丘，余为辅丘
- **左右对照**：左手看先天、右手看后天，两手对照看变化趋势
- **与主线配合**：八丘旺衰须与三大主线走势交叉验证

### 2. 常见旺衰组合

| 组合 | 论断 |
|------|------|
| 木星丘+土星丘均饱满 | 事业心强+稳重，主中年大成的栋梁之格 |
| 太阳丘+水星丘均饱满 | 名声+商业头脑，主名利双收 |
| 金星丘+地丘均饱满 | 精力+根基，主长寿富足 |
| 太阴丘+水星丘均饱满 | 灵感+口才，主文艺传播之才 |
| 火星平原适度+金星丘饱满 | 内心定力+精力充沛，主抗压能成大器 |

### 3. 旺衰调和

八丘有缺者，古法相理多提示后天修心补益：木星丘低者宜主动进取、培养领导力；土星丘低者宜修耐心、培养长远眼光；太阳丘低者宜培养审美、积累名声；水星丘低者宜练口才、学商业；金星丘低者宜养身修心、培养情感；太阴丘低者宜开阔视野、多出行；地丘低者宜固本培元、注重健康。

## 结语

八丘者，掌中之"五脏六腑"，各主一域天赋与运势。饱满为旺、低陷为衰，过旺过衰皆需调和。古法相理以八丘合参、与主线交叉，方能定先天禀赋与后天运势，为性格、事业、财运、感情、健康五维解读提供掌丘依据。
