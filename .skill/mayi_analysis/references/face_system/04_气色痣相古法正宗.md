# 气色与痣相·古法正宗（商用终审版）

> 气色与痣相为面相第四优先级（权重15%），气色主近期运势波动，痣相为先天标记。本文基于《麻衣神相》《柳庄相法》《神相全编》三典统合校订。相学为传统文化趣味参考，不作宿命断言。

## 一、气色总论

**骨为体，气色为用**：古法相理认为，骨相为先天之体，定一生格局大势；气色为后天之用，反映近期运势动态变化。

- **骨相**：主一生格局，先天既定，变化缓慢
- **气色**：主近期运势（半年内），随境遇、作息、心境动态变化

气色以"明润"为吉、"暗沉"为滞。气色可后天调养，规律作息、修心养性可改善气色，进而改善近期运势。

## 二、五色吉凶详解

| 五色 | 吉凶 | 主运 |
|------|------|------|
| 黄色 | 润黄为吉，暗黄为滞 | 主财运、喜事 |
| 红色 | 明红为吉，暗红为灾 | 主喜庆、官非 |
| 青色 | 多主不吉 | 主惊恐、压力、肝胆问题 |
| 白色 | 多主不吉 | 主丧服、破财、肺疾 |
| 黑色 | 多主大忌 | 主灾祸、重病、肾虚 |

- **黄色**：润黄如明油为大吉，主进财升迁；暗黄如蒙尘为滞，主财运迟滞。
- **红色**：明红透润为喜庆、进财；暗红如血为灾，主官非口舌。
- **青色**：主惊恐压力、肝胆失调，多见于过度劳累或受惊后。
- **白色**：主丧服破财、肺气不足，多见于大病初愈或忧伤过度。
- **黑色**：主灾祸重病，最为忌讳；若黑而枯槁无光，需提示静养避险。

## 三、四季正常气色

古法相理认为，气色须应季而论：

| 季节 | 应季气色 | 说明 |
|------|----------|------|
| 春 | 青 | 春属木，微青为应季，不忌 |
| 夏 | 赤 | 夏属火，微红为应季，不忌 |
| 秋 | 白 | 秋属金，微白为应季，不忌 |
| 冬 | 黑 | 冬属水，微暗为应季，不忌 |

应季气色为生理自然，不作凶论。反季气色（如春见枯黑、夏见惨白）为凶兆，提示对应脏腑失调或运势反常。

## 四、气色部位对应

不同部位气色对应不同运势领域：

- **印堂发黑**：主灾，提示近期运势低迷，需静心避险
- **天庭发黄**：主升迁，事业有进益之兆
- **准头红润**：主进财，财源有进
- **眼尾发青**：主感情压力，需注意沟通
- **地阁明润**：主晚年安泰、子女顺

> 商用要点：气色用于近期运势判断（半年内），重点察印堂、准头、天庭三处气色变化。

## 五、痣相总论

**痣的分类**：

| 痣色 | 吉凶 | 说明 |
|------|------|------|
| 黑痣 | 多凶 | 色黑而枯者多主耗损 |
| 红痣 | 多吉 | 色红如朱者多主吉庆 |
| 褐痣 | 中性 | 视部位与气色综合论 |

**痣的显隐**：古法相理认为，痣"藏为吉、露为凶"。
- **藏痣**：藏于眉内、耳内、发际等隐蔽处为吉，主暗藏福泽。
- **露痣**：露于面部显眼处多凶，主对应运势耗损。

## 六、痣相吉凶部位速查

**吉痣部位**：

| 部位 | 寓意 |
|------|------|
| 眉内藏珠 | 主智慧、暗藏福泽 |
| 耳垂有痣 | 主长寿、积福 |
| 下巴有痣 | 主有产业、田宅运佳 |

**凶痣部位**：

| 部位 | 寓意 |
|------|------|
| 印堂有痣 | 主运势受压、心胸受阻 |
| 眼尾有痣 | 主感情不顺、姻缘多波 |
| 鼻梁有痣 | 主破财、财源受阻 |

> 商用要点：痣相用于先天标记解读，需结合十二宫点位判断影响领域。痣色黑枯、长毛者多主耗损；红润者多吉。

## 总论

气色主近期运势（半年内），可后天调养改善；痣相为先天标记，定影响领域。二者须与骨相格局、五官十二宫配合，"相不独论"。气色明润为吉、暗沉为滞，可借修心养性、规律作息改善；痣相藏吉露凶，需结合部位论影响。所有论断遵循传统文化参考定位，强调后天修心改运，不作宿命断言。
